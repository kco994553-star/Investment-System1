## 1-3. 공개 + 비공개 2층 구조 (2026-10-31 오너, DC-36)

모든 기능은 두 층이다.
- **공개 층:** 공개 파일·정적 앱 내용·사용자 기기 자료로 완전히 동작한다.
- **비공개 층:** 로그인한 오너에게만 덧붙는다. 1인 비공개 구역 [#436 설계](../../implementation/docs/private_area/PRIVATE_AREA_KIS_DESIGN_20261031.md)를 따르고, 기본 공급처는 KIS(통합 일봉·거래량·장중가)이며 Lab 비공개 결과도 여기에 든다.

공개 화면·파일은 비공개 자료에 기대지 않는다. 비공개 자료가 없어도 공개 화면은 그대로 동작하고, 로그인 여부로 공개 결과가 바뀌지 않는다(설계 18.3, 가드로 검사). 비공개 추가분은 화면마다 `IS2.parts.privatePanel` 하나로 붙인다. 그 칸의 상태는 `비공개 기능 준비 중`(지금) · `로그인 필요` · 불러오는 중 · 오류 · 자료 없음 중 하나다.

**"비공개 추가분" 열은 제안이다. 오너가 승인한 뒤 확정한다(`TWO-LAYER-ADD`).** 기기에만 두는 개인 자료(보유·가중치·노트·★)는 비공개 층이 아니다(DC-22). V는 중앙 V(IEX) 그대로이고, KIS로 공식 V·순위·TARGET을 바꾸지 않는다.
