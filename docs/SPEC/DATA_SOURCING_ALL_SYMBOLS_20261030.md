## 5. AI·플러그인 수동 갱신 계약

원자료 수집 → 출처/시각 보존 → AI 구조화 초안 → 결정적 검증 → 기존값 대비 변경 검토 → 허용된 저장/게시 경로 → 웹 판독.
자동 경로와 수동 경로가 동일 입력 계약·검증기를 쓰도록 한다. 플러그인 연결이 웹 서버의 상시 호출 권한이나 자동 실행 기능을 뜻하지 않는다.

필수 메타데이터: 원천/접근 경로, 증권 식별자, 시장/통화/단위, 대상 기간/가격 기준일, 발표·가용·취득 시각, 원문 또는 적법한 원문 증거 참조, 수정/분할/배당 조정 방식, 변환 버전, 검증 상태, 갱신 방법, 실패 사유. 데이터 수명·저장·표시 권한도 별도 기록.
AI 해석과 사실 수치를 분리한다. 미확인을 0으로 채우거나 추정 가격을 차트에 넣지 않는다. 공급처 충돌은 출처/시점/조정 기준을 대사하고 조용히 덮어쓰지 않는다.
