# 방향 전환 대장 (Direction Changes)

작성 2026-10-23 23:20 UTC / 2026-10-24 08:20 KST. **AI가 가장 자주 되돌아가는 옛 방향을 한곳에 모은 문서다.** 새 세션은 [START_HERE.md](../../START_HERE.md) 다음에 이 문서를 읽는다.

- 각 줄은 "옛 방향(쓰지 말 것) → 현재 방향"이다. **결정**과 **구현 상태**를 따로 적는다. 결정만 되고 코드는 아직 옛 방향인 경우가 혼동의 주원인이다.
- 금지 표현은 [direction_rules.json](direction_rules.json)으로 기계 검사한다(`implementation/tools/spec_direction_guard.py`, CI 전체 시험에 포함). 옛 방향을 "바뀌었다"고 설명하는 줄은 통과한다.
- 새 방향 전환이 생기면 이 표에 한 줄을 더하고, 필요하면 규칙도 더한다. 결정 원문은 계속 [USER_DECISIONS_PENDING](../../implementation/docs/USER_DECISIONS_PENDING.md)에 둔다.
