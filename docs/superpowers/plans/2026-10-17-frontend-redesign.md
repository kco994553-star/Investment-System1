# 프론트엔드 시안 구현 계획

Goal: 현행 공개 데이터로 다섯 주 메뉴와 기업 상세·설정이 동작하는 반응형 시안을 만든다.
Architecture: experiments/frontend-redesign-v2에 격리한다. model.js는 자료 판정·검색·정렬, app.js는 화면과 이벤트, styles.css는 반응형 표현, data.js는 출처가 있는 읽기 전용 스냅샷이다.
Spec: docs/superpowers/specs/2026-10-17-frontend-redesign.md

1. [x] 자료 판정·검색·정렬 모델: 버전 불일치·7일 최신성·0점·결측 정렬·한글 alias·출처 URL 테스트 후 구현.
2. [x] 공통 shell + 오늘/기업/포트폴리오/시장/기록/설정/상세 구현. 직접 값에서 SVG Q·G 산점도·재무 추이·목표 배분을 그린다.
3. [x] 데이터 snapshot SHA와 시점 기록. HTML 단일 파일로 패키징. 모델 테스트·JS 문법·링크/출력/값 대조 검증.
4. [x] 독립 리뷰와 발견 사항 수정 완료. 원격 작업 브랜치·draft PR로 전달하며 운영 병합/배포는 하지 않는다.

Review focus: 오래된 행, target/universe 혼용, 사용자 입력 HTML, 선택/필터 상태 복원, 모바일 조작과 브라우저 검증 제한.

검증: Node 모델·출력·회귀 검사 17개 통과. 리뷰에서 발견한 결측 날짜의 1970년 표시, 한글 IME 조합 중 입력 교체, 표의 결측 사유 구분을 수정하고 회귀 검사로 확인했다. 실제 브라우저·모바일 검사는 환경상 수행하지 못했으며 운영 연결 전 필수로 남긴다.
