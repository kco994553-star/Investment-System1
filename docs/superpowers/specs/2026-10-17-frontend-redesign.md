# 투자시스템 프론트엔드 개편 시안 v2

사용자 요청: 현재 프론트엔드를 다시 만들되 투자시스템에 들어갈 기능을 고려한다.
확인 기준: canonical d98757c, WORKING_RULES, CURRENT_HANDOFF, USER_DECISIONS_PENDING, PLAYBOOK §17·18 및 2026-10-17 실제 Pages 화면.

## 목표와 선택
매일 확인 → 기업 탐색 → 기업 상세 → 포트폴리오 반영 → 기록의 사용자 흐름으로 구성한다. 현재 구현 내부의 QGV/Technical/Macro 분류를 주 메뉴로 노출하지 않는다.
선택: 밝은 분석 화면 + 네이비 사이드바 + 청록 강조. 기존 카드 재배치만 하는 안은 정보 우선순위를 해결하지 못하고, 고밀도 트레이딩 터미널 안은 모바일 가독성을 희생한다.

## 이번 결과
운영 파일과 분리된 실제 클릭 가능한 프론트엔드 설계 시안. 합성 가격·수익률·매매 신호를 만들지 않는다. 공개 게시본을 고정한 재무 점수·공시·뉴스와 TARGET v0를 사용한다. 새 홈페이지를 현재 운영 배포에 연결하거나 차트 탐지/매크로 게이트/TARGET v1을 가동하지 않는다.

## 정보구조
1. 오늘: 관심기업 목록, Q·G 분포, 참고 배분, 최근 공시·뉴스.
2. 기업 탐색: 티커·한글명 검색, 관심/자료 여부 필터, Q·G 정렬, 3종목 비교.
3. 기업 상세: 투자 유형 / 산업(SIC 기반, GICS로 오기하지 않음) / 전략 테마 독립 3축; Q·G 결과; 실제 연간 영업이익률 추이; Q·G 요인; 출처·수집 시점; 가격·가치·이벤트 연결 슬롯.
4. 내 투자: ACTUAL과 TARGET 분리. 공개 TARGET v0 19종목·4개 배분, 실제 보유는 미연결. TARGET v1 편집·확정과 3회 전환은 후속 운영 연결.
5. 시장·뉴스: 공시와 뉴스 구분, 신규·중복, 출처/시각/원문. 매크로와 13F 연결 계획.
6. 성과·기록: 실제/가상/일일 가상 매매/전진검증 구분. 미수집 성과 곡선을 만들지 않는다.
7. 설정: 언어/테마, 데이터 출처·계산 버전, 원자료 기본 접힘, 개편 범위 안내.

## 경계
- QGV v2만 표시. Q와 G의 평균을 총점으로 새로 만들지 않는다. V·현재가·평가금액은 가격 입력이 없으므로 미연결.
- calc_version 불일치, 결측, 만료를 구분. 숫자 0을 결측으로 취급하지 않는다. 504 universe와 TARGET 19 표본을 구분한다.
- 공개된 관심 목록 시안은 TARGET v0 참조이며 실제 기기 관심/보유 목록이라고 부르지 않는다.
- 시안 즐겨찾기는 독립 키에 저장하며 기존 앱의 금융 데이터·인증·계정·설정에 접근하지 않는다.
- 출처 링크는 http(s)만 허용. 입력/원문 escape. 외부 스크립트·폰트·이미지 자동 로딩 없음.
- 360px 이상 반응형, 모바일 5개 하단 메뉴, 필터/도구 가로 스크롤, 표만 내부 스크롤. 키보드 초점·닫기·현재 메뉴·reduce motion 지원.

## 운영 통합 순서
디자인 확인 후 ① 기존 shell/route 연결 ② 탐색·상세의 기존 QgvScores·PrivateHistory·CompanyScreen 연결 ③ 포트폴리오·매크로·성과 연결 ④ 390/1440px·ko/en·키보드·실제 입력·오류 상태 검증 ⑤ 승인 범위에서 병합/배포. 엔진 계약·원본 TARGET·Frozen은 변경하지 않는다.

## 검증 한계
이 환경에는 Sites control-browser가 없어 새 시안의 실제 브라우저 검사는 수행하지 않는다. 논리·출력 구조·문법·실제 출처 대조를 확인하고 운영 통합 전 브라우저 검사를 남긴다.
