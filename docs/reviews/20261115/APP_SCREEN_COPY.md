기준: 기본 가지 `4a3141b8fa1593e68552390c7ad4b1ea16b89d2f`, 2026-11-15. 소스 기반 조사이며 브라우저·배포·로그인 실환경 검증이 아니다. app.html은 [implementation/tools/web_app_preview.py:46](https://github.com/kco994553-star/Investment-System1/blob/4a3141b8fa1593e68552390c7ad4b1ea16b89d2f/implementation/tools/web_app_preview.py#L46)이 web_app/index.html로부터 생성한다. 기본 소스, 미병합 Draft 추가분, 동적 데이터는 구분한다. 아래는 재작성 요구사항이며 문구·가드·화면 코드는 수정하지 않았다.

## 범위와 해석

- 메뉴 0~6/n/n+1 표시는 현재 UI 번호다. 기능 명세 1~9와 혼동하지 않는다.
- screen-* 20개와 shell/parts/core/search-part-live/private/lab/qgv의 정적 문자열을 조사했다. 파일별 전수 후보 부록은 조건부 상태·접근성 라벨·동적 문자열 단편까지 포함한다. 문자열은 조합되거나 숨겨질 수 있으므로 모든 행이 동시에 화면에 표시된다는 뜻이 아니다.
- API/공개 JSON의 회사명·뉴스 제목·오류 사유·수치·일시, 사용자 노트, 가격 값은 이 문서에 복제하지 않는다. 해당 표시 슬롯을 유지하고 실제 데이터 인수 때 확인한다.
- loader가 불러오는 구 web_assets 모듈은 공유 엔진·판독기이며, 새앱이 실제 DOM에 연결하는 위치만 이 조사 대상이다. 구 화면 자체의 문구는 index.html 조사에서 다룬다.
- 프롬프트 라이브러리의 70개 입력 프롬프트 본문은 기능 데이터다. 제목과 원문 위치를 별도 목록으로 남기고 본문 전체를 방어용 UI 문구로 잘못 삭제하지 않는다.
- 정적 후보 부록은 기계 추출 + 처리 규칙 적용이다. 아래 주요 판정은 직접 소스를 읽고 결정했다. 영어 고정 라벨·aria-label도 후보에 포함했으나 데이터에서만 들어오는 영어 표현은 동적 범위다. 전체 렌더링 문자열의 완전성을 주장하지 않는다.
- DC-56은 설명 최대 한 문장, 운영 진단은 설정 상태, 출처 짧게·상세는 클릭, 자문 고지 하단 한 번이다. 오류/비산출 이유/사용자가 해야 할 조작을 없애는 규칙이 아니다. 정보구분 라벨(공식/연구/비공개/표본 진단)은 보존한다.
