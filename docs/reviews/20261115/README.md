## 판정의 의미

PR의 **병합 후보**는 다음 검토 대상으로 제안한다는 뜻이다. 오너 승인·최신 HEAD의 CI·최종 파일 범위·충돌 해결을 확인한 병합 허가는 아니다. **다른 PR로 대체됨**도 기본 가지에 배포됐다는 뜻이 아니다. 본문의 대체 선언과 Git 조상 관계를 구분한다. **닫을 것**은 승인 요청 목록이며 실제 종료는 오너 승인 뒤 Main이 한다.

화면 글은 소스에서 확인했다. 공개 사이트의 현재 배포 SHA, 로그인한 오너의 실자료 화면, 모든 오류 분기의 실제 DOM은 이번에 검증하지 않았다. 따라서 문자열 존재와 실환경 노출을 같다고 취급하지 않는다. 동적 값은 템플릿으로 남기고 실제 가격·개인 자료를 수집하지 않았다. 부록의 기계 추출 후보는 화면별 수동 판정과 구분한다.
