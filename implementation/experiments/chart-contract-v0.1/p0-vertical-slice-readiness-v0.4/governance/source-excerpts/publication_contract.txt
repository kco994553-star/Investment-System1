# PUBLICATION_ENVELOPE v1 — Contract

Policy: `docs/producer_infrastructure/P01_APPROVAL_2026-10-02.md` (APPROVED / ACTIVE_POLICY).
Code: `src/investment_system/publication/`.
Tests: `tests/test_p01_research_publication.py`.

This layer does not score, rank, select, or import QGV, Leaderboard, Macro, Technical, Portfolio, or Track C engines.
It reads a persisted document, copies the hash that document already carries, and decides whether an envelope may name a publication mode.

## Axes

These stay separate. The predicate does not collapse them and does not branch on a producer name.

| Axis | Rule |
|---|---|
| schema-1 `data_state` | `LIVE`, `FROZEN_SNAPSHOT`, `DEMO`, `NOT_AVAILABLE` only. `RESEARCH` is not added. `schema_version` stays 1 |
| `publication_mode` | Envelope only. `NOT_AVAILABLE` or, when an explicit research-display grant matches and disclosure allows it, `DISPLAY_RESEARCH` |
| producer validation | `PASS` / `FAIL` / `NOT_RUN`. `PASS` is not a grant and not Track C |
| methodology lifecycle | Copied verbatim. A research lifecycle is not a schema-1 state |
| Track C | This layer always records `NOT_RUN` and `track_c_validated=false`. A claim on the document is ignored |
| completeness | `READY` / `PARTIAL` / `BLOCKED` copied or mapped from the document's own status. `BLOCKED` and `POLICY_BLOCKED` are not shown as a score |
| grants | Research-display, Frozen, and Live are independent. One does not satisfy another |

## Active grants

| Grant | Status |
|---|---|
| Research-display | **NONE** |
| Frozen | **NONE** |
| Live | **NONE** |

`attach_publication_envelope` always uses that empty set. It cannot be given a grant.
`DISPLAY_RESEARCH` is therefore not active. Every production decision is `NOT_AVAILABLE`.
`decide` is the pure predicate. A test may pass a hypothetical authorization to it. That call does not change schema-1 and does not write a grant.

## Envelope

`publication_envelope` is a top-level key on a copy of a schema-1 bundle. It is not placed inside section `data`.
Section `state` and `data` are unchanged. Research bytes are not relabelled `LIVE`, `FROZEN_SNAPSHOT`, or `DEMO`.
Existing clients keep reading research sections as `NOT_AVAILABLE`. Only a client that reads the envelope sees the decision, which is `NOT_AVAILABLE` while grants are none.

## Extractors

Exactly one structural extractor must match. The predicate then sees only the fact.

| Document shape | Fact |
|---|---|
| `QGV_COMPANY_RESULT` v1 | Copies `semantic_sha256`. Does not copy Q/G/V or total. `PASS` is `PARTIAL`. Anything else is `BLOCKED` |
| `LEADERBOARD_COMPANY_RESULT` v1 with publication `NOT_AVAILABLE` | Copies `semantic_sha256`. A `POLICY_BLOCKED` within-tie order is `BLOCKED`. Score values are not copied |
| Macro withheld shell | `publication=POLICY_BLOCKED` and the four stored reasons. The fact hash is the canonical hash of the `NOT_AVAILABLE` producer snapshot only. Regime and indicators are not read |
| `TECHNICAL_RESEARCH_RECORD` with `web_publication.status=BLOCKED` | Copies `semantic_hash`. Feature, regime, and zone values are not copied. `m1`/`m2` `APPROVED` is a component label, not Track C |

A missing Yahoo-style or other document matches zero extractors and is refused.

## Withholding

`research_bytes_withheld`, `stale_or_expired`, `synthetic`, or a blocked score keeps `publication_mode` at `NOT_AVAILABLE` even if a hypothetical research-display grant names the same hash.
Stale data does not fall back to `DISPLAY_RESEARCH`.
`PARTIAL` may be `DISPLAY_RESEARCH` only in the pure predicate when an explicit research-display grant matches that hash. Production does not hold such a grant.
`reject_promotion` raises for `LIVE`, `FROZEN_SNAPSHOT`, `OFFICIAL`, `VALIDATED`, and `RESEARCH`.

## Invariance

Publication does not recalculate QGV, Leaderboard rank, Macro, Technical, Universe, or Portfolio.
The pinned engine fingerprint and the protected file digest are tests.
