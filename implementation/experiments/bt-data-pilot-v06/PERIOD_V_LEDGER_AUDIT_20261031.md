# BT-DATA-PILOT v0.6 — 2016년 이전 확장·V 입력·실자료 장부

## 실제 확보한 기간

기존 2016~2026 SIP 가격은 다시 수집하지 않았다. 신규 KIS 조회로 ABT의 **2009-11-06~2010-04-01 100행**과 **2011-02-01~2015-12-31 1,238행**을 확보·재사용했다. 두 구간은 연속이 아니다. 2010~2015 기준 달력 1,510일 중 1,300일(86.09%) 확보, **2010-04-05~2011-01-31 210일** 미확보다. 최초일 2009-11-06은 반환 페이지의 경계이며 공급처 제공 시작일 판정이 아니다.

기존 KIS **5회사·190행(2015-11-06~12-31)**을 원본으로 재확인했다. 신규 가격 행은 1,300개, 중복 제거 후 2016년 이전 자료는 **5회사·1,490행**이다. 최근 KIS 구간과 합친 검증 입력의 재사용 페이지는 이 신규 수에 중복 가산하지 않았다.

KIS API는 요청 시작일 대신 **BYMD 조회 기준일**을 받는다. 목표 시작일과 실제 인자를 구분한다. ABT `BYMD=20151105`로 기존 첫 페이지보다 이른 100행을 확보해, 종전 2015-11-06이 데이터 한계가 아니었음을 입증했다. 이어 각 페이지의 최저일 전날을 BYMD로 넣어 2011-02-01까지 진행했다. 동일 100행 반복 없이 진행했고, `BYMD=20110131`에서 `OPSQ1002 SESSION FULL`이 발생해 즉시 중단했다. 재인증·반복 재시도하지 않았다.

- [첫 실행 41172239025](https://github.com/kco994553-star/Investment-System1/actions/runs/41172239025): 인증 1회, 시세 4회. 2010 앵커 성공, `BYMD=20000403` HTTP 200/성공코드/0행, `BYMD=19900402` HTTP 500 `EGW00316` 조회 처리 오류. 2000 전체 미제공 또는 1990 자료 없음으로 일반화하지 않는다.
- [2010 확장 41172414612](https://github.com/kco994553-star/Investment-System1/actions/runs/41172414612): 인증 1회, 시세 신규 12회. 성공 캐시 재사용, 11페이지 추가 성공 후 SESSION FULL. 다른 9회사의 2010 앵커는 **미실행**이다.
- 두 실행 모두 비공개 raw 저장소의 `bt-data-pilot-v06-pre2016-<run>-1/final.zip`에 저장, 다운로드 후 SHA 검증. 비밀키·토큰은 저장하지 않는다. 수집기 호출 상한과 2초 간격을 적용했고, 샘플 반복 횟수를 공급자의 역사 제공 한도로 해석하지 않았다.
- 각 페이지 OHLCV를 원문 숫자로 재파싱·대조했다. ABT KIS/SIP 중복 162일에서 종가는 정확히 모두 일치. 0.01 USD 허용차로 시가 154/162, 고가·저가·종가 162/162, 거래량 0/162 일치. 시가 8일·거래량의 세션/집계 차이는 미해결이다. 가격 평균·자동 이어붙이기를 하지 않았다. V4에는 증권·통화·무분할·월말 달력 근거를 확인한 ABT 종가만 제한적으로 연결했다. 겹친 162일은 2016-01-04~2016-04-01 62일와 2026-06-03~2026-10-23 100일이며, 아래 실제 원본 집계가 우선한다.

## ABT 주식수와 V 감사

`QGV_V2_V_DEVICE.md`의 EV, `QGV_V2_QG_METHOD.md`의 V-SHARES, `USER_DECISIONS_PENDING.md`의 SH-BASIS는 **최근 공시 가중평균 희석주식수**를 지정한다. ABT의 종전 입력은 이 계약에 맞는다. 기말 발행/유통주식수·기본 가중평균으로 바꾸지 않았다. 실제 시점 시가총액과 동일하다는 의미가 아니라 기존 QGV의 EV 대용 정의다. 점시점 주식수로 바꾸려면 별도 명세 변경이 필요하다.

2016-04-01 기준 기존 3셀의 재구성 입력 통과를 유지하고, 실제 KIS 2013~2015 월말 종가를 확보해 V4를 추가했다. 2013년 AbbVie 분사 이전의 경제적 비교 기준이 미검증인 2012년 가격은 사용하지 않았다.

- 계산 완료 **19→20/50**, 재구성 PIT 입력 통과 **3→4/50**. 50은 고정 10회사 × V 5요인이며 가격 필드 수가 아니다.
- 회사별 계산: ABT 4, ACU 2, AE 3, BKTI 0, AMD 2, CECO 3, MATX 3, ALX 0, LNG 2, IDSA 1. ABT 외 셀은 산술과 입력 적격을 분리한다.
- V3 산업 대비는 모집단 없이 산출하지 않았다. 시장 모집단 점수 **0**, 당시 벤더 저장본 재현 **0**. V4의 자기 역사 점수 1셀은 시장 백분위가 아니다. 결측 가중치를 재분배하지 않았다.
- ABT **15평가일**: 2016년 기존 분기 신호 4개, 2016-04-01 기준일, 2017~2026 연간 신호 10개. 고정 달력으로 날짜 집합을 대조했다. ABT 75셀 중 **59셀 계산**, 첫 2016-02-12는 V4 선행 역사 부족으로 3셀, 이후 14시점은 4셀. 전 기간 일별/매월 계산을 완료했다는 의미가 아니다.
- 2016-02-12에는 2/19 공개된 2015년 연차보고서를 쓰지 않고 당시 공개된 2014년 연차·2015년 분기 자료를 사용했다.
- 새로운 상태 등록부는 산출·입력 적격·재구성 PIT·당시 저장본·모집단 점수를 분리한다. 기존 보고서와 50셀 파일은 과거 관측으로 보존한다.

V5는 **과거 3년 매출 CAGR**이다. ABT 2016-04-01에 사용한 기간은 FY2012→FY2015, 출처는 2015-02-27 17:57:49 UTC 접수본과 2016-02-19 20:48:41 UTC 접수본이다. 평가일 이후 실현 매출을 사용하지 않았다. 기존 기준일 V5 계산 가능 회사 4개와 ABT 15평가일의 원본 기간·공개시각을 검사했다. 공식 6유효숫자 반올림까지 일치시키고 운영 산식은 바꾸지 않았다. 역DCF solver의 별도 독립 구현 대조는 미실행이며 OOS 근거가 아니다.

가격 수집시각(2026년), 역사 거래시각, 연구상 S 완료 일봉을 T 시가 주문에 쓰는 가정, 실제 공급자 배포시각/수정 빈티지는 별도다. 기존 `RECONSTRUCTED_AS_OF` 어댑터는 당시 벤더 응답 저장본을 필수로 요구하지 않는다. 따라서 빈티지 미보유를 재구성 연구 전체의 차단으로 쓰지 않되, 실제 수신시각을 입증했다고 표시하지 않는다. 이는 추가 품질 등급을 구분한 것이며 승인 계약 완화가 아니다.

## 실제 입력 장부와 종료 사건

기존 연구 장부·PIT·거래일 엔진을 재사용했다. ABT 1개를 N15 중 한 슬롯에만 넣고 나머지 현금, 양방향 10bps, 계약상 별도 진단인 현금이자 0을 명시했다. 종목 선택 성과 실험이 아니다.

- 2016-02-12 신호 → **2016-02-16 실제 원시 시가 매수**, 2017-02-17 신호 → **2017-02-21 실제 원시 시가 매도**. 종료 사건을 미리 아는 매매 없음.
- 발행사의 실제 선언·권리기준일·지급예정일 **배당 4건**. 배당락은 [FINRA 17-19의 종전 Rule 11140](https://www.finra.org/rules-guidance/notices/17-19)에 따라 기준일 2영업일 전으로 도출했다. **거래소 ex-date 피드 직접 관측이 아니다.** 적용 구간 모두 보통 현금배당 25% 미만이며 관련 은행휴일 없음.
- 선언 원문: [2016-02-19](https://www.prnewswire.com/news-releases/abbott-declares-369th-consecutive-quarterly-dividend-300222959.html), [6/10](https://www.prnewswire.com/news-releases/abbott-declares-370th-consecutive-quarterly-dividend-300283018.html), [9/15](https://www.prnewswire.com/news-releases/abbott-declares-371st-consecutive-quarterly-dividend-300328391.html), [12/9](https://abbott.mediaroom.com/2016-12-09-Abbott-Raising-Quarterly-Dividend-for-45th-Straight-Year). 센트 금액·기준일·지급일을 역사 배당표와 코드로 대조했다.
- 배당락에 미수금, 발행사 지급예정일에 현금으로 이동. 실제 계좌 입금 확인으로 부르지 않는다. 비조정 가격만 써 현금배당 중복 반영을 피했다.
- **258개 일별 스냅샷, 수량·현금·미수금·NAV 1,032회 독립 Fraction 대사 통과**, 매수·매도 비용 모두 대사, 배당 4건과 체결 2건 중복 입력 멱등 검사 통과. 연구 가상 장부이며 실제 계좌 주문 0.
- 감사 코드의 수수료 합계가 기본 Decimal 28자리에서 반올림되어 정밀 대사가 실패한 것을 확인하고, 독립 합계의 정밀도를 높였다. 장부 엔진 버그로 보고하지 않는다. 공식 성장률의 6유효숫자와 달러/센트 표현 차이도 감사 코드에서 수정했다.

## 역사 모집단과 세 기간

보유한 `fja05680/sp500` 후보 CSV 1,262구간을 실제 집계했다. 끝 날짜를 잠정 반개구간으로 읽으면 1990/2000/2010/2016/2026 기준일 후보는 **0/491/499/505/503개**다. 이것은 검증된 역사 구성 수가 아니다. 원발표의 효력일·증권 ID·이용권을 확인한 완전한 시점 모집단은 **0개**이며 전부 정식 투입 보류다. FB→META 등 날짜 경계 미확정을 일괄 보정하지 않았다. 코드 MIT 라이선스를 S&P 원자료 권리로 대신 쓰지 않는다.

- **A 가격**: 위 회사별 원본 구간. 1983년 CSV는 격리 감사 표본.
- **B PIT 산식**: ABT 15시점 부분 V 입력과 2016-04-01 50셀 감사. 1998~2009 원문 8항목 확보가 같은 기간의 QGV 전체 입력 완성을 뜻하지 않는다.
- **C 정식 평가**: 없음. 검증된 역사 IEX 거래대상/역사 S&P500, QGV 전체 요인·결측 처리, 기업행사·상폐 정산, 비용/현금 계약의 전체 기간 검증이 필요하다. 가격이 조회되는 종목을 모집단으로 삼지 않았다. 과거 IEX 근거가 없으므로 소급하지 않는다. 더 오래된 미국 보통주 실험은 역사 모집단 근거를 가진 **별도 연구안**으로 등록해야 하며 현재 정의는 유지한다.

## 변경·검증·재개

신규 `pre2016_prices.py`는 기존 KIS Client·원본 저장소·정규화·비공개 릴리스 경로를 재사용한다. `github_kis_probe.py`는 기본 60회를 보존하면서 제한된 확장 작업의 상한 인자만 추가했다. `audit_v_ledger.py`, `audit_period_extension.py`는 저장 원본의 오프라인 검증이다. 운영 QGV/TARGET/자동매매는 변경하지 않았다.

실자료 재생과 별개로 기존 수집기 합성 회귀 **13개 통과**. 연구 장부/PIT/연간 계약 테스트는 `implementation` 작업 디렉터리에서 실행해야 한다. 루트에서 실행했을 때 6개의 상대 경로 오류가 났으며 제품 결함으로 분류하지 않았다. 올바른 작업 디렉터리에서 재실행한 기존 합성 회귀 68개는 모두 통과했다. 감사 스크립트의 원문 단위·정밀도 오류는 수정 후 실제 원본으로 재실행한다.

연구 엔진 의존성: 별도 보존 작업 트리 `ca310378ba4fe40a1a971da30b475d9812c68a15`의 `research/qgv_backtest`를 `--reviewed-src`로 참조한다. 새 엔진을 복제하거나 PR #417을 무단 병합하지 않았다. 해당 의존성이 없는 새 환경은 기존 Main 인계 패치부터 복원해야 한다.

오프라인 재현은 이 디렉터리의 `REPLAY_PERIOD_V_LEDGER.sh` 참조. 입력은 승인된 비공개 원본이며 개인 가격·산출값·장부 금액은 GitHub 공개 산출물에 포함하지 않는다. 셀 등록부는 숫자값 없는 단계별 상태만 공개한다.
