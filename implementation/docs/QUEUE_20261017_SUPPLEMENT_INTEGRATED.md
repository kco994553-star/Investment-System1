목표

A. 운영·데이터 안정화

- #289와 승인된 철회 후속 작업을 마무리한다.
- TARGET·Universe·기기 소비자·배포 검사의 상태 의미를 맞춘다.
- 식별 충돌과 단순 수집 실패를 구분한다.
- 철회된 자료가 점수·후보·시세 연결에서 사용되지 않는지 확인한다.
- raw 태그 충돌, 이전 관측 보존, 원장 연속성의 남은 작업을
  기존 결정과 승인 범위에 따라 처리한다.
- 배포 성공, 신규 수집 성공, 이전 관측 보존을 따로 집계한다.
- 실제 운영 증거와 합성·회귀 테스트 증거를 구분한다.

B. QGV·TARGET 검증

- 최종 숫자 재대조의 남은 항목을 처리한다.
  기기 FCF 수익률 / 3개사 HTML 대조 / 게시본 행 동일성.
- 기기에서만 가능한 검증은 사용자 실행 절차와 필요한
  최소 결과 항목을 준비하고 다른 검증을 계속한다.
- TYPE-SCOPE 반영 후 점수·유형 표시·플레이북·TARGET 기준을 맞춘다.
- WITHDRAWN-PEER는 최신 승인 여부를 확인하고 별도 변경으로 관리한다.
- #248·#263은 실제 최신 상태에서 이어간다.
- 구현 병합과 TARGET 확정을 구분한다.
- 규칙이나 입력이 바뀌면 영향을 받은 검증만 다시 한다.

C. 백테스트 준비

- 연구 전용 과거 공시 어댑터를 실제 표본으로 검증한다.
- 과거 모집단·상장폐지·가격·배당·분할·공개 시각·거래일 달력의
  확보 상태와 사용 제한을 정리한다.
- 승인된 가격 불필요 Q·G 시점별 검증은 계속한다.
- 10·15·20종목, QGV 단독, QGV+기술적 분석 등의 기존 연구 후보를
  현재 실험 등록부와 대조한다. 중복 실험을 만들지 않는다.
- 목적은 ‘현행 QGV 가중치와 선정 방식이 시장 대비
  투자 결과에 효과가 있는가’로 유지한다.
- 수익률뿐 아니라 위험·낙폭·회전율·비용·기간별 안정성과
  데이터 커버리지 편향을 검증 대상으로 유지한다.
- 연구 문서 병합을 BT·MD 결정 승인으로 간주하지 않는다.
- 운영 함수를 연구 목적으로 임의 변경하지 않는다.
- 불완전한 모집단이나 가격으로 만든 결과는 탐색 결과로 구분한다.
- 보호된 Holdout은 기존 승인 없이 소비하지 않는다.

4. 결측 기업도 확보된 정보와 값을 표시
━━━━━━━━━━━━━━━━━━━━

사용자 의도:
‘점수를 계산하지 못함’과 ‘기업 정보가 전혀 없음’을 구분한다.
확보된 값은 가능한 한 보여주고 상태와 사유를 덧붙인다.

기업 상세에서 다음을 제공한다.
- 확보된 유효 재무지표와 요인 값
- 계산 가능한 축 점수
- 기준기간·출처·수집 시각
- 현재 계산 반영 여부
- 누락·제외 사유
- 사용자 조치 또는 후속 조사 상태

다음을 서로 다른 상태로 표시한다.
자료 미확보 / 일부 자료 부족 / 가격 입력 필요 /
갱신 실패 / 오래된 자료 / 해당 없음 /
단위 확인 중 / 식별 충돌로 사용 중지

표시 규칙:
- 정상 값: 값·기간·출처를 표시한다.
- 오래된 값: 마지막 유효 값과 당시 기준일을 표시한다.
- 갱신 실패: 이전 값과 마지막 성공일, 갱신 실패를 표시한다.
- 부분 결측: 확보된 항목을 계속 표시한다.
- 단위 오류 의심: 원자료 값·단위·사유를 근거 상세에 표시한다.
  정상 현재값처럼 표시하거나 자동 보정하지 않는다.
- 식별 충돌: 다른 회사의 값으로 오인하지 않도록 사용 중지
  관측을 근거 상세에 분리한다.
- 실제 값이 없으면 숫자를 만들지 않는다.
- 과거 점수는 현재 점수와 분리하고 날짜·버전을 표시한다.

계산에서 제외한다고 화면에서 근거까지 삭제하지 않는다.
다만 오류·식별 충돌 값을 정상 분석값처럼 사용하지 않는다.

5. 커버리지 제외 사유와 복구 작업

축·요인별 결측을 다음 원인으로 구분한다.
- 원자료 부재
- 허용 태그·기간 선택 문제
- 가격 미입력
- 수집 실패
- 최신성 초과
- 단위·기업행사 문제
- 업종상 해당 없음
- 식별 충돌
- 원인 미확인

복구 가능한 경우:
- 기존 허용 개념의 다른 태그·공시·원문을 확인한다.
- 선택 함수 때문에 실제 존재하는 값을 놓치는지 점검한다.
- 올바른 근거가 확보되면 해당 경로를 최소 수정한다.
- 임의 배수 보정·0 채우기·다른 개념 대체는 하지 않는다.
- 새로운 대체 계산이나 업종별 규칙은 별도 결정으로 제시한다.

기업 수와 결측 요인 수를 구분한다.
같은 기업이 여러 사유에 들어가면 중복 집계임을 명시한다.

6. 부분 점수·가중치 재배분: 기존 구현 확인 우선
━━━━━━━━━━━━━━━━━━━━

사용자 의도:
일부 요인이 없어도 가용 요인으로 평가값을 제공하고,
결측과 가중치 처리 사실을 함께 보여주고 싶다.

먼저 현재 Q·G·V 구현을 확인한다.
- 결측 요인을 제외한 가중치 비례 재정규화를 이미 하는가?
- 자료 충족률은 원래 가중치 합계로 계산하는가?
- 축별 최소 충족률과 필수 요인 조건은 무엇인가?
- 부분 점수가 공식 순위·TARGET에 들어가는 조건은 무엇인가?
- ‘해당 없음’과 ‘자료 미확보’의 처리가 어떻게 다른가?

실제 함수·수식·작은 숫자 예시로 보고한다.
이미 구현돼 있으면 새 엔진이나 중복 계산을 만들지 않는다.

검토할 기본안:
- Q2가 빠졌다고 Q2 가중치를 Q1 하나에 몰아주지 않는다.
- 가용 요인 전체에 기존 가중치 비율대로 재배분한다.
- 부분 점수와 원래 가중치 기준 충족률을 함께 표시한다.

예시:
원래 가중치 Q1=25, Q2=10, Q3=25, Q4=20, Q5=20.
Q2가 없으면 남은 합계는 90.
가용 요인의 비중은 각각 25/90, 25/90, 20/90, 20/90.

이 예시는 방식 설명이며, 현재 공식 규칙 변경 승인이 아니다.

보호 조건:
- 가용 자료가 전혀 없으면 점수를 만들지 않는다.
- 재무 안전 필수 조건을 다른 요인의 높은 점수로 대체하지 않는다.
- Q·G·V 축 내부 재배분과 V 없는 기업의 Q·G 종합점수는
  별개 문제로 다룬다.
- 기존 산출 기준 미달 기업에 참고 점수를 제공하려면
  공식 점수와의 구분 및 사용 제한을 제안한다.
- 공식 규칙 변경이 필요하면 영향 분석 후 사용자 결정으로 남긴다.

7. 부분 점수의 화면과 결측 영향 범위
━━━━━━━━━━━━━━━━━━━━

기존 계약에서 가능한 표시부터 구현한다.
- 부분 산출 여부
- 원래 가중치 기준 자료 충족률
- 확보 요인 수 / 적용 요인 수
- 누락 요인·사유
- 재배분 전후 가중치
- 공식 순위·TARGET 사용 가능 여부

추가 검토:
누락 요인을 허용 점수의 최저~최고로 놓았을 때의
‘결측 반영 가능 범위’를 계산할 수 있는지 검토한다.

- 이는 산술적 범위이며 확률·통계적 신뢰구간이 아니다.
- 요인 점수 범위가 명확할 때만 산출한다.
- 비선형 관문·업종별 규칙이 있으면 단순 가중합 공식을
  무조건 적용하지 않는다.
- 근거 없는 중간값으로 누락 점수를 채우지 않는다.
- 추가 계산·공개 계약 변경이 필요하면 별도 제안한다.

목록에서는 다음을 구분해 탐색 가능하게 한다.
전체 / QGV 산출 가능 / 일부 축만 가능 / 자료 확인 필요

Q·G만 있는 기업도 찾아볼 수 있게 하되
QGV 종합순위와 같은 기준인 것처럼 섞지 않는다.

8. 결측 처리 방식의 백테스트 연구 후보
━━━━━━━━━━━━━━━━━━━━

기존 실험 등록부에 중복 없이 연구 후보로 기록한다.
실행·최종 채택 승인은 기존 연구 결정 절차를 따른다.

비교 후보:
- 현행 결측 처리
- 가용 요인 비례 재정규화
- 자료 충족률 기준을 달리한 방식
- 공통으로 자료가 갖춰진 기업만 사용하는 비교

현행 방식이 비례 재정규화라면 같은 실험을 중복 등록하지 않는다.

검증 항목:
- 점수를 산출할 수 있는 기업 수
- 결측 유무에 따른 점수·순위 변화
- 나쁜 요인이 빠져 오히려 순위가 높아지는 현상
- 업종·규모·시기별 편향
- 종목 교체·회전율·거래비용
- 시장 대비 수익과 위험
- 충분한 자료가 있는 기업과 부족한 기업의 결과 차이

가중치 방식 자체의 효과와 후보군 변화의 효과를 분리한다.
과거 시점에 실제로 알 수 있었던 자료만 사용한다.
결과를 본 뒤 유리한 결측 기준을 골라 정식 검증처럼 보고하지 않는다.
