## Golden evidence

golden_cases.json is captured once from exact canonical b8e39a2 with unchanged
source. It includes 71 explicit synthetic cases: uniform and heterogeneous/fractional
values; Q/G/V missing/all missing/blocked; financial applicability; every existing
QualityState with numeric/null values for representative Q and V factors; caller
confidence; out-of-range historical behavior; V-only change.

Every result field except the fresh operational qgv_snapshot_id is retained.
Axis/composite/attractiveness values also use float.hex() fingerprints to detect
arithmetic/rounding changes. Statuses, factor notes/table, candidate weights,
lifecycle, data stamps and version fields remain compared. This is equality of
the semantic projection, not equality of raw snapshot bytes with random IDs.

The fixture is not regenerated by tests or the committed tool. Independent
arithmetic anchors verify Q=70, missing 20% Q=56, financial Q=56, V-only 77.5 with
total=70, out-of-range Q=256 and null-total cases. Golden expectations and anchors
serve complementary purposes; a behavior golden is not an independent proof of
economic correctness. G/PIT raw cases are tested separately. Whole-repository
history preservation is checked against Git, not inferred from golden cases.

## Additional invariants and limitations

Existing registry/custom overrides are tested with isolated synthetic snapshots,
an in-memory board and TrackRecord container. Changing overrides must leave these
objects and their semantic hashes unchanged; OFFICIAL overrides and base-version
mismatch must reject. No persisted Official leaderboard is recalculated.

Runtime request/storage/cache/producer isolation after new wiring remains
NOT_TESTED. The same applies to new scoring policies, real PIT/OOS, 13F-derived
profiles, publication and migration. Tests do not create a new evaluator.

Metadata tests reject activation, QualityState as confidence/coverage, non-finite
JSON, naive times, false source-hash shape, future timestamps and missing required
PIT refs. Hash shape is not source authentication. Test-only ELIGIBLE examples
verify the time boundary, not actual real provenance. Date-only periods retain
precision; date-only availability is not silently admitted.

## Stop and later validation

This phase stops with spec, cases and neutral checks. Later approved migration
must retain the old calculation version and compare unchanged-case outputs first,
then separately report every intentional delta with its approved policy ID,
affected cohorts/consumers, rank effects, PIT coverage and rollback/version plan.
Real PIT/OOS is a pre-promotion gate; CAL_VERIFY/Holdout, Official, publication,
canonical merge and production deployment remain separately authorized actions.
