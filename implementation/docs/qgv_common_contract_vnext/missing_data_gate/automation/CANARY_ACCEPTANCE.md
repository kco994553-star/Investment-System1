## Real execution verification

Each hop receipt must include an actual platform execution identifier and
readback evidence, fresh remote refs, lease refs/token, fingerprint, validator
path/hash, accepted output paths/hashes and execution disposition. A local UUID,
manual run token, enabled automation or last_run_time alone does not prove the
two-hop chain. If platform run evidence is unavailable, tasks may produce useful
accepted D1/D2 artifacts but AUTONOMOUS_CONTINUATION_VERIFIED remains withheld.
Only independently authenticated distinct scheduler runs plus exact HOP1→HOP2
output binding and protected-byte preservation can receive that verdict.
