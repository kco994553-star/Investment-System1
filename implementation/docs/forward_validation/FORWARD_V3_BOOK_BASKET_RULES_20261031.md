## 4. SEC PIT + IEX 계산 가능성·식·결측

판정 `CONDITIONAL`은 필요한 원본/매핑을 확보하면 가능하다는 뜻이며 현재 전종목 자료가 준비됐다는 뜻이 아니다. 책 지표는 QGV V 요인과 별개다. 예: QGV의 FCF/EV를 책 PCF로 대체하면 안 된다.

**PIT 규칙:** 결산일이 아닌 최초 이용 가능 공시시각으로 자른다. accession·accepted_at·기간·단위·원본 hash를 비공개 입력 manifest에 남긴다. 수정 공시/후대 비교수치는 그 공개일 이전에 사용하지 않는다. 현재 companyfacts의 최신값만 읽어 과거를 채우면 PIT가 아니다. 시각 없이 filed 날짜만 있으면 해당일 다음 세션까지 보수적으로 지연한다.

**TTM:** 검증된 네 개 비중복 분기를 합산하거나 FY+현재YTD−전년동기YTD로 계산한다. 연간·YTD·분기 중복 합산 금지. 비교 대상 연도/분기·기간길이·통화가 맞아야 한다.

**책 복합 순위의 구체적 근사 제안:** 해당 전략의 모든 필수요소가 유효한 공통집합만 사용한다(VC1=5/5, VC2/3=6/6). 요소별 좋은 방향으로 오름순 midrank r, n≥2에서 p=1+99(r−1)/(n−1). 요소 p의 산술평균이 작을수록 좋다. 최종 동점은 영구 증권 ID 오름순. 결측을 0·50·최악순위로 채우지 않는다. 원서의 결측 50점 부여·음수값 처리와 다를 수 있어 **완전사례 근사**로 버전 고정한다. 각 결측 사유/숫자·전체 대비 적격 비율 보고. 금융/ADR 제외로 생기는 선택편향도 명시한다.

**총점 적격안:** Q·G·관문 적용 전 V 세 축 유효, total 유효, 동일 calc_version. 각 축 내부 요인 결측은 기존 50% 엔진 규칙을 그대로 두고 요인 수/가용 가중치를 표시한다. V 관문으로 총점에서 V가 빠지는 종목은 엔진 동작 그대로 허용하고 gate 사유를 기록한다. V 원자료가 없어 QG만으로 산출된 total은 이 QGV 바구니에서 제외한다. 이 적격조건은 기존 엔진 수정이 아니라 연구 바구니 제안이다.

**축별:** V 하위군에서 가치함정 관문 탈락을 통째로 빼면 비교편향이 생긴다. 저장소가 제공하는 독립 V 축점수(gate 전)를 쓰고 gate 상태는 별도 기록한다. Q/G/V 최상·최하 모두 같은 축의 동일 E_A에서 선정한다. 축간 공정 비교를 위해 추가 실행 없이 공통 교집합 규모도 보고한다.

**프리셋:** 저장소의 공식 balanced=34/33/33과 사용자 balanced=40/30/30을 분리한다. 공식 보관본에 다른 프리셋 총점이 없다면 공식 총점을 복사하지 않는다. 보관 요인으로 파생한 점수는 `DERIVED_FROM_ARCHIVE`(점수 산출 방식)로 기록하며 원래 공개 점수라고 표시하지 않는다. 필요한 원지표가 없으면 비활성화. 유형가중/관문 적용 후 실효 가중치는 단순 축 가중치와 다르므로 같은 엔진 호출로 계산한다.

**업종중립의 제약:** 모든 종목 1/N과 업종 노출의 정확한 일치는 정수 종목 수 때문에 일반적으로 불가능하다. 제안은 E의 업종별 비중 n_s/n을 목표로 m개를 최대잔여법 배정(floor(m n_s/n), 남은 칸은 소수부 내림·업종ID 동점)한 뒤 각 업종 총점 상위 k_s 선정. 업종 분류는 저장소 SIC 업종군 버전 고정. 분류 NA는 이 바구니에서 제외, 별도 제외수 보고. k_s=0인 작은 업종도 그대로 기록. 실제 비중−목표 비중을 보여 주며 라벨은 **업종 비중 근사 중립**. 같은 E의 동일가중 업종비중이 기준이지 SPY 시총비중이 아니다. 정확중립을 원하면 종목 동일가중 조건 변경 승인이 필요하다.

**규모:** 당시 종류별 시총만 사용. 오늘 시총·유동시총·EPS용 평균 주식수로 대체 금지. Universe504 안 중형 n<100이면 표본부족으로 비활성화, 작은 집단을 임의확대하지 않는다. 확장 모집단 적용은 별도 universe_version 승인 뒤다.

- 파서 처리량·날짜별 실제 GB·캐시 적중·실패 재시도·유효 기호 수를 먼저 소규모 측정해야 한다. 본 문서에서는 수집/워크플로를 실행하지 않았다.

### 원장 계약 초안

공개 원장에는 종목별 가격·EV·배율·종목별 수익률·역산 가능한 수량/평가금액·가격 해시를 넣지 않는다. 종목별 계산 중간값/회사행동/구성원 감사 자료는 기존 승인된 비공개 경로에 둔다. 바구니 원장만 중앙에서 계산한다.

- 비공개 rule manifest: series_id, rule_version, approval_ref, source_commit, calc_version, preset/type/gate 버전, universe_version/hash, source_kind, score_derivation, 입력 sha256, cutoff, available_at, 재선정일, 비공개 구성원 manifest 참조.
- 바구니 일별 행: series_id, date, 상태, 구성수/예정수, 가격coverage, 현금비중, 비용기준, 일별/누적 수익률, NAV 지수, benchmark_id, 수정참조. 사유코드 필수, 불가 수익은 null.
- 파일구성 제안: 작은 index/manifest + 연도·월별 일별 바구니 JSONL 분할. 기존 원장 경로 아래에서 Main이 실제 이름 결정, 신규 최상위 폴더 만들지 않음.
- 제한 제안: index 256KiB, shard 2MiB 초과 전 분할, 화면은 선택 계열/기간 지연읽기. 총보존 상한으로 과거 삭제 금지. 40계열×252일×행당0.5~1KiB ≈ 연5~10MiB(미압축 가정). 기존 가드 한도 변경은 구현 승인 범위에서 별도 검증.
- v1/v2 과거 바이트 불변. 이관 뒤 새 PRIMARY/성공 집계·신선도 기준은 v3만 검사하되, 구원장은 마지막 동결일/hash 보존 검사로 전환(Main 구현·검증).
- 실제 규칙 승인·입력 검증 없이는 RESERVED_DISABLED를 PRIMARY 성공 자료로 세지 않는다.

### 화면9.2

누적수익률·MDD 함께, D1−D10 및 Q1−Q5 누적수익률 차이는 **퍼센트포인트**로 표시(공매도 손익 아님). 기준 대비는 같은 기간 누적수익 차이와 상대부 지수 `(1+R_basket)/(1+R_benchmark)-1`를 다른 이름으로 구분한다. 버전·보관/재구성/실시간·가격/총수익·비용·유효 관측수·분모/결측률을 함께 표시한다.

**“판단에 기간 부족” 제안:** 동일 series에서 유효252거래일 미만 또는 완결된 연간 보유기간1회 미만이면 표시. 1~3년은 “초기 관측”, 3년 이상이어도 “검증 완료” 자동표시 금지. 기간 길이는 통계적 유의성 증거가 아니다. 중단/누락/룰 변경 시 세그먼트별 다시 셈. CAGR은 1년 미만 미표시. 다수 바구니 중 승자만 골라 성과 주장하지 않고 전체 후보 수와 미실행 수 공개.
