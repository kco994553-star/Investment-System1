 제1장 총칙
 제1조(목적)
 한국은행 경제통계 Open API 이용약관(이하 “본 약관”이라 한다)은 한국은행이 제공하는 경제통계 Open API 서비스 이용과 관련하여 한국은행과 이용자가 준수하여야 할 사항을 정하는 것을 목적으로 합니다.
 제2조(용어의 정의)
 본 약관에서 사용하는 주요 용어의 정의는 다음과 같습니다. 정의되지 않은 것은 관련 법령이나 기타 일반관례에 따릅니다.
 1. “Open API 서비스” 라 함은 한국은행 경제통계시스템(이하 “ECOS”)에 수록된 통계정보를 이용자들이 자유롭게 이용할 수 있도록 한국은행이 제공하는 서비스를 말합니다.
 2. “제공기관” 이란 본 약관에 따라 통계정보를 제공하는 한국은행을 말합니다.
 3. “이용자” 란 제공된 공유서비스를 직접 이용하거나 새로운 창작물의 일부로 재가공하여 배포하는 자를 말합니다.
 4. “통계정보” 란 ECOS에 수록된 통계데이터 및 통계설명자료 등을 말합니다.
 5. “통계작성기관” 이란 ECOS에 수록된 통계를 작성하여 공표하는 기관으로서 해당 통계에 대한 저작권을 보유하고 있는 기관을 말합니다.
 제3조(효력)
 ① 본 약관은 이용자가 Open API 서비스 이용을 위하여 본 약관을 읽고 동의하는 의사표시를 함으로써 효력이 발생합니다.
 ② 제공기관은 필요한 경우 본 약관을 개정할 수 있으며, 이 경우 일정한 기간을 정하여 적용일자 및 변경사유를 명시한 사항을 공지하거나 전자우편 등의 방법으로 이용자에게 통지합니다.
 ③ 약관의 변경 사실 및 내역을 확인하지 못하여 발생한 손해에 대한 모든 책임은 이용자에게 있습니다.
 제2장 이용 방법, 조건 및 절차
 제4조(제공방법)
 ① Open API 서비스 이용을 희망하는 자는 제공기관에 Open API 서비스 인증키를 신청하여야 합니다.
 ② 제공기관은 약관 동의 등 일정 요건을 갖춘 Open API 서비스 신청자에게 인증키를 부여하며, 이용자는 선량한 관리자의 주의의무를 다하여 인증키를 관리하여야 합니다.
 ③ Open API 서비스의 이용기간은 제공기관이 인증키를 발급한 날부터 2년으로 하며, 이용기간 만료 전에 이용자의 연장요청이 있는 경우 2년 단위로 연장할 수 있습니다.
 제5조(통계정보의 상업적 이용)
 ① 이용자는 통계정보를 상업적으로 이용할 수 있습니다. 다만 상업적인 이용을 제한하는 통계정보를 상업적인 목적으로 이용하고자 하는 경우에는 해당 통계 작성기관의 승인을 받은 후에 이용하여야 하며, 승인 없이 상업적 용도로 무단 복제하거나 배포하는 행위는 저작권법에 의해 처벌될 수 있습니다.
 ② 이용자가 Open API 서비스를 이용하여 영업활동을 하는 경우 제공기관은 그 결과에 대하여 일체의 책임을 지지 않습니다.
 제6조(서비스 제한)
 ① 제공기관은 다음 각 호의 어느 하나에 해당하는 경우 이용자에게 사전 공지 후 Open API 서비스 제공을 일시적으로 중단할 수 있습니다. 다만 부득이한 경우에는 예고 없이 서비스를 중단할 수 있습니다.
   1. 시스템 정기점검, 증설 및 교체의 경우
   2. Open API 서비스에 기술적 결함이 발견되는 경우
   3. 신규 Open API 서비스를 추가하는 경우
   4. 이용자의 과다 호출 등으로 시스템에 문제가 발생하는 경우 등
 ② 제공기관은 다음 각 호에 해당하는 경우 Open API 서비스 제공을 중단할 수 있으며, 법적 조치를 포함한 필요한 조치를 취할 수 있습니다.
   1. 속임에 의한 이용자 사칭
   2. 바이러스ㆍ웜 등 악성코드의 전파
   3. 저작권 위반이나 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」의 불법정보 등과 결합 또는 연계 이용
   4. Open API 연결방식의 위ㆍ변조
   5. Open API 인증키의 양도, 증여 및 담보 목적물 사용
   6. 접근이 허용되지 않는 범위에 접근을 시도하는 행위
   7. 이용자가 관련 법령 또는 본 약관을 위반한 경우 등
 제7조(이용자의 의무)
 ① 이용자는 Open API 서비스를 이용함에 있어서 관계 법령 및 본 약관에서 규정하는 사항과 ECOS 홈페이지에 있는 「통계정보 이용지침」 등을 준수하여야 하며, 제공기관의 업무에 방해가 되는 행위 또는 제공기관의 명예를 손상시키는 행위를 해서는 안됩니다.
 ② 이용자는 통계정보를 이용하는 경우 ECOS에서 제공된 정보임을 표시하여야 합니다.
 제8조(이용 변경 및 해지)
 ① 이용자는 성명이나 연락처(전자우편 주소 포함)가 변경된 경우에는 이를 제공기관에 즉시 통보하여야 하며, 변경내용을 통보하지 않아 발생하는 손해에 대하여 제공기관은 일체의 책임을 지지 않습니다.
 ② 이용자는 Open API 서비스 이용을 원하지 않는 경우 이용해지 의사를 제공기관에 통보하여야 합니다.
 제3장 기타
 제9조(면책)
 ① 제공기관은 이용자가 본 약관의 내용을 준수하지 않아 발생한 손해에 대하여 일체의 책임을 지지 않습니다.
 ② 통계정보는 ECOS에 수록된 내용을 그대로 제공하며, 제공기관은 통계정보에 포함된 오류나 누락, Open API 서비스 장애 등으로 인한 손해에 대하여 책임을 지지 않습니다.
 ③ 제공기관은 이용자와 제3자간에 Open API 서비스를 매개로 발생한 분쟁에 대하여 개입할 의무가 없으며, 이로 인한 손해배상책임도 없습니다. 만일 이용자와 분쟁 중인 제3자가 제공기관을 상대로 이의를 제기할 경우 이용자는 제공기관을 자신의 비용과 책임으로 면책시켜야 합니다.
 ④ 제공기관은 관련 법령에서 정하는 사항 외에 통계정보와 관련된 진술, 보증, 의무, 책임을 부담하지 않습니다.
 ⑤ 제공기관은 통계정보의 계속적 제공 또는 추가되는 통계정보의 지속적 제공을 보장하지 않습니다.
 제10조(개인정보의 수집 등 관리)
 ① 제공기관은 정보의 원활한 제공을 위하여 다음 각 호의 개인정보를 수집할 수 있습니다.
    1. 성명, 소속단체명(생략 가능)
    2. 전자우편주소
    3. 연락처
 ② 이용자의 개인정보는 본인의 승낙 없이 타인에게 누설, 배포하지 않습니다. 다만, 전기통신관련법령 등 관계법령에 의하여 관계 국가기관 등의 요구가 있는 경우에는 그러하지 않습니다.
 ③ 제공기관은 이용자가 개인정보의 수집 및 이용에 대한 동의를 철회하거나 수집 및 이용목적이 달성되거나 보유 및 이용기간이 종료한 경우에는 해당 개인정보를 지체 없이 파기합니다. 다만, 「공공기록물 관리에 관한 법률」 등 다른 법령에 따라 보존하여야 하는 경우에는 그러하지 아니합니다.
 제11조(재판관할 등)
 ① Open API 서비스 이용과 관련하여 제공기관과 이용자 사이에 분쟁이 발생한 경우 제공기관과 이용자는 발생한 분쟁을 원만하게 해결하기 위하여 필요한 모든 노력을 하여야 합니다.
 ② 제1항에도 불구하고 제공기관과 이용자 간에 발생한 분쟁에 대하여 소송이 제기될 경우 관할법원은 제공기관의 본부 소재지(서울 중구 남대문로 39)를 관할하는 법원으로 합니다.
 제12조(규정의 준용)
 본 약관에 명시되지 않은 사항에 대하여는 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」, 「공공기관의 정보공개에 관한 법률」, 「저작권법」, 「콘텐츠산업진흥법」 등 관련 법령 및 「공공정보 제공지침」에 따릅니다.
