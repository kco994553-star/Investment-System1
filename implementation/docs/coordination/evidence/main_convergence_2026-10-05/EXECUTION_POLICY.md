# Main Verification & Execution Acceleration Policy v1.0

User-directed operating summary recorded at an existing safe checkpoint on2026-10-05. This is a faithful operational summary, not a verbatim copy of the user message. Existing architecture, owner work and D1/D2 authority continue; CDR-016§13/CDR-017/CDR-018 protected boundaries remain.

Main owns coordination, authorized implementation/repair, blocker closure, integration and canonical-candidate preparation. QGV Audit, Platform Audit, Chart Audit and Claude Independent Monitor retain their specialist roles. Main does not absorb those roles.

| Lane | Default verification | Current application |
|---|---|---|
| FAST | targeted deterministic test; affected checks only for real dependencies | docs/routing, UI/fixtures/additive metadata/tooling |
| STANDARD | targeted + relevant negative + affected regression + bounded integration; at most1 independent verifier | ordinary Product API, adapters, Sync/Web/producer integration |
| CRITICAL | fail-closed hard gate, targeted/negative/adversarial and independent verification proportionate to actual risk; affected/full when justified | FPIA, PIT/Frozen/Holdout/Official, QGV/TrackC methodology, financial integrity/numeric policy, Auth/Tenant/read-only/secrets and canonical semantics |

Reuse exact source/tree-bound specialist evidence as AUDIT_VERIFIED_EXTERNAL only with clear scope, tests/results, compatibility and no related drift. Verify integration compatibility; do not repeat the same audit. No default completeness agent, adversarial panel or full repository suite for FAST/STANDARD. Default1 owner, optional+1 verifier;3+ only for justified CRITICAL/multiple expert conflicts or ambiguity. Valid owner work is not cancelled.

Full regression is justified by CRITICAL/shared-core change, integration/canonical/release milestone, unbounded affected scope or unexpected failures. Reuse valid unchanged-input evidence. Tool failure gets bounded retry/fallback/NOT_RUN; optional tool targets do not block independent work. No guessed service/project, backend replacement or deployment approval.

Track scoped blockers start/closed/new/net; completed implementation/integration/verification, audit-only findings, wait/block time and user interventions. Net blocker reduction counts actual closure, not findings or comments. Rough60% implementation/integration,30%verification,10%audit/docs is guidance, not a time quota. FAST compact evidence, STANDARD bounded handoff, CRITICAL/milestone full provenance.

D1/D2 owner work completes implementation, repairs, tests, evidence and eligible dependent work without step approvals. Only actual D3 interrupts: protected semantics/contracts, PIT/Frozen/Holdout/Official, QGV methodology/financial numeric policy, credentials/production auth/paid resources, canonical merge or irreversible action. Parallelize independent scopes only; never duplicate one blocker. Preserve all protected quality floors and trade/order/fund-transfer prohibition.
