# 기존 프런트엔드 연결 통합 — 2026-10-21

확인 2026-10-21 07:50 UTC / 16:50 KST. PR #372, branch `codex/frontend-links-20261021`. 아래는 로컬 구현/검증이며 최종 CI·병합·배포·실사이트 확인은 CURRENT_HANDOFF의 최신 증거를 따른다. 18쪽 시안은 미확보, 6쪽 원본만 이미지로 열람했다. 새로운 화면 구도를 추정하지 않았다.

## 최종 동작과 경계

- 1.1 기업검색: 검색한 비지원 기술 기업도 ID와 사유를 유지한다. ASML로 대체하지 않는다. 기업/관심 목록별 탐색 입력·더 보기 개수는 탭 RAM에 보관한다. 상세에서 원래 목록 복귀 때 스크롤·포커스·커서를 복원한다. 새로 변경한 그룹 설정을 옛 DOM 값으로 덮지 않는다. 홈 관심 뉴스는 공개 묶음 성공 적용/시간 재판정 뒤 갱신하며 활성 검색·입력 중 상태는 유지한다. 실패는 이전 묶음과 피드를 보존한다.
- 2.1 리더보드: 게시된 SIC 그룹과 기존 기업 유형 memberships로 표시 행만 AND 필터링한다. Universe504 공식 모집단·점수·순위·모델과 QG 참고 목록 구분은 유지한다. 분류 누락/선택 유형 불일치/철회를 구분하고 사라진 선택을 전체로 자동 확장하지 않는다. N10/15/20 모델 참고로 연결하지만 TARGET 확정으로 표현하지 않는다.
- 3.1~3.3 기술: 같은 기업의 차트/패턴/노트 이동은 기존 차트 RAM을 유지한다. 다른 기업·화면·로그아웃의 dispose는 유지한다. 패턴/노트 링크는 실제 패널로 이동한다. 합성 봉으로 상태 유지를 시험했으며 실가격/기업행사 검증이 아니다.
- 4.1 및 기존 매크로 하위: 근거를 경기·시장 영역 안에 두고 산업/개인/경기 메뉴를 실제 탭·패널로 연결한다. 모델 없는 공식 국면·확률은 미산출이다. 개인 추정은 공식 관측과 분리한다.
- 7.1 프롬프트: 마지막 명시적 공개 기업 선택만 RAM으로 전달한다. 같은 origin/source 메시지 검사와 공개 identity projection을 유지하며, 알 수 없거나 모호한 선택은 이전 기업으로 대체하지 않는다. 기존 프롬프트의 company/ticker 또는 seed_company/seed_ticker 칸에서 사용자가 명시적으로 가져온다. 둘 중 하나라도 입력돼 있으면 둘 다 보존한다. 기간은 의미 매핑이 없어 수동 입력한다. 입력을 부모/계정/AI로 전송하거나 새 초안 저장을 추가하지 않는다. Frozen catalog 불변.
- 9.1/9.2 Lab: 이미 구현된 백테스트/전진검증 설명·패널로 메뉴를 연결한다. 운영 실험/실가격 재생 완료로 표시하지 않는다.

Main 통합 소스는 nav adb12d04, QGV 57ec02dc, search a5ad8cc0, prompt b05f06f5 및 Main app 연결이다. 공용 app/guard/CI는 Main만 수정했다. 독립 리뷰 파일은 작업 공간에 보존하며 필요한 재현 명령은 각 CI registry와 전용 시험에 있다. 실제 배포 완료 뒤 새 컨텍스트에서 저장/새로고침/검색 흐름과 승인 글꼴·가로 넘침을 확인해야 한다.
