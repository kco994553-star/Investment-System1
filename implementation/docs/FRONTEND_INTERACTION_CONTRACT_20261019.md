## 3. 조작 × 갱신

### 3-1. 새 자료가 들어오는 세 길

1. **자료 새로고침 버튼**(S6): 같은 탭에서 공개 묶음을 다시 읽는다(계약 §2-3 R).
2. **시간 경계 재판정**: 새 게시본 없이도 파일마다 자기 기준(행 acquired_at 또는 파일 as_of + stale_after_seconds)을 지나면 1분 주기·탭 복귀·화면 이동 때 상태를 다시 판정한다. **사용자 조작 없이 일어난다**(`data-refresh.js:31-35,125-158`).
3. **페이지 새로고침(F5)·새로 열기**: 모든 RAM이 비워진다.

소유자 후속(2026-10-19, 코디네이터 전달): 첫 화면 기본은 **근거에 기반한 추정 구간** 표시다. 국면 순서 링 위에 강조한 호(예: "확장 후반~둔화 초입")와 찬성·반대 근거선, 기준 시각을 보인다. 모델이 판정하지 않으면 "판정 유보"와 사유를 쓴다. 링 위 정확한 점 좌표와 검증 안 된 확률은 없다. 경기·주식시장·산업 사이클은 서로 다른 화면·모델이다. 순환 회전(스와이프·키보드)은 아래 명세대로다.

### 4-1. 2026-10-19 작성 당시

- 3.1~3.3은 NA 절뿐이다(`ia-screens.js:225-231`). 그림·위치·확률을 그리지 않는다. 메뉴는 "준비 중"이다(`app-shell.js:33-38`).

- app_nav_ia는 이 절에 `svg`·`canvas`가 없음을 검사한다(`app_nav_ia_browser_test.js:101`).
- 국면 모델 초안은 병렬로 작성 중이다: 브랜치 `claude/macro-phase-model-draft`의 [MACRO_PHASE_MODEL_DRAFT_20261019](macro/MACRO_PHASE_MODEL_DRAFT_20261019.md). 이 문서를 쓸 때 원격 브랜치는 아직 없었다. 그 초안이 병합되기 전까지 이 링크는 열리지 않는다. 이 문서는 모델 내용을 되풀이하지 않는다. 구간·근거·유보의 **정의는 그 초안**을, **화면 표시는 이 문서**를 따른다.
- 매크로 경고등의 참고 모드와 재가동 승인 조건은 바꾸지 않는다(계약 §3-3, `macro-lights.js` 참고 표시).

### 4-3. 원칙

1. **축은 국면 순서다. 달력 시간이 아니다.** 링의 칸은 어휘 순서대로 시계 방향으로 놓는다.
2. **링 바탕은 개념도다**(계약 §5 "교육용 개념도" 층). 링에 "개념도 · 국면 순서"라고 적는다. 그 위의 추정 구간 호만 "시스템 추정" 층이다.
3. **순환은 둘러보기 순서일 뿐이다.** 실제 경기·시장이 이 순서로만 움직인다는 뜻이 아니다. 국면은 건너뛰거나 되돌아갈 수 있다. 링 아래에 이 문장을 둔다.
4. **추정은 구간(호)으로만 보인다. 점이 아니다.** 호의 시작·끝은 게시된 모델 출력의 구간 경계를 그대로 쓴다(예: "확장 후반~둔화 초입"). 국면 안 세부 단계(초입·후반 등)의 어휘와 개수는 모델 초안이 정한다. 화면은 경계를 칸 안 위치로 옮길 뿐 새 경계를 만들지 않는다. 호 안의 한 점(가운데·무게중심)을 따로 표시하지 않는다.
5. **세 가지 상태를 구분한다.**
   - 추정(ESTIMATED): 호 + 구간 글자 + 근거선 + 기준 시각 + 모델 id·버전.
   - 판정 유보(ABSTAINED): 모델은 돌았지만 판정하지 않음. 호를 그리지 않는다. "판정 유보 · 사유"와 찬성·반대 근거선을 보인다.
   - 미산출(NOT_COMPUTED): 승인된 모델 출력이 없음. 호를 그리지 않는다. "미산출 · 사유"(예: "위치 판정 모델 없음")를 쓴다.
   - 가짜 호·예시 호·"추정 중" 호를 그리지 않는다.
6. **근거선은 찬성·반대를 나란히 둔다.** 근거선마다 지표 이름, 관측 기간, 발표 시각(없으면 "수집 시각 기준(상한)", IA-16), 수집 시각, 출처를 쓴다. 근거 목록은 모델 출력에서만 온다.
7. **검증 안 된 확률은 없다.** 전환 문구는 결정된 근거 규칙(과거 국면 전환 빈도)을 Lab에서 검증한 뒤에만 쓴다. 형식: "이 국면에서 ○○로 넘어간 과거 비율 k/n · 기간 YYYY-MM~YYYY-MM · 표본 n회 · 규칙 id·버전". 기간이나 표본 수가 하나라도 없으면 "전환 비율 미산출"이다. 자료 신뢰도를 확률로 바꾸지 않는다.
8. 화면은 계산하지 않는다. 게시된 출력만 읽는다(계약 §5 "위치 규칙·버전·근거·불확실성은 한 묶음으로 게시").
9. 경기 링·시장 링·산업 링은 따로 그리고 따로 상태를 가진다. 한 링의 구간을 다른 링에 옮겨 쓰지 않는다.

### 4-4. 구조

- 링 1개 = 어휘 N칸(경기 4, 시장 4). 칸 = 원호 + 국면 이름.
- **추정 구간 호**: 링 바깥 띠에 강조색으로 그린다. 구간이 마지막 칸에서 첫 칸으로 넘어가면(예: "회복 후반~확장 초입") 호도 경계를 넘어 이어 그린다. 호 옆에 글자로 "추정 구간: 확장 후반~둔화 초입 · 모델 id 버전 · 기준 as_of"를 쓴다. 색만으로 뜻을 전하지 않는다.
- **근거 칸**: "찬성 근거"와 "반대 근거" 두 목록. 각 줄에 §4-3 6의 필드. 3.1에서는 근거선 그래프(실제 관측, 발표 시각 세로선)로 이어지는 링크를 둔다.
- **초점 국면**: 사용자가 돌려서 맨 위(12시)에 온 국면. "보는 국면"이라고 부른다. 추정 구간과 다르다.
- **상세 칸**(초점 국면): 국면 설명, 전환 문구(§4-3 7), 상향·유지·하향 조건 3칸("기준 미정"), 이 국면이 추정 구간에 걸치는지 여부.
- **내 위치**(3.4): 보라색 펜. 저장 결정 전에는 만들지 않는다.
- **◀ ▶ 버튼**: 늘 보인다. 제스처를 몰라도 돌릴 수 있다.
- **(선택) 띠 보기**: 소유자 예시의 "옆으로 움직이는 반복 그래프". 링을 펼친 반복 띠다. 같은 초점 상태와 같은 추정 구간을 쓴다. 띠를 끌면 링이 돈다. 처음·끝 칸을 하나씩 더 그려 이어 붙이고, 넘어가면 반대편으로 옮겨 끊김 없이 이어지게 한다. "개념도 · 높이는 뜻 없음"이라고 적는다.

### 4-5. 조작 — 순환(끝이 없음)

- 규칙: 초점 칸 번호 `i' = (i + d + N) mod N`. `d`는 +1(다음) 또는 −1(이전).
- **마지막 국면 다음은 첫 국면이다. 첫 국면 이전은 마지막 국면이다.** 가장자리에서 멈추지 않는다.
- **가로 스와이프·끌기**(포인터 이벤트 하나로 마우스·터치·펜 모두):
  - 왼쪽으로 밀면 다음 국면(시계 방향), 오른쪽은 이전.
  - 끄는 동안 링이 손가락을 따라 돈다. 추정 구간 호도 링과 함께 돈다(링에 붙어 있음). 놓으면 가까운 칸에 맞춘다.
  - 한 번에 여러 칸을 끌면 여러 칸을 돈다. N칸을 넘어도 계속 순환한다.
  - 움직임이 작으면 누름으로 본다. 칸으로 넘어가는 기준은 UI 상수다(제안: 칸 각도의 1/3). 방법론 값이 아니다.
  - 세로 움직임은 페이지 스크롤로 넘긴다(링에 `touch-action: pan-y`). 세부 메뉴 줄·표의 가로 스크롤과 겹치지 않게 링 영역 안에서만 받는다.
  - 휠로 돌리지 않는다(페이지 스크롤을 빼앗지 않음).
- **회전각은 누적한다.** 화면 각도 = 누적 각도, 칸 번호 = 누적 칸 수 mod N. 그래서 마지막→처음은 앞으로 한 칸(+360/N도)만 돈다. 거꾸로 한 바퀴(−(N−1)·360/N도) 되감지 않는다.
- **칸 누르기**: 그 칸을 맨 위로 돌린다(가까운 방향).
- **키보드**: 칸들은 탭 목록이다(`role="tablist"`, 칸 `role="tab"`, 상세 칸 `role="tabpanel"`, 초점 칸만 `tabindex=0`). 분석 탭(`company-screen.js:297-301`)과 같은 방식이다.
  - → / ↓: 다음(순환). ← / ↑: 이전(순환). Home: 어휘 첫 국면. End: 어휘 마지막 국면.
- **움직임 줄이기**(`prefers-reduced-motion: reduce`): 회전 애니메이션·관성 없이 바로 바뀐다. 기존 선례 `stat-radar.css:61`, `theme.css:521`.
- **화면 읽기 프로그램**:
  - 링 그림: `role="img"`, `aria-label` 예 "경기 국면 개념도 · 4개 국면 · 보는 국면 확장(1/4) · 추정 구간 확장 후반~둔화 초입" 또는 "· 판정 유보" / "· 미산출".
  - 칸 이름: "둔화 · 2/4", 추정 구간에 걸치면 "· 추정 구간에 포함".
  - 바뀔 때 알림(`aria-live="polite"`): "보는 국면 둔화(2/4)". 순환할 때 "회복 다음은 확장 · 처음으로".
  - 근거 목록은 링 그림 밖의 보통 목록이다(그림 속 글자에만 두지 않음).
  - 돌려도 포커스는 조작한 칸·버튼에 남는다.

### 4-7. 새 게시본 반응

- 추정 구간 호는 게시된 모델 출력을 따른다. 새 게시본에서 구간이 바뀌면 호가 옮겨지고 길이가 바뀐다. 움직임 줄이기 설정이면 바로 바뀐다.
- 상태가 바뀌면(추정 → 판정 유보, 판정 유보 → 추정 등) 호를 지우거나 그리고, 상태 글자와 사유를 바꾼다.
- **권장: 회전 상태(초점)는 보존한다.**
  - 처음 열 때 초점 = 추정 구간의 첫 국면(있으면) 또는 어휘 첫 국면. 사용자가 아직 돌리지 않았으면 초점이 구간을 따라간다.
  - 사용자가 한 번 돌렸으면 새 게시본에서도 초점을 그대로 둔다. 호만 바뀐다.
  - 이유: 리더보드 정렬·프리셋처럼 새로고침이 사용자의 탐색을 지우지 않는다(§3-3과 같은 원칙).
  - 알림: "추정 구간 바뀜: 확장 후반~둔화 초입 → 둔화 · 기준 as_of 이전 → 이후"(live 영역 + 배지). "추정 구간으로" 버튼으로 초점을 구간 첫 국면에 맞춘다.
  - 예외(초기화): 어휘 버전이 바뀌어 칸 수가 달라지면 초점을 구간 첫 국면 또는 어휘 첫 국면으로 되돌리고 알린다.
- 보관 위치: 모듈 RAM에 링별 키(`economy`, `market`, `rotation`, `industry:<industry_group>`)로 둔다. 스탯창 `live`(`stat-radar.js:437`)·리더보드 `OPEN`과 같은 방식이다. 같은 탭 편의로 sessionStorage에 비춰 둘 수 있다(try/catch, 실패하면 RAM만). 매크로는 전체 다시 그리기 화면이라(§3-2) DOM에 두면 지워진다.
- 3.3 고른 그룹이 새 게시본에 없으면 선택을 비우고 "고른 업종 그룹이 새 게시본에 없음"을 쓴다.
- 새 게시본에 모델 출력이 없거나 철회되면 호를 지우고 "미산출 · 사유"를 쓴다. 옛 호를 현재처럼 남기지 않는다.
- 자료 새로고침이 실패하면 계약 §2-3대로 묶음 전체를 바꾸지 않는다. 호와 기준 시각은 옛 것 그대로이고 막대가 "갱신 실패"를 쓴다.
- 지난 추정은 추가만 한다. 새 규칙으로 과거 추정을 다시 쓰지 않는다(계약 §4, §5).

### 4-8. 이것을 증명할 시험 (제안: `macro_cycle_ring_browser_test.js`, 390·1280 두 폭)

1. **끌기 순환 마지막→처음**: 마지막 국면에 초점. 왼쪽으로 한 칸 넘게 끈다(1280: `page.mouse`, 390: `hasTouch` 맥락의 포인터 이벤트). 초점 = 첫 국면, `aria-selected`, live 문구 "처음으로".
2. **끌기 순환 처음→마지막**: 오른쪽으로 끈다. 초점 = 마지막 국면.
3. **키보드 순환**: 마지막에서 → = 첫 국면. 처음에서 ← = 마지막. Home·End.
4. **버튼 순환**: ▶ 를 N번 누르면 제자리. 2N번도 제자리.
5. **되감기 없음**: 마지막→처음 때 누적 회전각이 +360/N도만 바뀐다.
6. **세로 스와이프는 회전하지 않는다**: 링 위 세로 끌기 뒤 초점 그대로, 페이지가 스크롤됨.
7. **모델 없음 = 가짜 구간 없음**: `[data-cycle-interval]` 0개, `[data-cycle-state="NOT_COMPUTED"]`와 사유 문구, 전환 칸에 숫자·% 없음. app_nav_ia 101행 검사를 "`[data-cycle-kind=concept]` 그림만 허용, 구간 호 없음"으로 바꾼다.
8. **판정 유보**: 합성 게시본이 유보를 내면 호 0개, "판정 유보"와 사유, 찬성·반대 근거 목록이 보인다.
9. **점 좌표 없음**: 어느 상태에서도 링 위 점 표시 요소가 없다. 추정 상태의 호는 시작·끝 두 경계를 가진 구간이다(`data-cycle-interval`에 시작·끝 속성, 화면 글자 "A~B").
10. **추정 구간(합성 게시본, 경로 가로채기)**: 호 경계와 글자 = 게시값. 경계를 넘는 구간(마지막 칸~첫 칸)도 끊김 없이 그려진다. 찬성·반대 근거마다 관측 기간·발표(또는 수집 상한) 시각·출처가 있다.
11. **새 게시본**: 구간이 바뀌면 호가 바뀌고, 사용자가 돌린 초점은 그대로, 돌리지 않았으면 따라감. 모델 필드가 빠지면 "미산출". 503 실패면 옛 호와 "갱신 실패".
12. **전환 문구 조건**: 기간·표본 수가 다 있고 검증 표식이 있을 때만 숫자. 아니면 "미산출".
13. **움직임 줄이기**: `emulateMedia({reducedMotion:'reduce'})`에서 전환 시간 0.
14. **폭**: 두 폭 모두 가로 넘침 없음. ◀ ▶ 가 보임.
15. **자료 새로고침·경계 재판정 뒤 초점 유지**: 매크로는 전체 다시 그리기 화면이므로 꼭 확인한다.
16. **분리**: 경기 링을 돌려도 시장 링·산업 링의 초점·구간은 그대로다.

### 4-9. 지금 만들 수 있는 것 vs 소유자 결정이 필요한 것

**지금 만들 수 있다(방법론 결정 없이):**

- 링 부품 하나(개념도 층): 칸 그리기, 순환 회전(끌기·스와이프·칸 누르기·◀ ▶·키보드), 누적 회전각, 접근성, 움직임 줄이기, 390·1280 배치, RAM 보관, 새 게시본 반응 틀.
- 세 상태(추정·판정 유보·미산출)의 화면 틀: 구간 호 그리기(경계 넘김 포함), 찬성·반대 근거 목록, 기준 시각, 사유 글자. 합성 게시본으로만 시험한다. 실제 화면에서는 모델 출력이 없으므로 "미산출"만 보인다.
- 전환 칸의 "미산출", 조건 3칸의 "기준 미정".
- 3.3 그룹 고르기: 공개 `sec-qgv2.json` 행의 `industry_group` 값에서 목록을 만든다.
- 시험 1~16(8·10·11은 합성 게시본).
- 단, 3.1 링에 칸 이름을 쓰려면 **IA-4 어휘 확정**이 필요하다. 표시 어휘 결정이지 판정 방법론이 아니다. 권장안 (a)가 이미 화면 문구에 쓰이고 있으니 소유자 확인 한 줄이면 된다.
- 화면이 읽을 게시 형식(구간 경계, 상태, 사유 코드, 근거 목록, 모델 id·버전, as_of)은 모델 초안과 맞춰 정한다. 형식이 정해지기 전에는 화면 틀을 합성 형식으로만 시험한다.

**소유자 방법론 결정이 필요하다(그 전에는 "미산출"):**

- 경기·시장 **국면 모델**(입력 계열, 구간 경계 규칙, 판정 유보 조건, 버전, 게시 형식) → 추정 구간. 초안: MACRO_PHASE_MODEL_DRAFT_20261019(병렬 브랜치).
- 국면 안 세부 단계 어휘(초입·후반 등)와 개수. 같은 초안.
- 과거 국면 이력과 **Lab 검증** → 전환 비율의 표본·기간. 규칙은 결정됐지만 계산과 검증이 없다.
- 상향·유지·하향 **조건의 숫자 기준**.
- 3.2 **순환매 칸의 뜻**(업종 그룹을 어느 국면에 놓는가). 이것이 없으면 3.2 링은 칸을 그릴 수 없다.
- 3.3 **산업 사이클 어휘**와 산업 지표·국면 모델. 산업 구성원도 아직 `MEMBERSHIP_NOT_AVAILABLE`이다(IMPACT_PATH b-2).
- 3.1 근거선의 실제 발표 시각(IA-16).
- 3.4 내 위치 저장 위치(IA-6, DRAW-STORE). 방법론이 아니라 저장 결정이다.

이 문서는 어떤 방법론·임계값·국면 순서·구간 경계도 정하지 않는다.
