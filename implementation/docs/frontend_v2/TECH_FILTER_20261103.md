# 1.1.8 기술 조건 필터 (기능 3.5) — 화면과 제안 계약 `tech-screen-v0`

작성 2026-11-03 · Main. 오너 지시 "계층 3 기술적 분석 리더보드 화면"(2026-11-03)에 따른 화면 구현 기록이다. 계산은 Codex, 화면·접근성·운영 통합은 Main(DC-42)이 맡는다. 이 문서의 필드 이름은 **Main 제안**이고, Codex와 합의한 뒤에 확정한다. 이 기록은 비공개 연구값 공개, 병합, 배포 승인이 아니다.

## 1. 화면 흐름 (새 앱 `#/qgv` → 1.1 리더보드 → 1.1.8)

1. **① 평가일 · 비교 그룹**: 파일에 있는 평가일과 그룹(예: U-A, U-B) 중에서 고른다.
2. **② 지표 원값 · 분위**: 지표 카드 5개(3·6·12개월 모멘텀, 6개월 변동성, 6개월 일평균 달러 거래대금). 카드마다 단위·창·기준일·비교 그룹·유효 종목 수(분모/구성원)·중앙값·분위 매김 여부, 그리고 D10의 뜻이 있다.
   - 변동성 D10 = 가장 크게 흔들린 10%
   - 거래대금 D10 = 거래 규모가 가장 큰 10%
   - 모멘텀 D10 = 가장 많이 오른(덜 내린) 10%. 값이 음수일 수 있다.
3. **③ 필터 조합**:
   - 모멘텀은 기간별로 '0% 초과' · '중앙값 이상' · '상위 10% (D10)'.
   - 변동성은 'D10 제외' · 'D10만'.
   - 거래대금은 'D10만' · 'D1 제외'.
   - '기술 조건 적용'을 켜야 표에 적용된다(기본 끔).
4. **④ 결과**: 고른 그룹 안에서 통과·조건 미충족·판정 불가 수를 보여 준다. 표에는 통과한 종목만 남는다. 정렬은 1.1.2 정렬 그대로(기본 QGV 높은 순)이고, 순위 번호와 점수는 바뀌지 않는다.

규칙:
- 분위·중앙값·분모는 **처음 고른 그룹 기준으로 고정**한다. 필터를 더해도 다시 매기지 않는다. 값은 파일에 있는 그대로 쓴다.
- 조건에 필요한 값이나 분위가 없으면 그 조건은 **판정 불가**다. 통과로도 미충족으로도 세지 않고, 그 종목은 표에서 빼고 사유와 함께 따로 적는다. 다른 조건에서 이미 미충족이면 미충족으로 센다.
- 작은 화면: 목록 줄 아래에 핵심 값 한 줄(고른 조건의 지표, 조건이 없으면 모멘텀 6개월)을 보여 준다. '기술 상세'를 열면 지표별 값·분위·분모·관측일·결손 사유가 나온다.
- 기술 지표 값(가격 파생값)은 `[data-ram-price]` 안의 텍스트로만 보여 준다. 속성·저장소·URL·로그에는 넣지 않는다. 화면 상태는 RAM에만 둔다.

## 2. 원천 상태

`IS2.techScreen.source()`는 지금 `NONE`이다. 공개 파일이 없으므로 아무것도 요청하지 않는다. 화면에는 "기술 지표 자료가 아직 없습니다 · 계산은 Codex 인계 뒤 연결 · 비공개 연구값은 공개 화면에 연결하지 않음"이 나온다.

연결 방법은 Codex와 합의한 필드로 정한다. 비공개 결과를 공개 화면에 잇는 것은 별도 승인(`LAB-PUBLISH`과 같은 성격)이 필요하다.

## 3. 제안 계약 `tech-screen-v0` (합의 전)

```
{ schema_version: 'tech-screen-v0', generated_at: ISO(시간대 포함), source_commit: 40 hex, data_status: SYNTHETIC|REAL|MIXED,
  evaluations: [ { as_of: 'YYYY-MM-DD',
    groups: [ { id: 'U_B', label: 'U-B', members: 정수 } ],
    stats:  { <group>: { <metric>: { n_valid, median|null, deciles: bool, reason|null } } },
    rows:   [ { company_id, ticker, groups: [<group>…],
                metrics: { <metric>: { value|null, obs_days|null, expected_days|null, reason|null, decile: { <group>: 1..10|null } } } } ] } ] }
```

- **지표:**
  - `mom_3m` · `mom_6m` · `mom_12m`: 기간 총수익률, 비율
  - `vol_6m`: 일간 수익률 표준편차 연율화, 비율
  - `adv_6m`: 하루 평균 달러 거래대금, USD
- **분위:** 그룹별로 유효값의 오름차순 십분위다. D10이 가장 큰 값이다.
- **검사:** 첫 위반에서 파일 전체를 거부한다. 거부하는 경우는 다음과 같다.
  - null 값에 사유가 없음
  - 분위가 없는 그룹에 사유가 없음
  - 소속이 아닌 그룹의 분위가 있음
  - 분위가 꺼진 그룹에 행 분위가 있음
  - 값이 있는데 분위가 빠짐
  - 값이 없는데 분위가 있음
  - `n_valid` > 구성원 수
  - 관측일 > 예상일
  - 음수 변동성 또는 음수 거래대금
  - 모멘텀 ≤ −100%
  - 사유 코드 형식 위반
- **Codex 확인 요청:**
  - 수익률 기준(배당 포함 여부, 분할 조정)
  - 창 길이(거래일 63/126/252)
  - 거래대금 산식: 종가×거래량 또는 VWAP×거래량. #467의 `vwap_volume`·`close_volume_proxy` 구분과 맞춘다.
  - 그룹 정의(U-A/U-B/C2)
  - 분위 동점 처리
  - 최소 표본 수(합성에서는 10 미만이면 분위 없음)
  - 사유 코드 목록

## 4. 합성으로 검증한 상태 (`tools/web_app_tech_filter_*`)

- **시장 하락일:** 6개월 모멘텀 D10이지만 수익률이 음수인 종목. top10은 통과하고 0% 초과는 미충족이다.
- **변동성 결손:** 'D10 제외'를 판정할 수 없는 종목. 판정 불가로 세고 사유 '원천 가격 자료 없음'을 적는다.
- **모집단 부족:** 원값과 중앙값은 있지만 분위가 없는 소표본 그룹. 카드와 칸에 '분위 없음 · 비교 그룹의 유효 종목이 적어 분위를 매기지 않음'이 나오고, top10을 걸면 전부 판정 불가다.
- **조건 결과 0개:** 계산은 정상인데 조건을 만족하는 종목이 없음. "계산은 정상 · 조건을 모두 만족하는 종목 0개"를 보여 준다.
- **오너 예시:** "U-B에서 6개월 모멘텀 D10이고 변동성 D10은 제외한 뒤 QGV 순". 표가 통과 종목만 리더보드 QGV 순서로 보여 준다. 필터를 더해도 카드의 분모가 바뀌지 않는다.
