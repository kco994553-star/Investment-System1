# 시각 양식 — 혼잡스 영상 기준 (DC-25)

작성 2026-10-27. 사용자 지시: 「프론트엔드는 이 유튜브처럼 해줘. 일관되게.」 — 혼잡스 「바이브코딩 원리는 알고 하세요 | 모든개발 지식부터 도구까지 이거 하나로 이해하기 90분 총정리」(https://youtu.be/bB37cJ-13pI). 모든 화면·시안 보드·새 앱 CSS가 **이 문서 하나**를 따른다. 화면마다 다른 양식을 만들지 않는다.

- 근거로 본 장면: 썸네일 '개발자 머릿속 별자리 지도'(기술 112개를 식당 비유로 잇는 지도)와 본편 장면 3장(흑백 선화 삽화 + 위쪽 가운데 자막). 영상 본편은 YouTube 봇 확인 때문에 더 받지 못했다.
- 견본: 시안 아티팩트 '영상 양식 견본' 구역(2026-10-27 버전 51). `add/vs/Map`(투자시스템 별자리 지도), `add/vs/Leaderboard`(2.1 리더보드), 모바일 두 장.
- 상태: 견본 확인됨(2026-10-27, 아래 2절). 시안 보드 전체(90장)는 버전 52에서 이 양식으로 바뀌었다. 새 앱 CSS·글꼴·상태 캐릭터는 양식 PR에서 바꾼다(승인 대기, 배포 안 됨).

## 1. 규칙

| 항목 | 규칙 | 영상에서 본 것 |
| --- | --- | --- |
| 바탕·선 | 흰 바탕 `#ffffff`, 잉크 `#161616`, 선 2~2.5px·둥근 끝. 그림자·입체 없음 | 흰 바탕의 검은 선화 |
| 보조 글 | 회색 `#6b6b6b`, 13~14px 한 줄 | 노드 아래 회색 설명("식당 건물과 메뉴판") |
| 글꼴 | 제목 Jua(둥글고 굵은 손글씨풍), 본문·자막 고딕(Noto Sans KR 등 기기 고딕) 400/700 | 지도 제목의 굵은 손글씨, 자막의 깔끔한 고딕 |
| 자막 | 화면 위 가운데 한 줄 설명, **핵심어만 굵게** | "지금은 **꾸미기 규칙** 파일 하나만 고치면" |
| 노드 | 원 + 선 아이콘(40 단위 viewBox, 선 2.4px). 크기: 입구 140, 큰 노드 104, 작은 노드 76(모바일 112·96·68). 원 아래 굵은 이름 16~18px + 회색 한 줄 | 원 안 아이콘 + 굵은 이름 + 회색 설명 |
| 구역 | 동그라미 번호(30px) + 굵은 이름 20px + 회색 부제 13px. 번호 = 기능 번호(DC-08) | "① 인터넷과 HTML / 식당 건물과 메뉴판" |

| 개인 | 이 기기에만 있는 것(내 노트·내 보유·내 가중치)은 **점선 원** | — (이 앱의 공개/개인 경계, DC-22) |
| 상태 | 빈·읽는 중·실패는 선화 캐릭터(로봇) 한 장 + 한 줄(핵심어 굵게) + 회색 한 줄. 같은 캐릭터를 모든 화면에 | 인물·로봇 선화로 상황 설명 |

## 2. 확인된 것 (사용자 2026-10-27 「이대로, 3 으로 진행 / 색은 있어도 돼」)

- 견본 방향 그대로 전체에 적용한다.
- 색은 있어도 된다: Q·G·V 색(파랑·초록·주황), 메뉴 색, 노란 강조를 선화 양식 안에서 쓴다(점수 막대·아이콘 일부·핵심 표시). 메뉴 색 그림자처럼 입체로 보이는 장식은 쓰지 않는다.
- 글꼴: 제목 Jua(이미 검토·고정된 자체 호스팅 부분 글꼴 `jua-regular-ksx1001.woff2`, 옛 화면 web_assets와 같은 이름·같은 바이트), 본문·자막 고딕. 본문은 기기의 한국어 고딕(안드로이드 Noto Sans KR, 아이폰 Apple SD Gothic Neo, 윈도 맑은 고딕)을 써서 내려받지 않는다. 손글씨(펜) 글꼴은 쓰지 않는다.

## 3. 앱에서 이 규칙이 사는 곳

- `web_app/app.css`: 글꼴 토큰(`--font-display` Jua, `--font-body` 기기 고딕, `--font-hand`는 본문과 같음), 모서리 16px, 메뉴 색은 위쪽 4px 선(입체 그림자 없음), 구역 표시(`.stamp`)는 동그라미 + 제목, 노란 빛 `--glow`.
- `web_app/parts.js` `mascot(mood)`: 상태 캐릭터(선화 로봇) 한 개. 화면은 이것만 쓴다(`plain` 빈·없음, `alarm` 읽는 중·실패·STALE).
- 시안 보드: `restyle_boards.py`(Main 작업 도구, 저장소 밖)로 같은 규칙을 보드 전체에 적용했다.
