## 2. 확인된 것 (사용자 2026-10-27 「이대로, 3 으로 진행 / 색은 있어도 돼」)

- 견본 방향 그대로 전체에 적용한다.
- 색은 있어도 된다 → **같은 날 바뀜(DC-26, 4절)**: 「색은 최소화하되 더 사용하는게 좋을거같아」. 색 가짓수는 줄이고, 남긴 색은 뜻이 있는 자리에 더 넓게 쓴다. 메뉴별 색은 없앤다.
- 글꼴: 제목 Jua(이미 검토·고정된 자체 호스팅 부분 글꼴 `jua-regular-ksx1001.woff2`, 옛 화면 web_assets와 같은 이름·같은 바이트), 본문·자막 고딕. 본문은 기기의 한국어 고딕(안드로이드 Noto Sans KR, 아이폰 Apple SD Gothic Neo, 윈도 맑은 고딕)을 써서 내려받지 않는다. 손글씨(펜) 글꼴은 쓰지 않는다.

## 3. 앱에서 이 규칙이 사는 곳

- `web_app/app.css`: 글꼴 토큰(`--font-display` Jua, `--font-body` 기기 고딕, `--font-hand`는 본문과 같음), 모서리 16px, 메뉴 색은 위쪽 4px 선(입체 그림자 없음), 구역 표시(`.stamp`)는 동그라미 + 제목, 노란 빛 `--glow`.
- `web_app/parts.js` `mascot(mood)`: 상태 캐릭터(선화 로봇) 한 개. 화면은 이것만 쓴다(`plain` 빈·없음, `alarm` 읽는 중·실패·STALE).
- 시안 보드: `restyle_boards.py`(Main 작업 도구, 저장소 밖)로 같은 규칙을 보드 전체에 적용했다.

## 4. 색 규칙 (DC-26, 사용자 2026-10-27 「색은 최소화하되 더 사용하는게 좋을거같아, 1,3번은 너의 제안대로하자」)

정한 방법: 세 방향(뜻 중심, 기능 길잡이, 영상 충실)으로 따로 안을 만들고 한 번 견주어 하나로 합쳤다(점수 8·5·7). 1·3번(견본 방향, 글꼴)은 Main 제안 그대로다.

**색은 여섯 가지이고, 색마다 뜻은 하나다.** 그 밖은 잉크 `#161616`과 회색이다.

| 색 | 뜻 | 쓰는 자리 |
| --- | --- | --- |
| 파랑 `#2457C5` · 바탕 `#EAF0FF` | Q | Q 막대, Q 글자 고리, Q 머리글·정렬 열·노드 바탕, 켠 Q 칩 |
| 초록 `#1F7A45` · 바탕 `#E7F5EC` | G | 같은 자리의 G |
| 주황 `#D9780A`(채움) · `#A05600`(글) · 바탕 `#FFF1DC` | V | 같은 자리의 V |
| 빨강 `#B4231C` 글자·선 | 오름(한국식) | ▲/+가 붙은 숫자, 오름 캔들, 강세 선, '▲ 호재' |
| 파랑 `#1D4FA8` 글자·선 | 내림 | ▼/−가 붙은 숫자, 내림 캔들, 약세 선, '▼ 악재' |
| 빨강 `#B4231C` 테두리·고리 · 바탕 `#FCEAE9` | 문제 | 실패·STALE·읽기 실패 칩과 카드, 앞에 '!' 고리. 글은 잉크 굵게 |
| 노랑 `#FFE45C` | 지금 있는 곳 | 화면마다 하나: 지금 메뉴·지금 탭, 메뉴가 없으면 화면 제목 |
| 보라 `#7A4CC2` 점선 · 바탕 `#F2ECFB` | 이 기기에만 | 기기 칩, 최근·★, 보유·내 노트·내 가중치, 이 기기 시세로 계산한 임시 V. 늘 '이 기기' 낱말과 함께 |

- 회색: 글 `#5C5C5C`(보조·NA·예시·결정 대기), 점선 `#808080`(자료 연결·기다림·꺼짐), 옅은 바탕 `#F4F4F4`(읽는 중·꺼짐).
- 메뉴마다 색을 두지 않는다. 메뉴는 동그라미 번호·아이콘·이름으로 가른다.
- 글자색은 오름·내림 숫자와 Q·G·V 글자에만 쓴다. 다른 뜻은 테두리·고리·바탕이 말한다.
- 형광펜은 쓰지 않는다. 핵심어는 굵게 쓴다. 노랑은 지금 있는 곳 하나뿐이다.
- 정상·통과에는 색이 없다(✓는 잉크).
- NA는 회색 'NA'이고 축 색을 칠하지 않는다. 0으로 채우지 않는다.
- 연한 바탕 위 글자도 4.5:1 이상이다(가장 낮은 것 G 글자/문제 바탕 4.60). 뜻 있는 선·막대는 3:1 이상이다(V 막대 3.16).
- 글에 색 이름을 쓰지 않는다('빨간 원' 대신 '굵은 원'). 색만으로 뜻을 전하지 않는다.
- 남은 약점: 빨강이 오름(글자)과 문제(테두리·바탕) 두 일을 한다. Q 파랑과 내림 파랑은 거의 같아 자리와 ▼로 가른다.
