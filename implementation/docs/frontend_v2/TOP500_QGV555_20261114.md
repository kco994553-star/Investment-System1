## 3. QGV 555 모형 (계약 요청)

- 555 = Q·G·V 각 축의 **평가 역할 5개**. 한 역할 안에 원지표가 여러 개여도 역할 수는 5다.
- 지금 요소 목록(`docs/research/sector_qgv/catalog.json`, 51개)은 Q 역할 5개(수익성·회계 품질·재무 여력·이자 지급 능력·안정성), G 2개(성장·수익성 변화), V 3개(이익·현금·기타 가치)다. **G·V의 5역할 정의는 계산 담당 계약 사항**이다. Main 권장안(미확정, 합성 예시에만 사용):
  - G: 매출 성장 / 이익 성장 / 수익성 개선 / 자본 성장 / 현금흐름 성장
  - V: 이익 가치 / 장부 가치 / 매출 가치 / 현금 가치 / 주주환원
  - EV 기준 지표(EV/EBITDA·EV/EBIT·EV/Sales·EV/FCF)의 역할 배정은 계약에서 정한다.
- 모형(별도 ID/version, 기존 축소 U1/U2/S1·333과 겹치지 않음, 제안):
  - **U1-555** 통합: 모든 평가 기업에 같은 공통 요소·같은 참조집단. 제안 ID `unified-555/0.1.0`, 프리셋 `qgv-555-unified-default/0.1.0`.
  - **S1-555** 섹터: 섹터×회계모형별 요소. 제안 ID `sector-555/0.1.0`, 프리셋 `qgv-555-sector-default/0.1.0`.
  - **내 설정**: 사용자 설정 `qgv-555-user-config/1`(제안). base preset ID/version을 이름으로 갖고, 새 프리셋이 생겨도 저장 설정은 자동으로 바뀌지 않는다.
- U1은 통합 리더보드, S1은 섹터 리더보드다. 섹터 점수를 이어 붙여 통합 순위를 만들지 않는다.
