10/19 v2 실제 기록 시작 여부는 아직 확인할 수 없다. 코드의 시작 정책은 2026-10-19이며, 첫 실제 실행에서 같은 거래일 공개 입력이 있으면 v1·v2를 함께 기록한다. 입력이 없으면 `SEC_QGV2_MISSING` 등의 고정 토큰으로 NA를 기록하고 배포를 막지 않는다. v2 가상매매는 하나 이상의 기업에서 유효한 Q와 G가 함께 나온 첫 v2 기록 날짜부터 시작한다. 전부 NA인 원장 행을 준비 완료로 보지 않는다. v1 저장 V를 v2 Q·G에 섞지 않는다.

(2026-10-31 폐지, DC-31: 기기에 V 이력을 쌓지 않는다. 아래는 옛 방향의 기록이다.) 기기 전용 v2 V 이력은 기존에 승인된 V 점수 저장 범위 안에서 별도 키를 쓴다. 현재 완료된 미국 거래일의 종가를 메모리에서 계산하고, 같은 거래일 공시 입력일 때만 점수와 버전·프로필·산출 요인 구성·모집단 해시·관측 시각을 저장한다. 가격·환율·보유·원자료는 저장하지 않고 백업에 포함하지 않는다. 같은 구성의 실제 20거래일 전 기록이 없으면 기울기는 NA다. 과거 종가에 새 공시를 적용한 소급 기록은 금지한다.

추가되는 공개 입력은 가격이 필요 없는 매출(연간/TTM), 최근 5개 회계연도의 영업이익률, 6년 매출이 있을 때의 5개 연간 성장률 표준편차와 발행사 단면 백분위다. 과거 `v_inputs_v2` 형태와 설명 값이 없는 예전 metrics도 허용한다. 정상화 이익은 사용자 정의 그대로 **최근 매출 × 5년 평균 영업이익률**이며, 5개가 없으면 `NORMALIZED_EARNINGS_NOT_AVAILABLE`이다. DART는 SEC 자료로 가장하지 않고 동일한 재무 계산 API를 이용한다. 새 성장률 설명 값은 기존 Q·G 점수를 바꾸지 않는다.

실제 504 보고를 준비하려면 공개 파일이 게시된 후 다음 명령을 실행한다. 도구는 가격·종합 점수·V를 계산하거나 채우지 않는다. Q/G 요인 수와 모집단 크기를 함께 보여 주고, 업종 상위 10은 Q·G 각각으로 분리한다. ‘직관 점검 후보’는 Q/G 차이가 큰 순서로 제시하는 조사 대상이며 판정 기준을 새로 만들지 않는다.

```sh
python implementation/tools/qgv_v2_quality_report.py --input <게시된-sec-qgv2.json> --out <비공개-보고서.json>
```

금융사 V와 v1 경기민감 V의 이익→EPS/FCFE 치환 정의는 미정이다. 이를 임의로 만들지 않았다. v1은 비교용으로 기존 계산을 유지하고, v2 경기민감 EBIT 요인은 정상화 입력이 준비된 경우에만 계산한다.

HANMI의 v2 전진 기록은 C의 엄격 검증된 DART 참고 어댑터와 같은 거래일 공개 재무 파일이 있을 때만 같은 Q·G를 기록한다. `reference_sources.hanmi`에는 DART 구분·실제 공개 파일 바이트 SHA-256·관측 시각·참고 전용 기준을 남긴다. 미국 단면에 한국 기업을 추가하지 않으며 v1 비교 기록은 바꾸지 않는다. API·선택적 v2 입력이 없거나 결측/다른 거래일이면 기존 HANMI NA를 유지한다. 자료가 준비된 날부터 추가하며 이전 NA를 고치지 않는다. 이 선택적 출처 필드도 공개 경계 승인 범위다.
