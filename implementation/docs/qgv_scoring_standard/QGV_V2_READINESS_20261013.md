10/19 v2 실제 기록 시작 여부는 아직 확인할 수 없다. 코드의 시작 정책은 2026-10-19이며, 첫 실제 실행에서 같은 거래일 공개 입력이 있으면 v1·v2를 함께 기록한다. 입력이 없으면 `SEC_QGV2_MISSING` 등의 고정 토큰으로 NA를 기록하고 배포를 막지 않는다. v2 가상매매는 Q·G가 준비된 첫 v2 기록 날짜부터 시작한다. v1 저장 V를 v2 Q·G에 섞지 않는다.

추가되는 공개 입력은 가격이 필요 없는 매출(연간/TTM)과 최근 5개 회계연도의 영업이익률뿐이다. 과거 `v_inputs_v2` 형태도 허용한다. 정상화 이익은 사용자 정의 그대로 **최근 매출 × 5년 평균 영업이익률**이며, 5개가 없으면 `NORMALIZED_EARNINGS_NOT_AVAILABLE`이다. DART는 SEC 자료로 가장하지 않고 동일한 재무 계산 API를 이용한다.

실제 504 보고를 준비하려면 공개 파일이 게시된 후 다음 명령을 실행한다. 도구는 가격·종합 점수·V를 계산하거나 채우지 않는다. Q/G 요인 수와 모집단 크기를 함께 보여 주고, 업종 상위 10은 Q·G 각각으로 분리한다. ‘직관 점검 후보’는 Q/G 차이가 큰 순서로 제시하는 조사 대상이며 판정 기준을 새로 만들지 않는다.

```sh
python implementation/tools/qgv_v2_quality_report.py --input <게시된-sec-qgv2.json> --out <비공개-보고서.json>
```

금융사 V와 v1 경기민감 V의 이익→EPS/FCFE 치환 정의는 미정이다. 이를 임의로 만들지 않았다. v1은 비교용으로 기존 계산을 유지하고, v2 경기민감 EBIT 요인은 정상화 입력이 준비된 경우에만 계산한다.
