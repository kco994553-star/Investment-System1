# QGV v2 — 버전·용어와 문서 읽기 안내

확인일: 2026-11-05. 기존 DC-03·DC-02·DC-31을 설명하는 문서이며 새 계산 규칙을 도입하지 않는다.

**현재 화면의 평가 모델은 QGV v2다. QGV v2는 요소와 계산 규칙을 함께 포함한다. “v1.5 계산 방식 + v2 요소”라는 조합으로 설명하거나 구현하지 않는다.**

## 1. 이름별 의미

| 이름 | 의미 | 사용 범위 |
| --- | --- | --- |
| QGV Standard v1.5 / `v1.5-balanced` | 과거 평가 기준명 및 레거시 계약 식별자 | 과거 자료 해석·호환성. 현재 화면 모델명으로 사용하지 않음 |
| QGV Scoring Standard v1 / `standard=v1` | 2026-10-08 채택 기록의 별도 점수 기준 | 동결 정의·과거 결과 해석. v1.5와 같은 버전 필드라고 간주하지 않음 |
| QGV v2 | 요소·측정·점수화·가중치·결측·관문을 포함하는 평가 모델 | 현재 화면 점수(DC-03) |
| `qgv2-calc/…` | v2 계산 구현 버전 | 결과 재현·계산 변경 구분 |
| 사용자 프로필 | 개인이 선택한 가중치 등의 설정 | 공식 결과와 구분. 설정 변경을 모델의 자동 승격으로 해석하지 않음 |
| QGV Analysis v1.7.6 / QGV System v1.7 | 분석 계약 / 과거 소프트웨어 개발선 | 평가 모델 버전이나 점수 척도와 구분 |

`versions.py`의 `QGV_STANDARD = "v1.5-balanced"`와 동결 결과의 동일 값은 현재 v2 화면을 v1.5라고 부를 근거가 아니다. 호환용 상수·스키마·과거 결과를 v2로 일괄 치환하거나 과거 점수를 재기록하지 않는다. 기존 v1 정의의 동결 의미도 유지한다.

## 2. 요소와 계산을 구분하는 방법

| 구분 | 질문 | 예시 |
| --- | --- | --- |
| 평가 요소 | 무엇을 평가하나? | 수익성 |
| 측정 지표 | 어떤 수치로 측정하나? | ROIC |
| 점수화 | 수치를 어떻게 점수로 바꾸나? | 정해진 비교 집단에서 백분위 계산 |
| 가중치 | 점수를 얼마나 반영하나? | Q 안의 수익성 비중, 종합의 Q 비중 |
| 결측·관문 | 자료 부족·조건 위반을 어떻게 처리하나? | NA, 재정규화, 가치 함정 관문 |

예: ROIC를 다른 지표로 교체하는 것은 지표 변경이고, ROIC를 유지한 채 비중만 바꾸는 것은 가중치 변경이다. 같은 지표·가중치라도 비교 모집단이나 결측 규칙이 달라지면 결과가 달라질 수 있다.

사용자 요소 편집 요구를 설명할 때는 **“QGV v2 기반 사용자 평가 설정 편집·재계산”**으로 부른다. 기존 가중치 조정과 새로운 요소 교체 기능을 구분한다. 이 문서 변경은 해당 기능의 구현·시험·배포 완료를 뜻하지 않는다.

## 3. 읽기 순서와 권위

1. [START_HERE](../../../START_HERE.md), [DIRECTION_CHANGES](../../../docs/SPEC/DIRECTION_CHANGES.md), [WORKING_RULES](../../../WORKING_RULES.md): 현재 정책. DC-03은 화면 v2만, DC-02·DC-31은 중앙 V와 기기 V 폐지, DC-06은 프리셋 이름 구분.
2. [CURRENT_HANDOFF](../../../CURRENT_HANDOFF.md): 기록된 운영 상태. 실제 상태는 해당 커밋·실행·게시본으로 확인.
3. [QGV_V2_CANDIDATE](QGV_V2_CANDIDATE.md): 첫머리의 현재 설명을 먼저 읽고 초기 후보안은 이력으로 읽는다.
4. [QGV_V2_QG_METHOD](QGV_V2_QG_METHOD.md): Q·G 상세 측정·점수화 설명. 운영 구현·계산 버전과 함께 확인.
5. [CENTRAL_V_DC02_PLAN_20261024](CENTRAL_V_DC02_PLAN_20261024.md): 중앙 V 계산·게시 설계. 이후 결정과 실제 게시본을 함께 확인.
6. [QGV_SCORING_STANDARD_v1](QGV_SCORING_STANDARD_v1.md): 과거 v1 동결 정의. 현재 화면 지시로 해석하지 않는다. 본문·채택 증거는 보존한다.
7. [QGV_V2_V_DEVICE](QGV_V2_V_DEVICE.md): SUPERSEDED인 옛 기기 V 기록. 현재 화면 계산 경로로 복원하지 않는다.

초기 후보 문서의 “v1이 기본”, “v2는 비교용”, “기기 RAM에서 V 계산”은 이후 결정으로 대체되었다. 모델이 v2라는 사실만으로 모든 요인의 산출 가능성, 실자료 백테스트 완료, 보정(CALIBRATED), 배포 완료를 주장할 수 없다.

## 4. 보고·개발 시 확인

- 현재 화면 모델은 “QGV v2”, 과거 v1.5 언급에는 “과거 기준/레거시 계약”을 함께 쓴다.
- 평가 모델·계산 버전·사용자 설정·데이터 기준일·비교 모집단을 구분한다.
- 공식 결과와 사용자 설정 결과를 혼합하지 않는다.
- 과거 15×10 점수 체계를 v2 백분위 점수에 자동 적용하지 않는다. v1.5·Scoring Standard v1·v2 사이의 요인 대응이나 숫자 변환은 이름만으로 추정하지 않는다.
- 옛 문서와 최신 지침이 충돌하면 최신 지침을 우선하고, 과거 원문은 이력으로 보존한다.

## 5. Main 통합 시 반영할 위치

이 문서 PR은 계산·가중치·버전 상수·동결 결과를 바꾸지 않는다. 담당 경계를 지켜 START_HERE·DC·공용 가드는 직접 수정하지 않는다.

- START_HERE의 “화면 점수는 QGV v2만” 항목에 이 안내 링크와 “v1.5는 레거시 계약, v2는 요소와 계산 규칙을 포함하는 모델” 설명을 연결한다.
- 필요 시 기존 방향 검사에 “현재 화면/공식 모델을 v1.5로 부르는 신규 문구”를 검사하도록 보완한다. 과거 인용·동결 스키마·버전 상수는 허용해야 하며 모든 v1.5 문자열을 금지하지 않는다.
- 위 연결·가드 보완은 이 PR에서 완료했다고 보고하지 않는다.
