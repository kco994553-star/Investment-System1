## 개인 사용 흐름

ACTUAL에서 종목별 수량·평균단가·단가 통화와 수동 현재가·가격 시각을
입력합니다. 현재가는 승인된 A-S2 상장 통화 USD·JPY·KRW를 사용합니다.
평균단가 통화 선택은 현재가의 상장 통화를 바꾸지 않습니다.
USD와 JPY 환율은 각각 **1 USD당 KRW**, **1 JPY당 KRW**입니다.
원/100 JPY 자료를 사용하는 경우 원/1 JPY 단위로 확인해 입력해야 합니다.
시각은 ISO8601 및 시간대가 포함된 값으로 표시하며 기본 현재 시각을 수정할 수 있습니다.

기기에 저장하면 원통화 평가액과 KRW 평가액을 함께 표시합니다.
모든 보유 행의 현재가와 필요한 환율이 있어야 전체 평가액·실제 비중·
TARGET 대비 비중 차이를 계산합니다. 한 항목이 없으면 전체 분모가
확인되지 않으므로 비중을 재조정하지 않고 NOT_AVAILABLE로 둡니다.
평균 매입가·다른 거래소 종목·이전 값으로 없는 시세를 추정하지 않습니다.
7일 이상 지난 가격은 STALE 표시와 원래 시각을 유지하며 제공된 값의
계산은 유지합니다. 환율에도 동일한 오래된 입력 표시를 적용합니다.
TARGET 차이의 단위는 **%p**이고 기존 TARGET 수치와 투자 계산법은 변경하지 않습니다.

보유 정보는 기존 `device-actual-holdings/1` 기록, 시세·환율은
`device-market-data/1` 기록으로 같은 IndexedDB에 저장합니다.
읽기·저장·가져오기는 두 기록을 원자적으로 처리하고 다른 탭의 변경과
충돌하면 보존합니다. 손상된 값을 삭제할 때도 처음 읽은 실제 기록과 비교하므로
다른 탭에서 복구한 보유 정보·시장 데이터·API 키를 지우지 않습니다.
비교할 수 없는 불투명/크기 가변 손상값은 보존하고 오류로 종료합니다. 저장 실패·잘못된 파일·취소는 기존 값을 유지합니다.
삭제는 보유·시세·환율 기록을 지우며 내보낸 파일은 사용자 기기에 남을 수 있습니다.

## 백업과 키

JSON 백업 `device-actual-holdings/2`는 사용자 소유·버전·effective_at·
available_at·A-S2/TARGET 버전과 해시, 보유 정보와 `market_data`를 포함합니다.
각 가격·환율의 출처와 기준/입력 시각을 보존합니다. 기존 schema1 보유
백업도 가져올 수 있으며 가격·환율이 없는 백업은 기존 시세를 함께 지우고
NOT_AVAILABLE로 복원합니다. 백업에는 API 키와 API 설정이 포함되지 않습니다.

설정 화면은 비밀번호 입력 형태의 기기 API 키 저장·삭제 구조를 제공합니다.
저장한 키는 입력칸에 다시 채우지 않고 저장 여부만 표시합니다. 앱 시크릿과
계좌 액세스 토큰을 입력하지 않습니다. 서비스는 NOT_SELECTED,
조회는 OFF이며 시세 새로고침 버튼은 비활성입니다. 외부 스크립트와
외부 시세 연결은 없고 CSP script-src/connect-src는 self만 허용합니다.
자동 갱신·예약 작업·브로커 계좌 연결·시세 재배포·유료 가입을 구현하지 않았습니다.

CDR052는 KIS와 사용자 전용 중계를 보류했습니다. 서버·중계 없이 각 사용자의
무료 API 키를 자기 기기에만 저장하는 방식으로 Alpha Vantage를 우선 검증합니다.
[이전 공식 서비스 선택안](DIRECT_API_SERVICE_OPTIONS_26E.md)은 당시의 후보 비교 기록이며,
중계 옵션을 현재 승인 구조로 해석하지 않습니다. API 구현은 후속 승인 전까지 OFF입니다.

  저장 파일이나 채워진 스크린샷을 만들지 않습니다.
- `evidence/public/actual-empty-*.png`와
  `evidence/manual/manual-empty-*.png`는 각각 네 장의 빈 기기 스크린샷입니다.
  수동 검사는 경계값 검증을 위해 테스트 브라우저 시계를 고정합니다.

웹 업로드 폴더에는 검토된12개 파일만 있습니다. 공개 데이터 JSON의
기존 승인 해시는 유지하며 변경한 UI/market 모듈만 고정 해시를 갱신합니다.
등록된 기기 보유·가격·환율·키 기록은 repository-guard와 빌드 입력 검사,
업로드 직전 폴더 검사와 배포 직전 실제 raw-tar 검사에서 거부합니다.
검사는 값이나 개인 파일명을 로그에 남기지 않습니다. 임의 인코딩과
악의적인 미래 소스 변경까지 검증했다고 주장하지 않습니다.

기존 투자 의사결정·Frozen/TARGET/scoring/Holdout·READ_ONLY는 유지합니다.
Chart source3/6, Platform1/9와 원래 생산 게이트 의무는 별도이며,
개인 화면 배포가 운영 데이터·정식 FPIA 완료를 뜻하지 않습니다.
