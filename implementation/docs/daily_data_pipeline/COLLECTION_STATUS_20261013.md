# 2026-10-13 수집 연결 점검

레인 C 작업 브랜치의 후속 변경이다. 새 계산·공개 경계·워크플로 변경은 PR 승인 후 병합한다.

## 실제 접근 확인

- Actions Secret 목록 조회는 `HTTP_403`(integration 권한 부족). 같은 조회는 반복하지 않았다. 키 값은 읽지 않았다.
- 최신 SEC 일일 실행 `38378607638`의 로그 아카이브에서 허용된 토큰만 추출했다. `BEA_USERID=SET_MASKED`여서 10월 11일 빈 환경 변수 문제는 최신 실행에서 해소됐다. 현재 BEA 키 재등록 요청은 없다.
- Fed 고정 진단: H.15 안내 경로 `HTTP_STATUS / 404 / HTML`; H.4.1·H.8 패키지 `BODY_SIZE / 200 / HTML / 0`. 낡은 경로·패키지로 유효한 CSV를 못 받았다.
- 공식 Fed 패키지 선택 페이지(H.15/H.4.1/H.8) 조회는 각각 한 번 `HTTP_403`. 확인되지 않은 해시나 경로를 새 값으로 바꾸지 않았다. 자료는 계속 `NOT_AVAILABLE`; 배포를 막지 않는다.
- DART 키 등록은 사용자의 확인을 따른다. 이 환경에는 Secret 값이 없으므로 실제 인증 요청을 보내지 않았다. 첫 승인된 Actions 수집의 `DART_*` 상태로 연결 결과를 확인한다.

## DART QGV v2 연결

- 기존 `dart-financials.json`에 선택적인 `qgv2` 블록을 투영한다. 원래 형식과 v1 Q·G는 유지한다.
- `qgv.v2_factors.compute_reported_periods`와 `qgv.v2_scoring.score_rows`를 그대로 사용한다. 통화 단위가 바뀌어도 비율은 같고, 한국 종목을 미국 발행사 분포에 넣지 않는다.
- 화면 계산 helper는 항상 **참고 순위**로 표시한다. 한국 종목의 SIC는 추정하지 않으며 미국 일반 기업 대비 참고다.
- 원래 한 건짜리 DART 공개 입력은 미국 peer가 충분해도 Q 최대 45%, G 0%였다. 후속 수집기는 `--qgv2-history`로 최신 연간 보고서부터 5년 전까지 실제 6개 FY를 수집한다. 보고서 목록에서 각 FY의 최신 접수번호를 고르고 재무 응답의 접수번호·연도·보고 유형을 일치시킨다. 30회 기본 예산·50회 상한을 유지하고 한도나 치명적 연결 오류 이후 추가 호출하지 않는다.
- 자산·매출총이익·세전이익·세금·이자·감가상각·희석 EPS·희석 가중평균 주식수는 명시된 IFRS 표준 계정 ID만 사용한다. 계정명으로 추정하지 않는다. 금융비용(`FinanceCosts`)을 이자비용으로 간주하지 않고 `InterestExpense`만 허용한다. 기존 부채 정의(단기+장기·유동분+사채+리스)를 유지하며 총부채의 출처 계정 여러 개도 엄격한 공개 검증기가 받는다. KRW·KRW/주·주 수 단위를 구분한다.
- 보고서별 원문 SHA·접수번호·CFS/OFS·일자를 공개 원장 입력에 보존하고, 서로 다른 연결/별도 기준의 이력은 섞어 계산하지 않는다. 없는 기간·계정은 `NA`; `DART_V2_*_NOT_COLLECTED`와 축별 산출 요인 수·확보 비중·NA 사유를 고정 토큰으로 기록한다. 소급 전진검증 기록은 만들지 않는다.
- 실제 표준 계정·6FY 구조를 모사한 합성 수집 사례에서는 Q·G 각각 5/5 요인·100% 확보 비중으로 같은 v2 계산이 가능했다. **실제 042700 점수·연결 성공은 첫 Secret 기반 Actions 실행에서 확인 전**이며, 합성 검증 결과를 실데이터 성공이라고 표시하지 않는다.
- `project_dart_qgv2.py`는 이미 모은 파일만 읽는다. 새 외부 호출·키 조회가 없고, 파일이 없거나 투영이 실패하면 고정 토큰과 종료 코드 0으로 원래 파일·배포를 유지한다. A의 공용 계산 API와 #211의 DART 수집 단계가 선행해야 한다.

## 매크로 재생: 실제 자료 2/5, 전체 5개 검증 아님

이번 환경에서 BLS POST 요청으로 1998–2026년 월별 실업률을 받았고, 공개 통계 미러의 CPI-U NSA와 실질 GDP SAAR를 읽었다. 입력은 기기 임시 경로에만 두었다. CPI 1913–2026, GDP 1947–2024; 아래 구간을 실제 자료로 평가했다. 금리 곡선·시장·신용 이력은 미제공이므로 **전체 5개 재생은 NOT_RUN**이다.

현재 수정치와 가정한 발표 지연(월 자료 다음 달 15일, 분기 종료 후 약 30일)을 사용한 비교다. 실제 당시 발표 빈티지·정확한 발표 시각을 재현한 PIT 검증이나 성과 검증이 아니다. 상태는 `v1 · UNCALIBRATED`를 유지한다.

## 공시·뉴스·운영 기준

- SEC 8-K 다음 뉴스, 다음 DART 순서의 원래 승인된 수집은 유지한다. SEC 연락처는 `SEC_USER_AGENT` 주입만 사용한다. 과거 편의 fetch의 직접 연락처 fallback도 제거해 Secret이 없으면 요청하지 않는다.
- ASML 6-K는 첨부 제목에 분기(Q1–Q4/quarterly/분기 순서)와 results/earnings가 둘 다 명시된 경우만 포함한다. 일반 Press release 제목은 확인 불가로 남기고 임의로 실적 처리하지 않는다. 6-K에 8-K 항목 코드를 만들어 붙이지 않는다.
- 뉴스 구조적 사건 helper는 업종 사례를 제목에서 좁게 대응한다. 일반 LEGAL 분류만으로 E4를 만들지 않는다. 등급 `SIGNAL`, 점수 영향 없음, 정보 전용 E4 후보, 사건별 반복 제외. 공시 증거 확인 전 R1/R2/R3로 올리지 않는다.
- 비교 최소 표본은 상승·하락 포착, 낙폭, 변동성 모두 20거래일이며 부족한 실제 표본 수를 반환한다. ETF·TWR 화면 연결은 B 레인이 담당한다.
- 리더보드 확인 helper는 공시 확인 분기와 같은 v2 계산이 선택한 매출·영업이익 TTM 종료일이 정확히 같고 원문 해시도 같을 때만 `확인`을 반환한다. 기존 v2 공개 입력에는 매출 TTM 날짜가 없어 `sec-filing-windows.json`의 선택적인 `qgv2_ttm_periods`에 날짜만 추가한다(금액 없음). v2 계산 함수는 변경하지 않는다. 스냅샷 날짜가 최신이라는 이유만으로 확인하지 않는다.
