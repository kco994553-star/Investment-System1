# 투자 시뮬레이션 스튜디오

2026-10-15 요청: GitHub 투자 시스템을 검토하고, 임의 값을 채워 백엔드 내용을 고려한 프론트엔드를 만든다.

기존 운영 앱을 보존하는 로컬 전용 데모다. 한국어, 390px 모바일 및 1440px 데스크톱을 지원한다. 기존 QGV v2 기본 프리셋·가치 함정 관문·결측 규칙을 그대로 호출한다. 공식 TARGET v0는 원본 비중을 읽기만 하며, 가상 ACTUAL은 별도로 명시한다. 기업명은 기존 식별자 레지스트리에서 가져오고 모든 재무·가격·뉴스·성과 예시는 합성임을 지속 표시한다. TEL의 모호한 시장 식별은 해소하지 않는다.

화면: 오늘, 포트폴리오, QGV 리더보드/기업 상세, 시뮬레이션, 기술적 분석, 매크로, 뉴스·관계, 검증·기록, 설정. 검색·필터·관심 기업·시나리오·자본금/기간/월납입·현금 비중·비교 시리즈·CSV 내보내기를 제공한다. QGV 점수는 v2만 사용한다. 원자료는 설정의 기본 접힌 개발자용 패널에 둔다.

Python 표준 라이브러리 로컬 서버가 기존 SimulationEngine, TechnicalEngine, MacroEngine, PortfolioEngine, QGV v2를 호출한다. 프론트엔드는 의존성 없는 HTML/CSS/JS이며 HTTP API를 사용한다. 시뮬레이션은 합성 월별 수익률을 재생하고 월말 납입을 더한다. 비교는 동일한 납입 조건을 적용한다. 수익률/낙폭은 납입 영향을 제거한 단위가치로 산출한다. QGV 프로필은 합성 수익률의 발생 규칙을 바꾸지 않는다. 매크로는 참고 표시만 유지한다. 실제 백테스트·전진검증·실시간 시세·계좌 연동·주문을 주장하지 않는다.

운영 공개 빌드 경로에는 합성 시세를 넣지 않는다. 배포/병합은 이번 작업에 포함하지 않는다. 로컬 소스와 검증 결과를 작업 브랜치·PR로 보존한다.
