## 1. 용어 구분(혼동 금지)

| 명칭 | 의미 | 책에 맞춘 행동 |
|---|---|---|
| **재선정(RESELECTION)** | 그 평가일에 투자 가능한 **모든** 발행사를 당시 정보로 다시 채점·순위화하고 새 포트폴리오 구성원을 정함 | **연간 1회가 새 책 기반 연구 주기** |
| **비중 재조정(REWEIGHTING)** | 재선정 후 계속 보유하는 종목의 비중을 고정 동일가중 목표로 맞춤 | 재선정 시 필요 수량만 거래 |
| **분기 재선정(QUARTERLY)** | 2·5·8·11월마다 전체 유니버스를 새로 평가해 구성원 교체 | **주기 효과 보조 비교**, 책 기반 주검정이 아님 |
| **12개 월별 시작 코호트** | 1~12월 중 서로 다른 달에 시작하는 독립적 포트폴리오, **각 코호트는 다음 해 같은 달에 재선정** | 월간 전체매매 아님. 각 달 출발 월 효과 비교 |

**유지 중인 종목을 매일/매월 목표비중만 되돌리는 행동과 매년 전체 점수 순위에 따라 보유 구성원을 바꾸는 행동은 다르다.**

## 2. 책 기반 QGV/팩터 백테스트의 새 주검정

적용 연구: **BT-01(QGV 고정 N, 신규 Book-aligned 버전), BT-02(QGV 10분위), BT-03(책 주제 팩터 BEST10)**.

- 선정 자격: 사전등록된 역사 PIT 적격 미국 주식군 2개 — U-BOOK200(미국 전체시장, 물가조정 실질 2억 달러 이상), U-SPX-HIST(과거 S&P500 실제 편입), 각 그룹 점수는 그 그룹 PIT 구성원 기준으로 독립 계산.
- 종목 선정: BT01은 N 상위 종목, BT02는 QGV 점수 D1~D10 **각각 약 10%**, BT03은 각 팩터별 BEST10(예: 저PER은 낮은 10%). 구성 기준·모집단 분모·QGV 점수 산출 여부를 모두 재검토한다.
- **핵심 Book-aligned 전략의 새 주주기 = ANNUAL_RESELECTION**. 매년 전체 기준을 재평가한다.
- 신호일 이전 공개된 재무와 직전 완료 거래세션 종가로 순위를 확정하고, **그다음 거래 가능한 시가**에 필요한 매수·매도를 체결한다. 이미 사라진 종목 정산·기업행동은 연중에도 처리한다.
- **단일 고정 재선정월 = 2월, 셋째 월요일 휴장 시 다음 거래일**은 기존 연구 엔진과 비교용 연구 가정이며 **책의 원문 재선정 날짜가 아니다**. 원서와 완전 일치한 결과라고 주장하지 않는다. 시작 월에 민감하면 12개월 시작 코호트를 별도 비교한다.
- **책에 착안한 월별 12개 연간 코호트**는 출발 월만 1~12월로 분리하며 각 코호트 내부 재선정은 **1년에 1번**이다. 첫 거래일에 형성(실행상 추가 연구 가정). 12개 NAV·비용·수익·분포를 개별 출력하고, 서지 원문 검증 전 하나의 '책과 동일 평균'으로 단정하지 않는다.
- **분기(2/5/8/11월 셋째 주) = CADENCE_SENSITIVITY**. 동일 기업군·동일 팩터·비용·처리규칙으로 연간 대비 차이를 검증한다. 달력만 바꾸어 결과가 개선된다고 가정하거나 연간 코호트와 분기를 혼합하지 않는다.
- **연간/분기 모두** 재선정 때 전체 순위를 다시 계산한다. 탈락 종목 목표 0/전량 처분(미체결·기업행동 예외), 새 편입 매수, 유지 종목만 순차이 비중 재조정. **신호일에 확정한 수량**을 다음 시가 이후의 미래 가격 정보로 맞춤 재계산하지 않는다.
- 신규주·상폐·시총변화로 구성원 수가 바뀌거나 교체수가 달라져도 정상. 최소 적격 100개 같은 연구 게이트는 별도 사전 등록값 유지. **재선정 주기와 가격 손절·실적 발표·뉴스 자동 거래는 무관**하며 다른 규칙은 여기서 활성화하지 않는다.
- 보고: 연간 주검정 CAGR, MDD, 회전율, 1·3·5·7·10년 롤링/base rate, 매년 재선정 전후 구성 교체 수/유지 수, 총 거래대금·비용·현금·미체결, 두 모집단, 상·하위 10%, 각 책 주제를 보고한다.

## 3. 기존 BT-01의 분기 주검정 보호 + 책 기준 새 계약

**중요한 충돌 사항:** #417의 qgv-backtest-standard/2026-10-26.5는 W0~W3×N15 분기를 **과거의 고정 주검정**으로 등록했다. 이 이력을 지우면 구현·합성 시험의 재현성이 깨진다.

- **기존 BT-01/v0**: 고정 N 30개 구조, W0~W3×N15 **분기 PRIMARY** 원본·테스트를 역사 버전으로 그대로 보존.
- **신규 BT-01/BookAnnual-v1 (별도 연구 계약 제안)**: W0~W3×N15 **연간 PRIMARY**, 분기 결과는 **주기 민감도**. 이미 등록한 W0/W3 N15-Y를 재사용하고 **W1/W2 N15-Y 두 셀을 신규 등록해야** 4가중치 비교가 공정하다. 실데이터 실행 전에 종목 수·코스트·기간·OOS·통계 가설을 잠그고, 새 research_spec_id·manifest로 분리한다.
- 새 계약 승인 전 #417 구버전이 자동으로 신규 계약으로 바뀌지 않는다. **공식 QGV·TARGET·PLAYBOOK 투자계좌 실제 리밸런싱 날짜는 그대로**이며, 연구 결과로 변경하려면 별도 사용자 승인이다.
- 신설 **2개는 구 30개 설정을 삭제하거나 결과를 바꾸지 않는다**. 신규 대비 전체 연구 격자는 구 30개+추가 N15-Y 2개=최대 32개 고유 구조를 뜻하나, v0 30 / BookAnnual-v1 overlay 2로 각 상태를 따로 기록한다. 사용자 지시가 없으면 BT01의 다른 종목수에 연간 W 실험을 무제한 확대하지 않는다.
- 아직 실제 장기 PIT 연구 데이터/사용권 미확보, 1980~2025 목표/2000~2025·2016~2025 진단 상태는 `BLOCKED_ON_DATA`, OOS 미확립. 수익률 생성 금지.

## 4. 구현 수용 기준·모순 반례

1. 1년 만에 구성원 50% 교체되면 `exit_count`/ `entry_count` 일치, 무조건 전년도 구성원을 계속 유지하는 **REWEIGHT_ONLY 버그 실패**.
2. 분기 중 QGV 순위가 변해도 연간 주검정은 매수·매도 0(자연스러운 기업행동 제외). 기업행동·상폐·미체결은 정해진 대로 처리.
3. 12개 시작 월은 각각 **12개월 후에만 재선정**, 매달 새로 고르는 잘못된 구현 실패.
4. 같은 월/날짜/모집단에 대해 연간·분기 모두 최초 선정 종목이 동일해야 하고, 이후 재선정 주기에서만 차이.
5. 내림차순/오름차순 팩터별 BEST10, 점수/업종/분모 재계산 및 NA·동점·미래 공시 누출 없음.
6. 기존 N15-Q 주검정과 N15-Y 신규 주검정은 동일 파일명/experiment_id를 공유하지 않음.
7. 신규 전환을 **'연간 재선정이 확정되었다'**와 **'운영 코드가 연간 재선정으로 전환되었다'**로 구분. 합성 PASS/실데이터 미실행 상태를 정확히 보고.

## 5. 실행 우선순위

1. PR #418 문서와 본 표준 확인·충돌 진단. 책/AAII 연간 재선정 확인 및 12개월 시작 코호트 정확한 원문 정의 출처 찾기.
2. PR #417 구현 소유자에게 변경 영향 전달: 연간 주검정 분기 자리 교체가 아니라 **BookAnnual-v1 연구 등록 새 버전**을 요구한다. 동일 엔진 코드 재사용.
3. 작은 합성 자료로 종목 편입/탈락·거래 수량·현금 대사·12 offset 합성 확인.
4. 자료·라이선스 승인 후 연간 코호트 먼저 실데이터 실행, 분기 민감도 및 시작 월 민감도 이어서 수행.
5. 결과 보고 뒤 별도 승인 없이 운영 QGV/TARGET/실투자 PLAYBOOK 변경 금지.

**서지 사실과 연구 가정 구분:** 연간 종목 재선정은 AAII 자료로 지지; **2월 셋째 월요일·월별 첫 거래일은 우리 연구 날짜**다. 원서 4판에 정확히 동일한 절대 날짜가 나왔다고 주장할 수 없다.
