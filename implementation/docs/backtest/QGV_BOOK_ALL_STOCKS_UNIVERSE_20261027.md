**종목 자격**: 해당 미국 거래일에 NYSE/AMEX(NYSE American)/NASDAQ 등 검증된 미국 공인 상장거래소의 운영기업 보통주·보통주 클래스. ETF·펀드·폐쇄형 펀드·권리증서·우선주·비거래 OTC·중복종류는 기본 제외. **ADR·REIT는 별도 자격 정책/표본 영향 보고**(2014 AAII의 재현 화면은 ADR/REIT 제외; 이것이 4판 모든 전략의 공통 원문 규칙이라고 주장하지 않음). 한 기업 CIK 여러 종목은 점수·분위 계산에서 1번, 거래 종목은 PIT 60세션 거래대금 중앙값/영구 증권 ID 정책으로 하나 선택. 상장·퇴출·합병·분할·상폐를 그 당시 기준으로 추적.

**PIT 시가총액**: 종목/회사 식별자를 대사한 거래가능 주식수(가능하면 당시 기발행 보통주 수) × 해당 시점 가격, 발행사 다중 클래스 총액 계산 정책 명시. **EPS 계산에 쓴 diluted weighted-average shares를 시총 발행주식수로 무조건 대체 금지**. 결정일 당시 알려지지 않은 주식수·재작성된 역사 시총·후일 업데이트된 종목 마스터 사용 금지.

**물가조정 하한**: 기본으로 **2009년 CPI-U 연평균 값 기준 $200,000,000**을 사전등록하고 각 평가일의 이용 가능한 CPI vintage 기준으로 상대 보정:

`floor_USD(t) = 200_000_000 × CPI_asof(t) / CPI_U_2009_annual`

2009년 기준값은 연구자가 2009년 구매력으로 해석하기 위해 선택한 역사상 고정 단위이고, **1980년 투자자가 2009년 CPI를 미리 예견했다고 주장해서는 안 됨**. CPI 발표일 사용 가능성·2009 기준 확정 시점의 역사적 회귀 해석은 별도 명시한다. 배당·배수의 시점 정합성도 개별 검증. 2009년 $200m와 2009년 $205m, 2025년 명목 $200m는 서로 다른 정책임을 결과표에 명시한다. 명목 2억 달러 조건은 별도 진단(기본 공식 모집단 아님).

**유동성**: 시총 문턱은 실제 체결을 보장하지 않는다. 과거 일별 거래대금, 호가 스프레드 및 가격/상폐 수익률, 거래 정지·미체결 비율을 추적한다. 최소 유동성 고정 임계치를 성과 확인 후 고르지 말고 별도 후보를 미리 사전 등록하며, 없는 입력은 `LIQUIDITY_NOT_VERIFIED`.

## 2. 필수 분모·점수 산정의 변화

**중요: Universe504 QGV 백분위 점수를 U-BOOK200의 기업에 그대로 붙이면 안 된다.** QGV v2 점수 산출은 동종업종·미국 전체 발행사 백분위가 섞여 있으므로 다음 자료와 단계가 필요하다.

1. 날짜별 `U-BOOK200` 투자 적격 종목 / 시총 하한 / 제외 사유를 계산하고 고정한다.
2. **그 날짜에 존재하고 공개된 PIT 원지표**로 U-BOOK200의 산업 비교군, 일반기업/금융업 프로필, 원지표 백분위를 전부 **독립 연구 네임스페이스**에서 다시 산정한다. 최초 사업회사 소속이 사후에 바뀐 산업코드로 소급 분류되지 않도록 한다. v2 15요인의 가중치·결측 50%·업종 Q 가치함정 관문은 승인된 현행 의미 그대로 유지.
3. 축 미산출 기업은 기본 분위수 분석 **점수 없음/제외**로 보고, 특히 금융업 공식 V 미지원 때문에 3축 완전 패널에서 제외될 수 있는 비대칭성을 정량화한다. 점수 없음=하위 10%가 아니다.
4. `RESEARCH_QGV_V2_ALL_US` 등의 별도 score_universe/score_basis/experiment_id로 기록하고, **운영 공식 Universe504의 점수나 공식 리더보드라고 부르지 않는다**.
5. 스코어 모집단과 매수 후보 모집단의 구분이 중요한 검증을 위해 세 가지 경우를 분리한다.
   - B0: U-BOOK200 **전체에서 재산정하고 전체에서 거래** (분위수 주연구)
   - B1: U-SPX-HIST **당시 비교군에서 재산정하고 같은 비교군에서 거래** (기존 기준선/진단)
   - B2: U-BOOK200 전체에서 재산정하고 **S&P 구성원으로 후보만 제한** (평가 모집단 효과 분리용 진단)
6. 시점별 PIT 평가 가능률과 투자 가능률, V NA·발행사 수·거래 가능 기업 수, 각 분위의 산업·시총 분포를 비교 표에 함께 제시한다.

## 3. 기존 30개 연구 보호·변경 요청

기존 연구 PR #417의 N=15 분기 주검정과 30개 고정 N 실험은 **유지**한다. 이 파일은 U-BOOK200으로 기존 실험을 강제로 바꾸는 명세가 아니다. 분위수 연구 D1~D10/두 주기의 주가설만 새로운 U-BOOK200을 적용한다.

**결과 해석의 두 층:** (i) 규모 문턱 때문에 실제 선정 종목과 수익률이 달라진 효과, (ii) QGV 백분위 모집단 자체를 넓히며 점수가 달라진 효과. 규모 효과를 분리하지 않고 '시총 2억 필터가 좋다'고 결론 내리지 말 것.

## 4. 역사 자료·실행 관문

1980~2025 목표 및 1975년 준비기간은 유지하지만, 1980년 SEC XBRL 부재·상장폐지 포함 데이터·CRSP/Compustat급 정합성·과거 발행주식수/업종·보고시차·스프레드·라이선스가 미검증이면 **BLOCKED_ON_DATA**다. 2000~2025 / 2016~2025는 별도 기간이 맞는 승인된 자료가 있을 때만 `EXPLORATORY_DIAGNOSTIC`으로 표시한다. 비공개 가격/과거 순위/실제 수익률은 승인된 비공개 위치에서만 저장·처리하고 유료 라이선스 구매/자료 대체/보호 Holdout 무단 사용을 금지한다.
