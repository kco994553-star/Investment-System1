## 2. 양쪽 시장 그룹을 독립 처리

| 시장 그룹 | 투자 가능 모집단 | 각 요인의 BEST10 비교 방식 |
|---|---|---|
| **U-BOOK200 (미국 전체)** | 당시 미국 상장 보통주 + CPI 물가조정 시총 2억 달러 이상 + 거래 가능성 + PIT | 그룹 전체에서 팩터와 QGV v2 점수를 각자 계산, 공통 후보군에서 양쪽 BEST10 대조 |
| **U-SPX-HIST (S&P 500)** | 해당 날짜 S&P 500 편입 기업(유효일 기준), 실제 상폐 이력, 보통주/매매가능성 | 이 그룹만의 팩터와 **새로 계산한 QGV**로 양쪽 BEST10 대조 |

- U-SPX-HIST는 **책의 '대형주(Large Stocks)'와 동의어가 아니다.** 책의 대형주군은 전체 주식군의 평균 시가총액 초과라는 정의다. 추가 U-LARGE-MEAN은 통제 진단이다.
- 두 그룹에서 **동일한 시점·PIT 원지표·신호일·다음 거래일 시가·거래비용**으로 비교한다. 두 그룹 모두 **개별 팩터별 데이터 가용성이 다를 수 있다**.
- 두 모집단의 고유 기준점(QGV v2 W0 BEST10)을 비교할 때 같은 종목의 백분위가 달라질 수 있다. **현재 Universe504의 QGV 공식 리더보드 점수를 외부 시장에 가져오지 않는다.**

## 3. 비교 공정성: 동일한 후보 집합 우선

- 주평가: 같은 날짜, 같은 시장 그룹에서 팩터와 **QGV 세 축을 모두 계산 가능한 종목의 교집합** `ELIGIBLE_BOTH(i,t)`을 만들고, 그 안에서 두 전략의 BEST10을 독립 선정한다. 투자 기회와 자료 누락이 달라 성과가 갈리는 오류를 줄인다.
- 팩터 내림차순/오름차순은 각 ID의 사전 정의를 따른다. QGV W0는 무조건 **높은 점수**가 좋은 방향이다. PER·PBR·PSR·P/CF는 **낮은 10%**가 가치 측면 BEST10이다. 배당·매입·ROE·상대강도는 **높은 10%**다.
- 보조 진단: 각 팩터가 계산 가능한 **고유 전체 후보군**에서 해당 BEST10을 계산한다. 이 결과를 교집합 주평가와 섞지 말고 표에서 `NATIVE_FACTOR_ONLY`로 표시한다.
- 적격 발행사 최소 100개(사전 등록된 연구 가정), 동점은 값+CIK+영구 증권 ID, 한 기업 중복 방지, 결측/음수 등 분모 문제는 NA로 처리. NA를 최악 10%로 넣지 말라. 동점 경계와 QGV/팩터 상위10%의 **구성원 겹침률(Jaccard, 공통수/합집합수)** 보고.
- 낮은 PER이 다른 기업과 비교해 어떤 우위가 있는지 확정하기 전, **최상/최하 10%를 양쪽 모두 관찰**하되 운용 포트폴리오는 사전 명시된 BEST10만 핵심 비교 대상으로 둔다. 개별 요인에 따라 업종 편향·규모 편향이 생길 수 있으므로 업종·시총 중립 진단을 병행한다.

## 4. 자산·기간·비용·종목수 선택

- QGV D1~D10 연구는 2시장×2주기(분기,연간)×10분위 **40개의 롱온리 셀**로 별도 등록. 기존 고정 N 30설정은 보존한다.
- 개별 요인 BEST10: 실제 계산 스펙을 설명한 F01~F15 **15개 후보** × 2시장 × 2주기 = **60개의 후보 전략 셀**을 추가 등록한다. **단 이는 설계상 후보 수이며 실데이터 실행가능·공식 채택을 뜻하지 않는다.**
- F16~F21 6개 복합 주제는 구성요소를 기록하지만 원서 산식·자료 정합성 확인 전 **BLOCKED_ON_FORMULA**이며 60개에 합산하지 않는다.
- 책에 존재하는 주제인 '업종 분석'은 **별도의 업종 성과표**로, 'Market Leaders'/'Small Stocks'는 **별도의 기업군 비교표**로 기록하며 개별 팩터 열에 억지 추가하지 않는다.
- 각 상위10% 코호트 내 **동일가중**, 외부입출금 없음, 이전 완료일 종가 입력/다음 거래 가능일 시가 주문. 분기 2·5·8·11월 셋째 월요일, 연간 2월 셋째 월요일. 매수/매도 각각 기본 10bp, 0/20/25/30bp 민감도. 1980~2025 목표, 2000/2016 시작은 데이터 검증된 경우 **별도 제한 진단**. 상폐·배당·분할·거래정지·현금·수익률·OOS는 기존 #417 연구 계약 계승.

## 6. 사전검증·오류 반례·다중 비교

- 작은 EPS(특히 음수/0), 음수 현금흐름, 음수 자본·EV/EBITDA, 분모 0, 음수 배당/대규모 신주발행/특별배당, 발행 주식수 분할 후 변환, 상폐 당일 가격, 배당락 이중 계산, 시장 상장자격 변경, 평가일 주가 미래값.
- 팩터 각자 유효한 기업 수가 100 미만이면 `NO_DECILE_COVERAGE`. 고수익을 관측한 전략만 선택하거나 복합 산식을 나중에 바꾸면 해당 자료를 OOS처럼 재평가 금지.
- 15개 팩터×2시장×2주기 및 40개 QGV 분위 관측의 **다중 비교·선택 편향**을 보고한다. 선택할 때는 사전 등록된 H0/H1과 집단별 요인 효과의 정확한 분모를 사용하며, 향후 기준 채택은 별도 사용자 승인.
