## B. 사용자 요청을 정확히 구현

1. **두 독립 시장**: `U-BOOK200` = 당시 미국 상장 보통주 중 물가조정 시총 하한 2억 달러 이상, 별도 시총 상한 없음. `U-SPX-HIST` = 당시 진짜 S&P500 구성원 전체. **S&P500 ≠ 책의 Large Stocks**(평균 시총 초과)임을 명시하라. 책식 Large Stocks를 추가하려면 별도 진단 U-LARGE-MEAN.
2. `U-BOOK200` 문턱은 연구자가 채택한 **2009년 달러 구매력 $200m 기준**. 당시 이용 가능한 CPI/가격/기발행주식수를 사용하고 기준 연도값은 소급 표준화로 따로 기록. 이 숫자를 4판의 정확한 물가 기준연도라고 주장하지 않는다. 명목 $200m/2009 실질 $205m 비교는 별도.
3. 각 그룹·평가일에서 **당시 15요인 원자료로 QGV v2 W0를 완전히 새로 산정**(업종·금융 프로필·누락/관문/TYPE_SCOPE 포함); Universe504 공식 백분위·현재 공개 V·현재 TARGET 값을 복사하지 않는다. 선택 후보와 점수 백분위 모집단을 분리해 기록한다.
4. QGV **D1 최고점 10%~D10 최저점 10%**, 10분위 전부 롱온리·동일가중. 하위10%는 공매도가 아니다. 순위는 score desc→CIK asc→permanent id asc; 분위 할당 `1 + floor(10*(rank-1)/n)`. 평가일마다 n 바뀜. 최소 적격 발행사 100명이라는 연구 가정 미충족이면 NO_DECILE_COVERAGE.
5. 위 2시장×2주기(분기/연간)×10분위 **40개 롱온리 셀**을 연구 등록부에 추가한다. 이 40은 기존 고정 N=10·15·20·25·50/W0~W3의 30개 실험과 **별개**다. 기존 N15/분기 주검정을 덮어쓰지 않는다.

## C. 4판 주제의 상위 10% vs QGV 상위 10%

다음 팩터 F01~F15는 **책 4판 주제에 근거한 사전 지정 연구 후보**다. 단순한 하위 10% '숫자 큰 순'이 아니라 경제적 방향을 맞추어 BEST10을 계산한다.

- 시총 가장 큰 10%와 작은 10%(특성 검증, 어느 쪽이 우수하다는 선입견 없음).
- 저PER(양의 EPS만), 고 EBITDA/EV, 저 주가/영업현금흐름, 저PSR, 저PBR(양의 장부가치).
- 고 배당수익률, 고 순자사주매입수익률, 고 주주수익률(배당+순자사주매입).
- 고 1년 EPS 성장률, 고 이익률, 고 ROE, 고 1년 상대가격강도.
- 5항목 AAII 근사 복합가치(저 PE·PS·P/FCF·EV/EBITDA와 고 주주수익률; 3/5 이상 가용) — **책의 복합 전략을 정확히 재현했다고 부르지 않는다**.

팩터 변수·산식·책 원문과의 일치도·모집단·공시시점을 JSON 스펙으로 고정하고, 사전 정의되지 않은 항목을 성과를 본 뒤 추가하지 않는다. F16~F21(회계 건전성·품질·다중팩터·이상적 성장/가치/성장가치 결합)은 책의 **주제 등록만 완료**, 원문 방법과 역사 데이터가 검증될 때까지 BLOCKED_ON_FORMULA. 단지 데이터가 없다는 이유로 0을 주지 않는다.

- 위 **F01~F15 × 2시장 × 2주기 = 60개**는 잠재적 BEST10 비교 코호트이며 데이터가 없으면 실행 미완료로 표시한다. F16~F21은 별도 차단 등록. 모든 팩터의 하위 10%는 추가 진단, 상위10% 전략과 구분한다.
- **주비교를 공정하게**: 동일 시장, 동일 날짜, 동일 팩터와 QGV 모두 가용한 교집합 안에서 팩터 BEST10과 QGV BEST10을 각각 추리고 동등한 초기 자본·거래 규칙으로 매수한다.
- 보조: 각 팩터 원래 적격 모집단 전체에서 추린 BEST10을 `NATIVE_FACTOR_DIAGNOSTIC`으로 추가. 주비교 성과와 뒤섞지 않는다.
- 동일 10% 비중은 **그 평가일 적격 발행사 수의 약 10%**, 고정 N=50과 혼동하지 않는다. 장부 등 부적격 요인이 매우 많아 집단이 100개 미만이면 진단 보류.
- 가치 지표(PER/PBR/PSR/P/CF)의 **낮은 값 10%가 BEST10**, 배당·ROE·EBITDA/EV·모멘텀의 **높은 값 10%가 BEST10**이다. 시총은 상·하 양극단 별도 특성 집단이다.

## D. 체결·편향·성과 검증

공통 비교는 기존 #417의 역사 PIT·공시시차·회사행동·배당·상폐·현금·USD 100,000·소수주·동일가중·비용 가정을 변경하지 않는다. 매수/매도 각각 10bp를 주비용으로 하고 0/20/25/30bp 민감도를 사전 집행한다. **사용자 최신 기준: 책식 연간 전체 종목 재선정이 본 주검정**(원래 연구의 2월 셋째 월요일 및 휴장 이월은 시작 월 통제 가정이며 원서의 확정일 아님). **분기 2·5·8·11월은 보조 주기 민감도**. 재선정은 그날 전체 기업 점수/순위를 다시 계산하고 새 편입/탈락 종목을 교체하는 것이며, 유지 종목 비중만 조정하는 REWEIGHT_ONLY가 아님. 신호일 완료 종가 정보로 주문을 결정하고 다음 거래 가능 시가에 체결하며 미래 시가를 보유 금액 목표 계산에 사용하지 않는다. SPY 1993년 이전에 가짜 수익률을 만들지 않으며 S&P500 총수익 시계열의 라이선스를 확인한다.

반례를 별도 합성 데이터로 작성하고 우선 실행하라:
- n=100/101/109/500/누락/동점·한 CIK 여러 상장 종류, 최고점 방향, 1/N 체결 현금 보존.
- 동일 기업이 전체시장 상위10%지만 S&P500 다른 분위가 되는 사례(분모 분리), S&P에서 미편입·퇴출, 시총 하한 물가 변동, ADR/REIT 처리.
- PER 낮지만 EPS≤0, PBR 분모≤0, CFO≤0, 순자사주매입률 음수, 특별배당 및 주식분할 이후 share count, V NA 금융, 1년 EPS 기저 왜곡.
- 데이터 없음 기업을 하위 10%로 넣지 않음. 학습 지표 정정 공개 전 접근 금지, 기업행동 결산일/실적 공시일 구분.
- 책 조합 F16~F21 원문 미확정 상태에서 임의 버전 채워 넣는 실수, 단일 팩터·QGV 단독 점수와 동일 팩터 이중 반영.
- 장기 1980~2025 QGV 15요인 PIT 재현 실패 시 BLOCKED_ON_DATA, 2000/2016 시작 자료 진단과 구분, 실제 실행 불가 시 합성 검증만 표시.
