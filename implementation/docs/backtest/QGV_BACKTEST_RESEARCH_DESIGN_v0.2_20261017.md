# QGV 백테스트 연구 설계안 v0.2
작성일: 2026-10-17 · 대상: Investment-System1 · 상태: 제안/설계, 성과 결과 없음

## 1. 목적과 이번 작업 범위

주질문: 현재 QGV 계산·가중치가 시장 및 단순한 대안보다 유용한 투자결과를 만드는가?

부질문:
- 상위 10·15·20개 보유에서 결과가 유지되는가?
- V 추가가 QG만 사용할 때보다 도움이 되는가?
- 기술적 분석 또는 매크로 매수 정책이 비용 후 성과·위험을 개선하는가?
- 개선이 종목 선정에서 오는가, 업종 쏠림·현금 보유·특정 종목에서 오는가?

이 문서는 연구 기본안이다. 운영 가중치, TARGET 확정, 매크로 재가동, 차트 구현 착수에 대한 새로운 승인이 아니다. 현재 운영 수정·숫자 대조·TARGET 작업과 10/19 전진 관측은 기존 순서대로 진행한다. 실제 과거 기업 선정이나 수익률 계산은 아직 하지 않았다.

지금 진행할 일은 기존 구현 조사, 데이터 확보 가능성·비용 확인, 실행 가능한 규칙으로의 정리, 합성 데이터 검증까지다. 유료 데이터 구매, 대량 수집, 실제 성과 실험은 자료·규칙·실행 범위가 구체화된 뒤 진행한다.

## 2. 비교 실험 목록

각 유형을 N=10·15·20으로 실행해 21개를 사전 등록한다. N=15가 주검정이고 10·20은 집중도 민감도 확인이다. 결과가 가장 좋은 N으로 주검정을 바꾸지 않는다.

| ID | 유형 | 검증 질문 | 순서 |
|---|---|---|---|
| A | 현재 QGV | 현행 점수의 투자 효용 | 1차 |
| B | Q·G·V 최종 축 비중 각각 1/3 | 현재 축 가중치가 단순 균등보다 나은가 | 1차 |
| C | 각 축 내부 요인 비중 균등 | 현재 내부 가중치가 단순 균등보다 나은가 | 1차 |
| D | QG만, V 제거 | V의 추가 효과가 있는가 | 1차 |
| E | A + 기술적 매매 규칙 하나 | 진입·이탈 시점 규칙의 추가 효과 | 2차 |
| F | A + 매크로 매수 정책 | 매수 제한·속도 조절의 추가 효과 | 2차 |
| G | A + 동일 기술적 규칙 + 동일 매크로 정책 | 두 장치의 결합 효과·중복 | 2차 |

첫 실행 묶음은 A~D의 12개다. E~G의 9개는 규칙과 가격·매크로 자료가 준비된 뒤 이어간다. F·G의 매크로 정책은 아직 기계적으로 완전히 정의됐다고 보지 않는다. 준비되지 않은 유형 때문에 A~D 준비를 멈추지 않는다.

B는 기업 유형 조정까지 거친 최종 축 비중을 1/3로 바꾸는 통제다. 내부 요인, 결측 규칙, 가치함정 처리 등은 유지한다. C는 내부 가중치만 바꾸고 최종 축 가중치는 A와 같다. D는 Q:G의 상대 비중을 유지해 재정규화한다. 각 변화가 결측 허용 범위에 주는 영향도 기록한다.

후속 후보는 별도 등록한다: Q/G/V 단독, 점수 5분위의 후속 수익 단조성, 박스권 돌파, 이중 바닥, 월간·연간 리밸런싱, 점수 비례 보유. 이들을 지금부터 조합해 무제한 탐색하지 않는다.

## 3. 현재 가중치의 정확한 뜻

현재 점수는 단순히 Q/G/V=34/33/33만 적용한 결과가 아니다. 조사한 문서에는 프리셋과 기업 유형 비중을 결합하고, 결측 요인을 재정규화하며, 가치함정 규칙을 적용하는 구조가 있다.

따라서 실행 전 다음을 한 구성 파일로 고정한다.
- 계산 코드 커밋, calc_version, 연구 구현 버전.
- 프리셋, 기업 유형·소속도 산출법, 최종 축 비중 계산법.
- Q/G/V 내부 요인·비중, 업종 비교 모집단, 최소 비교 기업 수.
- 결측·유효성·최신성·가치함정·경기민감 이익 정상화 규칙.
- 과거 날짜에 적용할 기업 식별자·상장 주식 종류·업종·유형.

오늘의 유형, 오늘의 주식수, 최종 수정된 과거 재무제표를 과거 시점에 그대로 넣지 않는다. 현재 규칙을 과거에 적용하는 연구와 당시 운영됐던 전략의 복원을 구분한다.

가중치 효과를 분리하는 주분석에서는 각 시점 A~D가 모두 점수를 낼 수 있는 공통 후보군을 사용한다. 제안 기본안은 Q·G·V 축이 모두 계산 가능한 기업이며, 축 내부 부분 요인은 현행 규칙을 따른다. 금융 등 V 정의가 없는 프로필의 제외 수를 별도로 보고한다.

별도 현실 적용 분석에서는 각 유형의 실제 결측·편입 규칙을 적용한다. 공통 후보군 분석과 현실 적용 분석을 섞지 않는다. C의 가중치 변경으로 가용 비중 기준을 넘나드는 경우를 따로 집계한다. QGV 자료가 있는 기업만 남긴 효과를 가중치 효과로 해석하지 않는다.

## 4. 기간 후보와 데이터 조건

| 구분 | 제안 기간 | 용도 |
|---|---|---|
| 주분석 후보 | 2016~2025 | 여러 시장 환경에서 고정 규칙 평가 |
| 세부 보고 | 2016~2019 / 2020~2022 / 2023~2025 | 시기별 일관성; 최적 기간 선택용 아님 |
| 최근 부록 | 2026년 초~2026-10-16 | 최근 구간 참고; 주분석과 별도 |
| 전진 관측 | 2026-10-19 미국 거래일 이후 | 실제 관측 시점에 남긴 기록으로 평가 |
| 후속 확장 | 2008·2011 등을 포함하는 더 긴 구간 | 과거 자료가 확보될 경우 별도 등록 |

2016년은 자료 확보가 확인된 시작일이 아니다. 5년 재무 이력·기술적 지표 준비 구간까지 거슬러 확보할 수 있는지 먼저 확인한다. 수익률을 본 뒤 시작일을 바꾸지 않는다. 기존 Holdout으로 보호하는 날짜·대상이 있으면 읽거나 실험하지 않고 제외 범위를 기록한다.

주식 매수 시작은 2016년 첫 정규 리밸런싱일 후보로 하고 정확한 첫·마지막 평가일을 사전 고정한다. 그 이전 자료는 지표 준비에만 사용한다. 모든 비교 계열의 날짜를 맞춘다.

현재 가중치를 2026년에 설계했으므로 2016~2025를 자동으로 “미사용 검증 구간”이라고 부를 수 없다. 시점 일치 자료는 미래 입력 유입을 막지만, 과거 시장에 대한 설계자의 지식까지 지우지는 못한다. 이 연구는 고정 규칙의 소급 평가이며 전진 관측이 별도로 필요하다.

SEC XBRL API만으로 과거 투자 가능 종목 전체, 상장폐지 수익, 과거 가격을 모두 확보할 수 있는 것은 아니다. SEC 문서는 XBRL 의무화 시작을 2009년으로 설명한다. 장기 구간은 자료 가용성 확인이 선행돼야 한다.

## 6. 공통 매매 가정 제안

- 가상 초기 자산 100, USD, 외부 입출금 없음. 세전·거래비용 차감 결과를 주분석으로 한다.
- 분기 재선정: 기존 플레이북의 2·5·8·11월 15~21일 사이 월요일; 휴장이면 다음 미국 거래일.
- 직전 완료 거래일의 정해진 컷오프까지 이용 가능한 자료로 점수를 산출하고 다음 거래 가능 시가에 체결한다. 같은 종가로 신호와 체결을 동시에 만들지 않는다.
- N종목 동일 비중. 여기서 동일 비중은 보유 금액의 비중이며 QGV 점수 가중치와 다르다.
- 연구 기본안은 추가적인 TARGET 카드 판단·테마 한도를 붙이지 않는 순수 상위 N 선정이다. 실제 TARGET 운용의 복원 결과로 표현하지 않는다. 기존 점수 자체의 가치함정 등은 A에 포함한다.
- 유효 후보가 N보다 적으면 종목 수를 보고하고 빈 자리는 현금으로 둔다. 미래 데이터를 가져와 N을 채우지 않는다.
- 분기 사이에는 A~D의 순위 변화만으로 거래하지 않는다. 기업행사·상장폐지는 사전 정의한 처리 규칙을 따른다.
- E~G는 분기마다 동일 QGV 후보 목록을 받는다. 기술 신호 불충족 종목을 다음 순위로 몰래 교체하지 않고 해당 몫을 현금으로 둔다.
- 분기마다 자산을 N개 몫으로 나누는 방식으로 기술적 진입·청산을 추적한다. 몫 안에서 주식/현금 전환을 하며 매일 전체 포트폴리오를 자동 동일 비중으로 재조정하지 않는다. 다음 분기에 동일 비중을 재설정한다.
- 결합형 G에서는 매수만 “기술적 허용 AND 매크로 허용”으로 제한한다. 기술적 청산을 매크로가 막지 않는다. 세부 재진입은 규칙 문서에 명시한다.
- 수수료·스프레드·슬리피지를 구분하고, 체결 비용의 근거를 먼저 확보한다. 예시 민감도 0/10/25bp(매수·매도 각각)는 가정이며 실제 비용 추정치가 아니다. 비용을 중복 차감하지 않는다.
- 현금 수익은 당시 이용 가능했던 달러 단기금리/현금 대안의 정의와 출처를 고정한다. 자료가 없으면 무이자 현금 가정을 명시하고 영향도 보고한다.
- 배당, 분할, 합병, 분사, 상장폐지와 주식 종류를 처리한다. 조정 가격 수익에 배당을 다시 더하지 않는다. 기술 신호용 OHLC와 체결·자산 평가용 가격의 기준을 맞춘다.
- 거래정지·시가 부재는 체결 없음으로 처리한다. 가격 소실을 0% 수익으로 만들거나 손실 종목을 표본에서 삭제하지 않는다. 최종 정산 자료가 없으면 해당 결과의 한계를 표시한다.
- 동점은 미래 수익과 무관한 고정 식별자 순서로 처리한다. 세금·환율·월 적립식·정수 주식 수는 별도 개인 운용 시나리오로 분리한다.

## 7. 기술적 분석의 첫 규칙 후보

### TA-1: 120거래일 이동평균 추세 조건 — E/G 주후보

선택 이유는 기존 화면에 SMA120 계산이 있고 규칙이 단순해 QGV 선정 효과와 매매 시점 효과를 나누기 쉽기 때문이다. 수익이 검증됐기 때문이 아니다. 기존 화면의 연구용 표시를 매매 규칙으로 바꾸는 것은 새로운 연구 가설이다.

- 완료된 일봉 종가 > 같은 기준 가격의 SMA120: 보유하지 않은 분기 선정 종목은 다음 거래 가능 시가에 해당 몫으로 진입.
- 종가 < SMA120: 보유 종목은 다음 거래 가능 시가에 청산.
- 종가 = SMA120: 현재 상태 유지.
- 분기 선정에서 빠지면 다음 정규 리밸런싱 체결 시 정리.
- 최소 120개의 유효한 완료 봉 필요. 이력 부족·가격 기준 불연속 미확인 시 신규 진입 불가.
- 보유 후 신호 자료가 빠졌다고 임의 청산하거나 “정상” 판정하지 않는다. 마지막 상태를 유지하고 미판정 기간을 기록한다. 가격 평가 자체가 불가능한 경우는 성과 완전성 문제로 별도 처리한다.
- 60/120/200 중 성과 좋은 기간을 골라 결과를 내지 않는다. 추가 기간은 새 실험으로 사전 등록한다.
- 잦은 재진입, 회전율, 비용, 현금 기간을 반드시 보고한다.

### TA-2: 박스권 돌파·실패·무효화 — 후속 후보

기존 차트 설계의 피벗 확인 시점, ATR 완충, 실패·무효화 조건을 연구 버전으로 고정해 재사용한다. 단순 그림 인식률이 아니라 실제 다음 봉 체결 결과를 평가한다. 같은 봉에서 확인 전 피벗을 사용하지 않는다. 여러 박스가 겹칠 때 선택법, 재진입, 청산, 최대 대기기간을 확정한 뒤 실행한다.

### TA-3: 이중 바닥 확인 — 후속 후보

두 저점이 보였다는 이유만으로 진입하지 않는다. 넥라인 확인 가능 시점 이후 진입, 실패·무효화·만료·동시 패턴 우선순위를 정한다. 이중 천장은 롱 포지션 청산 연구로 시작하고 공매도를 기본안에 넣지 않는다.

TA-1은 비교용 기준선, TA-2·3은 패턴의 추가 가치 검증용이다. 패턴 적합도는 상승 확률이 아니다. 세 후보는 설계에 포함하되 모든 매개변수를 동시에 최적화하지 않는다.

## 8. 매크로: 기존 정책과 새 실험의 경계

확인한 PLAYBOOK은 매크로를 “무엇을 얼마나 빨리 살지”에 적용하고 매도 판단에는 쓰지 않는다. 따라서 “위기면 기존 주식을 전부 팔아 현금화”는 기존 정책의 재생이 아니다.

- M0: 참고 표시만. 현재 게이트 비활성 정책과 대응한다. A와 매크로 때문에 거래가 달라지면 안 된다.
- M1: 기존 매수 정책을 재생. 정상/경고/위기, 경기민감 매수 제한, U3 예외와 분할 매수 속도를 반영하되 매크로 자체의 강제 매도는 없다. F/G의 후보는 이것이다.
- M2: 100/50/0% 노출 전환 또는 위기 강제 현금화. 별도 신규 전략 가설이며 이번 21개에 몰래 포함하지 않는다.

M1 실행 전에 확인할 대응표:
1. 다섯 경고등의 원자료·발표 시각·당시 공개치. 사후 개정값을 당시 값으로 쓰지 않는다.
2. M-RULE C를 가설로 표시. 물가 조건과 다른 경고등 조합을 정확히 구현한다.
3. U3의 시장·업종 주도 하락, 재무 안전, V 개선 조건을 당시 자료로 기계적으로 판정할 수 있는지.
4. 사용자 판단 카드가 필요한 조건을 사후 인간 판단으로 채우지 않는 방법.
5. 외부 입금이 없는 연구 계정에서 “입금+현금/6”, 분할 매수, 보류 자금의 다음 분기 처리.
6. 경고 해제·자료 부족 때 보류 주문의 재개 시점과 기술적 신호와의 우선순위.

이 중 재현 불가능한 조건은 명시한다. 단순화가 필요하면 “M1 근사”라는 별도 실험으로 등록하고 사용자 결정 사항으로 남긴다. 과거 재생의 M1 활성화는 운영 M-REENABLE 승인이 아니다. 2022 한 구간으로 검증 완료를 선언하지 않는다.

## 9. 데이터 감사와 구현 재사용

필수 조사표: 자료 종류 / 기간 / 과거 시점 복원 가능성 / 누락·상장폐지 처리 / 라이선스·비용 / 저장 위치 / 확보 여부.

필요 자료:
- 과거 투자 모집단과 편입·퇴출 이력, 티커 변경·CIK·주식 종류.
- 당시 제출된 재무와 수정 제출의 공개 시점; 정확한 기간·태그·단위.
- 당시 기준 주식수·기업행사·주가·배당·거래 가능성.
- 당시 업종·유형 판정에 필요한 입력과 동시점 비교 모집단.
- 매크로 발표치와 개정 이력, 당시 시장·신용 가격.

현재 504개 기업을 과거로 그대로 가져가는 결과는 “현재 생존 종목에 한정한 탐색”으로만 표시한다. 정식 과거 투자 가능 성과로 쓰지 않는다. 더 좁은 GENERAL 공통 후보군을 쓰면 그 적용 범위를 결과 제목에 표시한다.

조사한 기존 코드는 재사용 후보이며 완성된 v2 백테스트로 간주하지 않는다.
- validation/backtest.py: toy 경로와 공식 결과가 아닌 상태를 구분.
- validation/historical.py: 과거 후보 경로가 현재 v2 Q/G/V 규칙을 모두 재현하는지 점검.
- providers/sec_vintage.py: 제출일이 없을 때 기간 종료일로 대체하는 경로를 과거 시점 연구에 그대로 쓰지 않는다.
- 제출 날짜만 있으면 장 시작 전에 공개됐다고 가정하지 않는다. 보수적으로 다음 거래일부터 사용하거나 접수 시각을 확보한다.
- 공용 운영 선택 함수를 임의 수정하지 않는다. 연구용 어댑터를 분리하고 필요한 영향 범위를 검증한다.

합성 검증은 미래 제출 차단, 수정 공시 시점, 과거 모집단, 분할 중복 보정, 다음 봉 체결, 상장폐지, 배당 이중 합산, 비용, 결측·동점·종목 수 부족, 기술 신호 확인 시점, 매크로 무매도 정책을 중심으로 한다. 구현을 그대로 복제한 테스트보다 실제 오류를 잡는 사례를 쓴다.

과거 연구의 자료 커버리지와 현재 게시 Q/G 각각 454개 조건은 다른 지표다. 현재 90% 게시 조건을 모든 과거 날짜의 임의 통과 기준으로 복사하지 않는다. 과거 시점별 산출·탈락 수와 편향을 보고한다.

## 10. 평가 지표와 판단 방식

| 범주 | 필수 지표 | 해석 |
|---|---|---|
| 수익 | 비용 전·후 CAGR, 누적 수익, 시장 CAGR과의 차이(%p) | CAGR 차이를 회귀 알파라고 부르지 않음 |
| 손실 | 최대 낙폭, 최악 월·분기, 회복 기간 | 종료일까지 미회복이면 그대로 표시 |
| 위험 대비 | 연환산 변동성, Sharpe, Information Ratio | 현금금리·주기·연환산 방식 명시 |
| 일관성 | 연도별·구간별, 12/36개월 이동 성과, 시장 상회 비율 | 겹치는 기간을 독립 표본으로 세지 않음 |
| 방어/참여 | 상승·하락 시장 참여율, 평균·최대 현금 비중, 시장 베타 | 현금 효과와 신호 효과 구분 |
| 운용 부담 | 회전율, 총 비용, 거래 횟수, 평균 보유 기간 | 비용을 넣으면 사라지는 우위 확인 |
| 집중 | 업종·유형 비중, 상위 종목 기여도 | 몇 종목·한 업종이 전체 결과를 만드는지 |
| 자료 품질 | 시점별 적격 수, Q/G/V 가용률, NA·추정·유지 입력 수 | 숫자가 좋아도 자료 오류면 판정 불가 |

주대조는 A15 대 시장, A15 대 B15·C15, A15 대 D15다. E15/F15/G15는 준비 후 A15와 비교한다. 10·20종목은 강건성 자료다. 모든 시도와 변경을 남기고 실패한 결과도 표에 넣는다.

불확실성은 같은 달의 전략·시장 수익을 함께 재표집하는 블록 방식 등 시간 의존성을 고려해 추정한다. 95% 구간을 쓰더라도 독립 일수로 표본을 부풀리지 않는다. 다중 비교·탐색 횟수와 경제적으로 의미 있는 개선 폭을 함께 보고한다. 검정 방법·블록 설정·최소 의미 개선 폭은 수익을 보기 전에 분석 계획에 고정한다.

판정은 하나의 종합 점수로 압축하지 않는다.
- 지지 근거 있음: 사전 지정 비교에서 비용 후 우위가 보이고 불확실성·기간·집중도 점검이 이를 뒷받침.
- 방어 효과 있음: 수익 우위와 별개로 낙폭·회복에서 개선, 현금·노출 효과를 함께 설명.
- 증거 부족: 차이가 작거나 구간·종목 의존, 불확실성이 큼.
- 지지 못 함: 시장 또는 단순 대안에 일관되게 뒤지거나 비용 후 효과 소멸.
- 판정 불가: 미래 정보·생존 편향·가격/정산 누락 등으로 해석 불가.

“통계적으로 유의하지 않음”을 곧 “효과 없음”으로 쓰지 않는다. 반대로 소급 평가의 유의성을 미래 수익 보장으로 쓰지 않는다. 숫자 기준을 맞추기 위해 가중치를 바꾸는 작업은 별도 후속 연구다.

## 11. 결과 보고서 형식

첫 페이지의 질문은 세 개다: 현재 가중치가 도움이 됐나 / TA·매크로가 추가로 도움이 됐나 / 실운용에 옮길 근거가 충분한가.

이어 다음을 낸다.
1. 모든 등록 실험의 상태·결과 표. 미실행/자료 부족도 삭제하지 않고 표시.
2. 동일 축의 누적 자산·최대 낙폭 추이·시장 대비 상대 자산 차트.
3. 연도별·구간별 성과, 10/15/20 비교, 비용 민감도.
4. 현금·베타·업종 비중과 종목별 기여도; 방어 개선의 원인.
5. 매 리밸런싱의 기업 목록, Q/G/V, 최종 가중치, 선정·제외 사유, 주문·체결·보유 내역.
6. 실패·보류 주문, NA·추정·누락 자료, 가격 기준·분할·정산 문제.
7. 코드·규칙·자료 버전, 시점 컷오프, 시도 횟수, 한계와 미해결 사항.
8. 현행 유지 / 추가 검증 / 운영 변경 제안의 구분. 결과만으로 운영 규칙을 자동 변경하지 않음.

가격·EV·V·순위·개인 운용 정보를 공개 저장소·공개 Actions 로그에 쓰지 않는 기존 원칙을 지킨다. 실데이터 연구와 성과 산출물은 허용된 비공개 환경에 둔다. 공개 코드·문서의 예시는 합성 데이터로 한다.

## 12. Claude Code에 전달할 작업 지시

아래 작업은 기존 운영 대기열과 독립적으로 할 수 있는 조사·설계부터 진행한다. 특정 점검 시각까지 아무 일 없이 대기하지 않는다. 실제로 선행 결과가 필요한 작업만 의존 사유를 적고 보류한다.

1. 이 문서를 연구 설계 후보로 검토하고, 기존 승인 결정과 다른 신규 제안을 구분해 BACKTEST_RESEARCH_PLAN.md에 정리한다. CURRENT_HANDOFF에는 링크와 현재 상태만 남긴다.
2. 현행 v2 계산 코드·가중치·유형 조정·결측·가치함정 규칙의 정확한 경로와 버전을 조사한다. A~D의 차이를 최소 설정 변경으로 표현한다.
3. 2016~2025 후보 구간에 필요한 자료의 확보 가능성·비용·이용조건 표를 만든다. 현재 504개만으로 정식 결과를 만들지 않는다. 기존 Holdout은 보호한다.
4. 21개 실험을 등록하되 먼저 A~D 12개를 준비한다. N15 주분석, N10/20 민감도, 시장·공통 모집단 비교를 명시한다.
5. TA-1은 새 연구 가설 후보로 명시하고 TA-2·3의 재사용 가능성을 조사한다. 매크로 M1은 PLAYBOOK의 무매도 원칙과 U3 조건을 재현할 수 있는지 먼저 대응표를 낸다.
6. 공시 공개 시점·수정치·기업행사·상장폐지·다음 봉 체결·비용·결측 처리의 합성 검증을 준비한다. 공용 운영 함수를 무단 변경하지 않는다.
7. 보고서 틀을 만들고 계산 가능한 지표·부족한 입력을 표시한다. 아직 수익률이나 과거 선정 기업을 추정해 채우지 않는다.
8. 다음 보고는 (a) 준비된 실험, (b) 데이터 제약, (c) 실제 결정이 필요한 차이, (d) 기존 코드 재사용 범위 네 가지로 한다. 기술적 분석·매크로의 미해결 항목이 A~D 준비를 막지 않게 한다.
9. 기존 운영 수정, 숫자 재대조, TARGET 확정, 10/19 전진 관측은 기존 승인 순서대로 계속한다. 이 연구를 새로운 운영 차단 조건으로 추가하지 않는다.
