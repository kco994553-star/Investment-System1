## 0. 공통 원칙 (모든 화면)

- **하단 메뉴 5개:** 오늘 / QGV / 기술 / 매크로 / 검증. 현재 탭은 굵은 글씨와 위쪽 막대로 표시.
- **분석 흐름 번호:** 1 QGV → 2 기술적 분석 → 3 매크로 → 4 검증·연구. 각 화면 머리에 번호 배지.
- **QGV 하위 화면:** 상단에 `← QGV`와 소분류(내 투자 / 종목 찾기 / 시장 정보 / 성과)를 표시.
- **카드형 레이아웃:** 흰 카드, 둥근 모서리, 회색 배경(#F4F4EF), 강조색 짙은 초록(#1E4D43). 숫자는 고정폭(tabular-nums).
- **상태 칩 색 규칙**

  | 상태 | 색 |
  | --- | --- |
  | 사용 가능·정상 | 초록 |
  | 부분·근접·경고 | 주황 |
  | 관찰 | 파랑 |
  | 재평가·위험 | 빨강 |
  | 준비 중·자료 없음 | 회색 |

- **결측 표시:** `[—]` 또는 `NOT_AVAILABLE`. 0으로 대체하지 않음. 합성·예시 값에는 "모양 예시 · 실제 값 아님"을 명시.
- **데이터 배지:** 데이터 상태(LIVE / FROZEN / DEMO / NOT_AVAILABLE), 신선도, 기준 시각, 점수 기준 버전(v1 · 보정 전)을 화면 머리에 표시.
- **개인 데이터는 기기 전용:** 보유, 거래, 시트 ID, 관심 기업, 프로필. 공개 저장소·Pages에 올라가지 않음을 화면 문구로 안내.
- **주문 없음:** 매수·매도·주문·이체 기능 없음. 판단 결과는 신호만 보여 주고 지시하지 않음.
- **분류 3축 분리:** 산업(SEC SIC 기반 업종군, GICS는 유료라 미사용) / 전략 테마(ETF 보유 기반 자동) / 투자 유형(8개, 소속도). 서로 상위·하위 개념이 아님.
- **QGV는 격리:** 기술·매크로 결과가 QGV 원점수를 바꾸지 않음. 원 QGV와 유형조정 QGV를 함께 보존·표시.

## S01 오늘 (Main, 하단 '오늘')

- **헤더:** 프로필 표시, 전체 검색, 기준일 · 시세 상태.
- **통합 판단 카드:** 규칙 잠정 버전, 세 시스템(QGV·기술·매크로) 상태 행, 결과 문구. 아래에 "매수·매도 지시 아님, 주문 기능 없음".
- **목표 대비 실제:** 총 평가액, 테마별 목표→실제와 초과·부족 칩, 집중도(예: 기술 관련 테마 합계).
- **주의할 것:** 재평가 신호, 매크로 경고, 관심 기업 변화를 모아 표시.
- **많이 벗어난 종목:** 목표→실제 차이 상위. 보유가 없으면 "보유 입력하기" 버튼.
- **시스템:** 분석 흐름 4단계 카드(번호·상태 칩·하위 항목).
- **데이터 기준:** 목표 비중 버전, QGV 기준 버전, 시세·환율 상태, 보유 정보 상태.

## S03 포트폴리오 (Portfolio, QGV · 내 투자)

- **헤더:** 분기 선택, 배지(TARGET 사용자 v0 / ACTUAL 상태 / 시세·환율 시각). 보기 전환 칩.
- **요약 4칸:** 평가액은 입력 시세로만 계산하고, 평균 매입가를 시세로 쓰지 않음.
- **분기 필수 시각화 3종 (분기 스냅샷 고정)**
  1. 산업 구성 도넛: 업종 근거가 없으면 "자료 없음". 테마로 대신 채우지 않음.
  2. 투자 유형 구성: 유형별 독립 도넛. 중복이 있어 합계가 100%를 넘을 수 있음.
  3. 유형 중복 조합: 정확한 조합 기준이라 합계 100%. "미분류"는 별도.
- **전략 테마 목표 대비 실제:** 산업과 다른 축. 테마 쏠림 경고도 여기에 표시.
- **보유 종목 표:** 기업(티커·시총 순위) | 수량 | 평단 | 현재가 | 평가액 | 실제 | 목표 | 차이 | QGV | 신뢰도 | 손익 | 위험. 상단에 "보유 입력" 버튼.

## S13 전략 프로필 (StrategyProfile, QGV · 내 투자)

- **탭:** 기본(공식) / 내 프로필. 배지: 점수 기준 v1 OFFICIAL, 보정 전.
- **요소별 비중 표 (막대 + 성숙도 태그, 축별 합 = 100)**

  | 축 | 요소 (비중) |
  | --- | --- |
  | Q | 경쟁우위 20 · ROIC−WACC 20 · 시장지위 15 · FCF품질 15 · 마진품질 10 · 재무건전성 10 · 경영진 10 |
  | G | 향후 3~5년 성장 25 · 성장효율 20 · 매출성장 15 · EPS·주당FCF 15 · 지속성 15 · 산업대비 초과 10 |
  | V | 내재가치 25 · 역DCF 20 · 동종비교 15 · 과거밸류 15 · 안전마진 10 · 섹터맥락 10 · 테마프리미엄 5 |

  - 성숙도 태그: 공식 / 검증됨 / 잠정 / 미정 / 잠김
- **내 프로필 만들기:** ①공식 복사 → 초안 ②비중 조정(합 100 자동 확인) ③미리보기(리더보드 순위 변화) ④백테스트로 보내기. 미리보기 결과는 공식·실제와 섞지 않음.
- **6관점 따로 표시:** 기업분석·기술·매크로·포트폴리오 적합·위험·계좌 상황. 판단 결과는 관찰/추가검토/보유맥락/비중재검토/위험재검토/차단 중 하나.
- **버전 기록:** v1 사용 중 / v2 예정 / 내 프로필 초안.
- **추가 결정:** 기업 유형 커스텀(type_config: 유형·기준·유형별 Q/G/V·혼합 규칙)도 같은 패턴으로 이 화면 하위에 둠.

## S14 모델 포트폴리오 (ModelPortfolio, QGV · 내 투자)

- **재검토 신호 칩:** 차이가 크면 '비중 재검토' 신호만. 앱이 비중을 제안·변경하지 않음.

## S15 관심 기업 (Watchlist, QGV · 종목 찾기)

- **헤더:** 그룹 칩(전체 / 그룹 / +그룹, 가로 스크롤). "[n]개 기업 · 정렬: 추가한 순 · 편집".
- **기업 카드:** ★기업명, 티커·그룹, 상태 칩(정상/관찰/근접/재평가), 4칸(QGV·일간·실적 D-·뉴스).
- **내 그룹:** 새 그룹 / 이름 바꾸기 / 삭제. 한 기업이 여러 그룹에 들어갈 수 있음.
- **한눈에 4칸:** 평균 QGV, 재평가 신호, 이번 주 실적, 새 뉴스. "리더보드에서 관심 기업만 보기".
- **저장:** 이 휴대폰에만. 백업 파일로 이동.
- **실적 D-:** SEC 제출 패턴 기반 '예상 시기'이며 "확정일 아님" 라벨.

## S16 투자자 13F (Investors13F, QGV · 시장 정보)

- **배지:** 출처 SEC EDGAR·무료 / 최대 45일 늦은 자료 / 상태. 보기 전환: 투자자별 / 종목별 / 내 종목과 겹침.
- **'읽기 전에' 경고:** 분기 말 매수 보유분만 담기고, 공매도·채권·현금은 없음. 투자 신호 아님.
- **투자자 카드:** 이름·제출일·기준 분기·★, 4칸(종목 수·상위 10 비중·신규·전량 매도). 분기 선택.
- **이번 분기 변화:** 칩(신규·추가·축소·전량매도) + 목록. 평가액은 분기 말 가격 기준이라 수량 변화와 가격 변화를 구분.
- **내 목표·관심 종목과 겹침 2칸:** 도쿄일렉트론·한미반도체는 13F 대상이 아님.
- **투자자 목록 관리:** 사용자가 ★로 직접 추가. 앱이 추천하지 않음.

## 구현 연결 메모 — 위 사용자 제공 정본과 구분

화면 명세의 자리·문구와 현재 제공 상태를 구분한다. 이 문서 추가로 모델 산식·임계값·가중치·새 권한·수집/검증 기간을 채택하지 않는다. 미정 요소는 자료 없음/NOT_AVAILABLE로 표시하고 사용자 승인 계산 계약을 따른다.

- SIC→업종군 표는 사용자 확인 대기다. **경기민감·경기방어 소속도는 그전까지 NOT_AVAILABLE**. 산업·테마·유형은 서로 대체하지 않는다.
- S10의 ‘보호’는 사용 금지 안내다. 현 보호 판정은 **UNCONFIRMED**, 기존 Holdout은 v2 근거에서 제외한다. v2/forward 시작일은 향후 착수 때 사용자가 결정하며 에이전트는 기간을 선택·사용하지 않는다.
- S02/S06의 ‘500’은 목표 범위다. 504 listing code-only 자산과 실제 500회사 점수 커버리지·시총 순위 제공을 혼동하지 않는다. M3는 본인 기기 RAM 계산이며 공개 순위에 연결하지 않는다.
- S08 지표·시나리오 및 S09 확률/6상태·영향은 정의·검증이 끝난 결과만 표시한다. Research 지표는 표시 전용이며 Model/TSV/QGV 입력으로 승격하지 않는다. 확률 검증 전 숫자 확률을 합성값으로 채우지 않는다.
- S11 자동 시트 생성은 추가 결정 항목이다. 기존 읽기 전용 로그인에 쓰기 권한을 자동 추가하지 않는다. 시트 ID·키/토큰은 저장소·Pages에 넣지 않는다.
- S16의45일은 통상 분기 종료 후 제출 기한을 가리키며 최신성의 최대 지연 보증이 아니다. 가격 없는 공개 #129/#141 출력은 **보고 수량 변화**, 실제 매매·현재 보유·전량매도 확정이 아니다. 공개 가격/가치 환산·비공개/정정/부분 표 추론은 차단하며 기존13F 적격성 계약을 따른다.
