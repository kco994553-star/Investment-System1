# 프론트엔드 Atlas 구현 인수인계

사용자 지시: “프론트엔드는 너가 만들자”. 합의된 2026-10-18 제품 설계와 시안을 실제 기존 앱에 적용한다.
기준: `35ffbf84462924412641a99f8af9a6fa1c11d69e` (정규 브랜치, #303 포함).
작업 브랜치: `codex/frontend-atlas-20261018`.

## 이번 구현

- 기존 홈 + 8개 메뉴를 PC 왼쪽 탐색 메뉴로 배치. 모바일 5개 하단 메뉴와 전체 메뉴, 언어·테마·검색·기존 경로는 재사용.
- 무채색 종이/잉크 디자인, 얇은 구분선, 반응형 카드·글자 크기. 새 외부 리소스·네트워크 요청 없음.
- 시스템 안내를 실제 기능 흐름으로 구현. 자료→지표→판단→비교→기록·검증과 7개 분석 영역의 접이식 설명, 기존 화면 링크, 기존/부분 연결/신규 모델 필요를 표시.
- 기업 종합·분석 화면에 Q/G/V + 추가 3축 골격. 기존 `primary.q/g/v`만 읽으며 재계산하지 않는다. 추가 축은 이름·기간·정규화 미정으로 비워 둔다. 결측 축을 가로질러 선을 잇거나 영역을 채우지 않는다. 비교군 평균을 만들어 넣지 않는다. 표 형태의 대체 정보 제공.
- 기기 가격 도착 시 점수 카드와 다각형이 함께 다시 그려지도록 기존 부분 갱신 목록에 다각형 추가.

## 통합 범위

공통 파일 `app.js`는 `SCORE_SECTIONS`에 다각형 선택자 1개만 추가한다. #300/#304의 app.js 변경을 대신하지 않는다. `theme.css`, `app-shell.js`는 #304와 함께 병합할 때 각 변경을 보존해야 한다. `pages_artifact_guard.py`의 네 정적 파일 해시는 검토된 이번 바이트로 갱신했으며 통합 후 최종 바이트에 맞게 다시 확인해야 한다. 개인정보·가격·원장·Frozen 계약·공식 계산식과 네트워크 권한을 변경하지 않았다.

## 검증

- JS 문법, git diff --check: 통과.
- 공개 빌드 및 pages_artifact_guard: 102개 파일, 위반 0.
- Node: 33개 테스트 단위 통과(기존 screens_gaps 묶음 내부 6개 포함), 새 다각형·안내 회귀 4개 포함. QGV 엔진/접근자 기존 검증 통과.
- Python unittest: 빌드·산출물 가드 47개 통과. 같은 실행에서 test_web_mvp는 pytest 부재로 import 오류가 발생했다.
- test_web_mvp + test_app_nav_ia: 저장소 mini_pytest shim으로 9개 통과. 정식 pytest 실행으로 표시하지 않는다.
- 기존 app_nav_ia 브라우저 검사를 PC 사이드바·구조도 기대값에 맞게 갱신했다. 브라우저 제어 기능이 제공되지 않아 로컬 브라우저 실행/스크린샷은 미검증. CI에서 해당 검사를 실행해야 한다.
- 새 Node 회귀 검사는 기존 ci_node_tests 목록에 추가했다.
