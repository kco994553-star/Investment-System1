# 디자인·정리 백로그 (2026-10-14)

2026-10-14 화면 정리 작업(유형 버그 수정, 원자료 카드 이동, v1 표시 제거) 중에 눈에 띈 항목이다. 이번 작업 범위는 아니다(소유자 결정: 디자인 다듬기는 지금 하지 않음). 형식: **화면 → 항목 → 이유**.

새 화면 규칙(소유자 결정 4): 사용자 화면에는 결과만 보이고, 원자료(영어 변수명, 긴 소수, 원목록)는 설정 > 원자료 보기(개발자용)에만 둔다. 아래 항목 다수는 이 규칙을 기존 화면에 적용하는 일이다.

## S04 기업 요약

- **S04 → 분류 3칩의 '투자 유형' NA 문구 → 사유 분리.** 지금 문구 '소속도 0.3 이상 유형 없음 또는 자료 없음'은 "계산됐지만 0.3 미만"(예: 매출 CAGR 12%면 성장 0.2)과 "자료 없음"을 하나로 묶는다. 유형 버그를 고친 뒤에는 앞의 경우가 흔해진다.
- **S04 → v2 NOT_AVAILABLE일 때 QGV 카드 → 배지 4개(QGV v2·Q·G·V)를 한 줄로.** 지금은 NOT_AVAILABLE 배지가 네 번 나오고 그 아래에 이유 한 줄이 온다. 이유 한 줄만으로 충분하다.
- **S04 → 데이터 배지 줄 → 상태 코드·ISO 시각을 한국어·짧은 날짜로.** 'LIVE', '기준 2026-10-14T11:11:48+00:00', 'PIT OBSERVED_CAPTURE_ONLY'는 원자료 표기다.
- **S04 → '다음 실적' 한 줄 → 스타일과 D-0 표현.** 지금은 꾸밈 없는 문단이다. 제출 구간이 이미 열려 있으면 'D-0'이 되는데 '진행 중'이 더 정확하다.
- **S04 → '근거 자료' 제목 → 이름 정리.** 원자료 카드를 옮긴 뒤 SEC 보고 재무 패널과 설정 링크만 남았다. '재무 보고' 같은 이름이나 S05 재무 탭과의 합치기를 검토한다.
- **S04/S05 → 가치 카드 → 원코드 숨김.** 'v1+dcf_v1_1_default' 버전 배지, NO_DEVICE_PRICE·FCFE 사유 코드, accn 번호는 원자료다.
- **S05 가치 탭 → 'V 요소 (이 기기 계산 · 보정 전)' 표 → v2 V로 옮길지 결정.** v1 라벨은 없지만 v1 V 요소(핵심 가치·안전마진 등 7개) 계산이다. 이번에는 'v1' 라벨이 붙은 V축 행만 뺐다.

## S05 기업분석

- **S05 → v2 요인 표의 '상태' 배지 → 한국어 라벨.** PUBLIC / CALCULATED / OWN_HISTORY는 내부 값이다.
- **S05 → '산출 요인 n/15 · qgv-v2/balanced/gate-on' → 프로필 이름으로.** 프로필 id 문자열은 원자료다. '균형 · 관문 켬'으로 보이면 된다.
- **S05 → 종합 탭 '신뢰도' → 항상 NOT_AVAILABLE.** 정의가 나올 때까지 행을 숨기거나 '정의 대기'로 줄인다.

## S06 리더보드

- **S06 → QGV 칸 한 줄 문자열 → 요인 막대 또는 열 분리.** 'QGV 61.2 · Q 60.1 · G 55.0 · V 48.2 · 산출 요인 14/15'가 한 칸에 들어가 폭 390에서 줄바꿈이 많다.
- **S06 → v2 NOT_AVAILABLE 이유 → 짧은 배지 + 펼침.** 'QGV v2 산출 불가 · 산출 요인 3/15 · Q 축 비중 50% 미만'이 표 칸에 길게 나온다.
- **S06 → '일별 스냅샷' 배지 → sec-qgv2.json 기준 시각으로.** 지금은 v1 파일(sec-qg-factors.json)의 as_of를 보인다.
- **S06 → '내 프로필 기준(PREVIEW)' 탭 → v2로 옮기기.** 아직 v1 개별 요인과 사용자 v1 비중으로 Q/G를 다시 계산한다(PREVIEW 라벨은 있음). v2만 보이는 원칙과 맞추려면 v2 요인 비중 편집이 필요하다.
- **S06 → 연결 안 된 열(일간·컨센서스·목표·QGV 시나리오·재평가·VMR) → 숨김.** 모든 행이 '—'라 표만 넓어진다.
- **S06 → M3 사유 코드 → 한국어.** UNIVERSE_NOT_READ, NOT_IN_UNIVERSE가 그대로 보인다.
