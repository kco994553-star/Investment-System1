### 3.2 기술적 분석 가격

- 실제 일봉은 #436 1인 비공개 구역의 KIS 일봉을 우선 연결 대상으로 설계한다(#436 설계에 차트 이력 계약을 더함).
- #436 승인과 인증·비공개 저장·조회 연결 전에는 "비공개 기능 준비 중" 상태와 시험용 자료로 화면을 구현한다. 실제 인증 동작을 가장하지 않는다.
- KIS 원자료(MODP=0)를 조정 완료 가격으로 간주하지 않는다.
  - 오너 권장안: 원자료(MODP=0)는 장부·연구용으로 보존하고, 차트용은 수정주가(MODP=1)를 별도 계열로 받는다.
  - **바뀜(같은 날, #436 17.2):** Codex #432 실측(NVDA 10:1 분할 전후)에서 `MODP=1`이 분할만 반영한 값과 0/16 일치했고, 거래량은 조정되지 않았다. 그래서 `MODP=1`은 함께 받아 대조용으로만 쓴다. 차트 계열은 원자료와 확인된 분할(원주가÷수정주가 정수비 계단 + SEC 주식수 교차 확인)로 Main 코드가 만든다.
  - 분할·배당을 중복 반영하지 않는다. 적합성이 확인된 종목·기간부터 연결하고, 미확인 구간만 분석 보류와 사유를 보인다.
- 공개 화면은 승인·검증된 가격 시계열이 생기기 전까지 지표 판정을 보류한다.
  - 지금의 IEX 마지막 체결가 경로는 차트용 연속·조정 OHLCV가 아니다.
- KIS 가격·거래량·토큰은 공개 파일·화면·로그·아티팩트에 들어가지 않는다(#436 가드 범위).
