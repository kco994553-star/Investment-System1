## 발행주식수·사건 범위

시총용 주식수는 10-Q 표지의 **시점별 실제 발행주식수**로 기록했다.
회사별 수량·본문 근거·기준일·가용일·hash는 비공개 `classification-security-shares.json`에 있다.
동일 시점의 보유 DEI 원천과 수량·기준일이 일치한다. 기간 가중평균 희석주식수와 값이 다름을 확인했고,
시총 입력으로 대체하지 않았다. 2018-01-30 보도자료의 EPS용 평균 주식수도 대체값으로 쓰지 않는다.

조회한 역사 페이지와 보관 recent에서 2017-09-30~2018-02-16의 공시 메타데이터 **45건**을 연결했다.
전체 원문을 읽은 접수 건은 위의 10-Q·8-K **2건**이다. 나머지 43건의 원문을 모두 읽은 것은 아니다.
이 범위에서는 **분할·신원 변경 공시가 ‘확인 범위에서 발견되지 않음’**이다.
사건이 없다는 완전성 보증이나 S까지 가격·주식수 기준이 일치한다는 확인으로 승격하지 않았다.
NASDAQ 티커 관측이 생겼지만 역사 공급자 series의 증권 유효구간은 여전히 별도 근거가 필요하다.

## 보유 가격 기록과 남은 정확한 필드

기존 2018년 가격 ZIP의 원래 hash와 응답 manifest hash를 대사했다.
요청 인자와 manifest URL 모두 **SIP / 1Day / adjustment=raw / asof=-**를 명시한다.
S 가격 봉 1개가 있다. 이는 raw 조정을 **요청했다는 확인**이며 공시 사이 주식 기준의 증명은 아니다.

요청·응답·manifest에는 **가격 통화 필드가 없다**. 기존 #432 예제와 #464 가격 어댑터의 USD 리터럴은
코드에서 대입한 값이며 이 응답에서 읽은 원천 필드가 아니다. 재무 USD를 가격 통화로 전사하지 않았다.

| 남은 필드 | 현재 판정 | 필요한 근거 |
| --- | --- | --- |
| `quote.currency`와 그 출처 | 미확인 | 해당 보관 SIP series에 적용되는 통화 명세 또는 자산 메타데이터 |
| 역사 증권 ↔ 공급자 symbol/series 유효구간 | 부분 관측 | CIK·보통주·NASDAQ AMD를 S의 보관 가격 series에 연결하는 역사구간 근거 |
| `share_price_basis` | 미확인 | 2017-10-27 실제 주식수와 S의 raw 종가 사이 분할/신원 변화 및 필요한 조정 근거 |
| 완전 C2 manifest | 기존 생성 미확인 | 역사 전체 후보·발행사 시총·대표증권·적격·같은 S의 PIT 입력과 기존 CPI 묶음 |

첫 세 조건이 맞아야 `S 종가 × 시점별 발행주식수`로 시총을 계산하고, 부채−현금을 더한 EV를
매출·FCF와 비교할 수 있다. 이번에는 **시총·EV/매출·EV/FCF 모두 null / 실제 비율 계산 0회사**다.
원시 비율에 C2가 필요해서 멈춘 것이 아니다. **C2는 그 다음 점수·순위의 별도 차단**이다.
승인된 SEC 범위의 남은 횟수를 가격 통화 확인 목적의 다른 서비스 조회에 사용하지 않았다.

| 이번 대상 1회사 단계 | 확인 수 |
| --- | ---: |
| 당시 분류 | 1 |
| 평가일에 유효한 동일 증권의 완전한 연결 | 0 |
| 같은 증권·통화·주식 기준의 가격·재무 연결 | 0 |
| 원시 비율 계산 | 0 |
| 기존·후보 점수 비교 | 0 |

①기존 점수/기존 순위, ②같은 점수/섹터 순위, ③후보 점수/섹터 순위 모두 미산출.
소표본으로 C2 백분위를 대체하지 않았다. 기존 6개월 거래대금·#465 CPI 계산은 그대로 보존한다.

## 비공개 산출물과 검증

승인된 루트 `/workspace/private-bt-data-pilot-v06/continuation/sector-qgv-input-audit-20261102/` 아래:

- `sec-approved-lookup-20261102/`: 세 원본 응답·요청 시작/완료 기록·hash·누적 요청 수·읽은 본문.
- `sec-connected-v1/`: 분류/증권/실제 주식수, 가격 기준, 기간 내 공시 목록, SIC 연결 PIT 행,
  원시 비율 미산출 사유, 단계별 수, 입력/출력 manifest.

회사별 결과와 원본은 **로컬 비공개 보존**이다. 일반 연구 가지에는 도구·연구 문서만 보존한다.
직접 검증은 원본·기존/신규 출력 hash, 공시 cutoff·가용일, 실제/희석 주식수 구별,
기존 V 입력 동일성, 0700/0600 권한이다. 전체시장 계산·독립 감사·점수 검증은 아니다.

조회 도구 `fetch_approved_sec_pair.py`는 우선 두 고정 URL만 읽고 자동 재시도·리다이렉트를 하지 않는다.
공시 목록 검토 후 `--identity-followup`으로 검토된 한 8-K만 추가했다. 동일 출력에 같은 요청 재실행은 거부한다.
새 SEC 요청 없이 재현하려면 `connect_approved_sec_evidence.py`에 `--sec`, `--prior`, `--facts`,
`--amd`, 새 비공개 `--out`을 전달한다. 표준 라이브러리와 기존 PIT 코드를 사용한다.
