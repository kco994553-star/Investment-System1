- 미수집·미연결은 정당한 제외가 아니다. 인계물에는 후보 · 적격 · 제외(규칙) · 미확인(입력 없음) 수를 따로 센다.

## 6. 인계 계약

### 6.1 순서

1. **선정 입력(전체 후보):** 실행 ID, 전체 코드 SHA, 설정, 재현 명령 / 비공개 manifest(원본 위치·출처·기간·sha256·권리) / 역사 후보·고정 증권 ID·발행사 시총·대표 증권 / 점수화 기준 모집단과 U-A·U-B 선정 모집단 / 요인·축·총점·관문·순위·제외 사유 / 후보·적격·제외·미확인 수.
2. **장부 입력(선정 종목):** 신호 가격·T 시가·보유 가격·기업행사 / 체결·수량·현금·미수금·평가액·비용 / 그룹 기준·S&P 500 비교 / 알려진 결손·근사 가정.

### 6.2 첫 묶음 범위

- **첫 평가일: S = 2018-02-16 → T = 2018-02-20, 보유 → 다음 재선정 T = 2019-02-19 시가.**
  - 고정 규칙: TOPS 1.6(거래 상태 메시지 있음) 파일이 있는 첫 연간 S. 성과를 보기 전에 자료 기준으로 정했다. Codex가 고른 첫 시점(2018-02-16 → 2018-02-20)과 같다.
  - 2017-02-17은 TOPS 1.5(거래 상태 없음, 호가로 대신)라 진단 확장 후보로 둔다.
- 범위: U-A·U-B 전체 후보. 소수 종목 표본으로 대신하지 않는다.
- 첫 묶음 뒤 2019~2026 S로 넓힌다.

### 6.3 비공개 인계 위치

- 제안: 비공개 저장소 `investment-system1-raw`(Codex가 이미 읽는 곳)의 `exp-stock-indicator-deciles-v1/<run_id>/` 아래 manifest·선정 입력·장부 입력.
