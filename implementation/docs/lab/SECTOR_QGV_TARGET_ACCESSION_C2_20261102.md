그 역사 페이지 원본도 두 archive에 없다. 공백을 '관련 공시 없음'으로 처리하지 않았다.

## 가격·재무의 겹침과 원시 비율

기존 결과의 manifest hash를 다시 확인하고 **공용 `qgv2_inputs.normalize`**로 대상 1행을 읽었다.
매출·FCF는 **TTM 2017-09-30**, 부채·현금·희석주식수는 **2017-09-30** 기준으로 모두 존재한다.
재무 통화는 USD다. `cash_and_equivalents`가 정규화된 `cash`로 연결됨을 확인했다.
현금 필드가 빠졌다는 판정은 하지 않는다.

최신 사용 공시는 companyfacts 계보상 위 접수 건이며 **2017-11-02 공시 / 2017-11-10 가용**이다.
이는 기존 NYSE 5개 완전 세션 지연 규칙의 계산이며, SEC 헤더의 접수시각을 이번에 확인했다는 뜻은 아니다.
S의 cutoff **2018-02-08**을 유지했다.

기존 가격 archive에는 같은 티커의 S 봉이 1개 있고, 요청은 SIP·1Day·adjustment=raw·asof=-다.
그러나 **티커 공존만으로 같은 역사 증권을 확정할 수 없다**. 당시 SIC·증권 종류/유효 신원,
가격 통화 근거, 주식수와 raw 가격 사이의 분할 기준 확인이 남는다.
현재 재무 행의 주식수 비율 IN_BAND는 그 재무 행의 점검일 뿐 역사 신원·분할 확인을 대신하지 않는다.

따라서 숫자 입력의 공존은 **1회사**, 검증된 같은 증권 연결은 **0회사**다.
EV/매출·EV/FCF는 null과 미산출 사유로 비공개 보존했다. 조건부 산술을 실제 비율로 세지 않았다.
기존 V의 EV 산식은 `가격 × 희석주식수 + 부채 − 현금`이며,
C2 적격 판정의 **종류별 실제 발행주식수로 계산하는 발행사 시총**과 구별한다.

| 단계 | 이번 지정 대상 1회사 | 종전 보조 섹터 표본 2회사 |
| --- | ---: | ---: |
| 당시 분류 확인 | 0 | 2 |
| 평가일에 유효한 증권 확인 | 0 | 0 — 원문상 S 이전 합병/옛 주식 소멸 |
| 같은 증권의 가격·재무 연결 | 0 | 0 |
| 원시 EV 비율 계산 | 0 | 0 |
| 기존·후보 점수 비교 | 0 | 0 |

종전 #432 고정 10회사 중 PIT 재무 3행은 그대로 재사용한다. 이번에 3행을 새로 계산한 것이 아니다.
두 보조 회사를 2018년 적격 표본으로 더하지 않는다. 실행 섹터·가중치 활성화 없음.
①기존 점수/순위, ②같은 점수/섹터 순위, ③후보 점수/섹터 순위 모두 미산출이며 순위 이동 사유는 해당 없음.
정보기술 EV/매출은 기존 V에 없는 **새 요인 추가**라는 사전등록 구분을 유지한다.

## 비공개 보존과 재현

승인된 임시 연구 루트
`/workspace/private-bt-data-pilot-v06/continuation/sector-qgv-input-audit-20261102/`의
`target-accession-v1/`에 검색 내역·submissions 범위·재무/가격 상세·미산출 비율·단계별 수·manifest를
**로컬 비공개 보존**한다. `c2-generation-records.json`은 원격 인계 본문 수령 기록이다.
회사별 실제 값은 연구 가지에 넣지 않는다.

[재현 도구](../../experiments/sector-qgv-first-20261102/audit_target_readiness.py)는 네 입력을 받는다:

```sh
PYTHONPATH=implementation/src python implementation/experiments/sector-qgv-first-20261102/audit_target_readiness.py \
  --raw <private>/c21-raw-store-36305927245.zip \
  --amd <private>/AMD.zip \
  --sec <private>/sec-universe-raw-2026-10-29-all-shard4.tar.gz \
  --prior <private>/result-v2 --out <new-private-output>
```

각 archive의 원래 `.sha256`이 필요하다. 종전 출력 manifest와 모든 출력 hash를 확인한 뒤
공용 정규화기를 사용한다. 네트워크·점수 함수 호출 없음. 합성 시험·책 판독은 반복하지 않았다.
검증은 **보관 실자료에 대한 자체 검색·입력 점검**이며 독립 대사나 전체시장 검증이 아니다.

## 다음 행동과 외부 접근 요청 범위

기존 백업으로 풀리지 않은 최초 차단은 지정 공시의 **당시 분류·증권 근거 원본**이다.
외부 접근은 기존 사용자 지시상 추가 승인되지 않았으므로 실행하지 않았다.

최소 후속 요청은 **SEC의 CIK 0000002488 한 회사, 평가일 이전 신원·분할 확인 목적의 읽기**다.
고정 대상은 위 접수 건의 complete submission text(헤더·10-Q 표지 포함)와
`CIK0000002488-submissions-001.json` 1페이지다. 이어서 목록에 실제 존재하는 공시 중
2017-09-30~2018-02-16의 증권 종류·합병·상장/분할 변화 확인에 필요한 원문만 조건부로 읽는다.
**최대 성공 GET 6회(고정 2 + 필요한 원문 최대 4), 그 이상이면 중단**, 신규 가격·전체시장 수집은 포함하지 않는다.
가용일과 효력일을 분리하고 S의 채택 규칙을 그대로 적용한다. 원문이 있어도 신원이 불충분하면 UNKNOWN을 유지한다.

전체 C2는 이 한 회사 공시로 해결되지 않는다. Codex가 우선 기존 비공개 저장 담당 경로에서
보고된 부분 진단/CPI 묶음 위치를 연결하고, 역사 후보 전체 명부의 기존 보유 위치를 확인해야 한다.
완전 후보가 없는 상태에서 전시장 수집을 이번 요청에 포함하지 않는다.
