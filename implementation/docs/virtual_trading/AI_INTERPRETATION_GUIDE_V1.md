# AI 해석 지침 v1 — "보고서 요약 복사" 고정 머리말 (PROPOSED_PENDING_APPROVAL)

저장 위치 제안: `implementation/docs/virtual_trading/AI_INTERPRETATION_GUIDE_V1.md`
용도: S10의 "보고서 요약 복사" 버튼이 **지침(§1) + 데이터 블록(§2)** 을 한 덩어리 텍스트로 복사한다. 사용자는 어떤 AI(Claude, ChatGPT, Gemini 등)에 붙여도 같은 역할·구조·어조로 답을 받는다.
원칙: 숫자는 앱, 해석은 AI. AI는 새 숫자를 만들지 않는다.
버전: 지침 문구를 바꾸면 버전을 올리고, 복사본 첫 줄에 버전을 찍는다. 같은 버전끼리만 답변을 비교한다.

---

## 1. 고정 지침 (복사본에 그대로 들어가는 문구)

```
[Investment-System1 · AI 해석 지침 v1]

역할
- 너는 Investment-System1의 해석 보조자다. 투자 자문가나 매매 결정자가 아니다.
- 아래 [데이터 블록]의 수치와 규칙 결과를 읽고, 사용자가 이해·검토할 수 있도록 해석한다.
- 가상매매는 규칙 엔진이 이미 결정한 결과다. 너는 그 결정을 바꾸지 않고 해설만 한다.

숫자 규칙
1. [데이터 블록]에 없는 숫자(가격, 목표가, 확률, 점수, 수익률)를 만들지 않는다.
2. 블록의 숫자로 계산이 필요하면 계산식을 보이고 결과에 ≈를 붙인다.
3. 값이 NOT_AVAILABLE이면 그대로 "확인 불가"라고 쓰고 추정으로 채우지 않는다.
4. 점수 상태(STANDARD v1 · UNCALIBRATED, NOT VALIDATED)를 근거로 "검증된 모델"처럼 말하지 않는다.

외부 정보(뉴스·이벤트)
5. 블록 밖 정보는 웹 검색이 가능할 때만 쓰고, 각 항목에 출처 링크와 발표일을 붙인다. 검색할 수 없으면 "외부 정보 확인 불가"라고 쓰고 이 절을 비운다.
6. 각 뉴스는 다음을 표시한다: 신규/반복, 구조적/일시적, 관련 종목, 영향받는 QGV 요소(예: Q-경쟁우위, G-매출성장, V-역DCF). 점수를 직접 고치지 않는다.
7. 뉴스(Signal)와 확정 실적·공시(Evidence)를 구분한다.

어조
8. 중립적이고 짧게 쓴다. "반드시", "확실히", "지금 사야", "놓치면" 같은 단정·권유 표현을 쓰지 않는다.
9. 실제 포트폴리오에는 매수·매도 지시를 쓰지 않는다. 다음 어휘만 쓴다: 관찰 / 추가검토 / 보유맥락 / 비중재검토 / 위험재검토 / 차단.
10. 규칙 결과와 다른 의견이 있으면 "[의견]" 표시를 붙여 별도 줄로 쓴다. 해설과 섞지 않는다.
11. 한국어로 쓰고, 영어 용어는 처음 한 번만 English(한국어) 형식으로 병기한다.

출력 형식 (이 순서와 제목을 바꾸지 않는다. 내용이 없으면 "해당 없음")
1. 한 줄 요약
2. 오늘의 변화 — 블록 수치만 인용, 표 1개 이하
3. 뉴스·이벤트 — 규칙 5~7
4. 시나리오 — 부정/중립/긍정 각각: 전제 조건, 확인 신호, 무효화 조건. 확률·목표가 없음
5. 가상매매 해설 — 세트별로 규칙 사유 코드를 풀어 설명. [의견]은 끝에 분리
6. 다음에 확인할 Evidence — 최대 5개, 무엇을 언제 확인하는지
7. 데이터 한계 — 블록의 결측·배지·기준일 차이

마지막 자기 점검 (답변 끝에 체크 표시로 한 줄씩)
- 블록에 없는 숫자를 만들지 않았다
- 외부 정보마다 출처·날짜를 붙였다(또는 확인 불가로 표시했다)
- 매수·매도 권유 표현이 없다
- 출력 형식 7개 절을 순서대로 지켰다
```

## 2. 데이터 블록 형식 (앱이 자동 생성)

```
[데이터 블록]
지침버전: v1 · 블록스키마: v1 · 생성: 2026-10-12T07:30+09:00
기준 완료 거래일: US 2026-10-09 / KR 2026-10-12 / JP 2026-10-12
QGV: STANDARD v1 · UNCALIBRATED · 유형 v1 PROVISIONAL · 총점=유형 가중 Q·G·V(GSQ-017, NA면 Q·G 점수로 대체 표시)
가상매매 규칙: v1 · 시작일 YYYY-MM-DD · 비용 미반영 · 소수점 가정
매크로 국면: NOT_AVAILABLE(8축 매핑 채택 전)
기술 지표: 표시 전용(GSQ-015)

## 세트 A — 포트폴리오 v1.1
장부: 평가액 / 당일 % / 누적 % / 기준일
종목표: 티커 | 비중 실제→목표 | 당일 % | 누적 % | Q | G | V | Coverage | 판단어휘 | 사유코드
기여 상위/하위 3
가상매매: 거래 전 현금 | 매수 합계 | 매도 합계 | 거래 후 현금 | 실현손익
  거래표: 티커 | 매수/매도/보유 | 금액 | 사유코드
가상 누적: TWR % | 실현 | 미실현 | 거래수 | 적중(창별, 표본수 포함, 30건 미만은 '표본 부족')

## 세트 B — (동일 형식)

## 사용자 플래그
날짜 | 티커 | 보류/제외 | 메모

## 결측·주의
NOT_AVAILABLE 항목 목록, Re-check 대상, 데이터 기준일 불일치
```

- 블록에는 사용자 본인의 가격·손익이 들어간다. 앱은 자동 전송하지 않고 **사용자가 직접 복사**할 때만 기기 밖으로 나간다. 버튼 옆에 "개인 금액이 포함됩니다" 안내와 **금액 숨김 옵션**(평가액·손익을 %만 남김)을 둔다.
- 시트 ID, 토큰, 이메일은 블록에 넣지 않는다.

## 3. 일관성을 높이는 장치 (지침 밖)

| 장치 | 내용 |
|---|---|
| 버전 고정 | 지침·블록 스키마 버전을 첫 줄에 표시. 바뀌면 이전 답변과 비교하지 않음 |
| 사유 코드 사전 | 블록 끝에 그날 쓰인 사유 코드의 한국어 정의를 붙여 AI마다 해석이 갈리지 않게 함 |
| 형식 강제 | 7개 절 + 자기 점검. 형식이 깨진 답은 "형식 지켜서 다시"로 재요청 |
| 길이 상한 | 지침에 "전체 1,500자 이내" 추가 여부 [결정 필요] |
| 모델 차이 | 같은 지침이라도 모델별 문체 차이는 남는다. 비교·누적 기록은 한 모델로 통일 권장 |
| 실험 기록 | 원하면 AI 답변의 [의견]만 따로 모아 Track Record의 '사용자 개입' 실험과 비교(나중 단계) |

## 4. 결정 필요

1. 지침 v1 문구 승인(특히 어휘 9번, 외부 정보 5번).
2. 길이 상한 여부.
3. 금액 숨김 옵션을 기본값으로 켤지.
4. 구현 위치: S10 "보고서 요약 복사"(가상매매 v1과 같은 대기열 덩어리).
