# 플레이북 화면·기기 기록 v1

2026-10-13. `#playbook`에서 기존 19종목과 기기에 실제로 보유한 종목을 점검한다. 기업·포트폴리오 화면에서도 패널을 열며, 일일보고서 판단 셀의 버튼은 같은 패널을 연다. §10 프롬프트 원문을 설정에 복사하고 §7 업종 조사 항목·현재 값을 삽입한다. 외부 AI 호출 없이 사용자가 프롬프트를 복사하고 답변을 붙여 넣는다.

산 이유·무효화 조건은 빈 값으로 저장하지 않는다. 보류에는 사유·해제 조건·실제 유효한 날짜가 모두 필요하다. 판정은 활성 선택지만 저장하며 E4는 정보 전용이고 선택지를 만들지 않는다. 확인한 값에는 출처·허용된 근거 등급이 필요하고, 값이 없으면 확인 불가 사유를 저장한다. 결과는 제안 행동으로 기록하며 원본 TARGET v0를 바꾸지 않는다.

기기 저장 `device-playbook/1`을 통합 백업 `investment-device-backup/4`에 넣는다. /1~ /3 가져오기는 기존 플레이북 기록을 보존한다. 기록 복원 중 보유 복원이 실패하면 플레이북을 포함한 변경 전 저장값으로 돌린다. 가격 시계열·채점 수익률은 RAM에만 둔다. 백업 내보내기·가져오기 모두 UTF-8 16MiB 상한을 적용하며 초과 시 기록을 잘라내지 않고 오류를 표시한다. 제안 TARGET은 저장 전에 정확한 필드·등급·숫자·한도를 검증한다. 기기 저장이 손상되면 원본을 덮어쓰지 않는다.

확인일이 지난 마지막 기록은 오늘 화면에 E5로 표시한다. 같은 날 새 점검이 저장되면 이전 기록의 알림을 대체한다. 후보 코드는 판정 저장 여부와 무관하게 패널 평가 시 날짜·종목·코드별 한 번씩 센다. 13F 전량 매도·구조적 뉴스는 확인된 후보 원인만 정보 기록으로 남긴다. 13F 자료가 완전하지 않으면 보유 수는 NA다.

판정 채점은 실제 기기 시계열의 D+20·D+63·252세션 수익률을 업종 ETF·SPY와 비교한다. 일일보고서에서 가져온 기기 시계열을 RAM으로 공유하며, 자료가 없거나 기간이 지나지 않았으면 NA다. 판정일 자체가 SPY 거래일이 아니면 `BASE_SESSION_UNAVAILABLE`이다. 임의로 전·후 거래일 가격을 선택하지 않는다. "시스템 판정대로"와 "확신 유지" 기록을 구분한다.

TARGET v1 작성은 Universe504 후보 + 기존 미국 외 후보를 선택하고 산 이유·무효화 조건 각각 2~3개, 등급·비중, 현금, 2~3분기 전환 계획을 적는다. §16 한도와 합계 100%를 검사한다. 미국 외 Q·G 미연결 후보는 관찰 2%로만 넣는다. v2 준비 전 최종 저장은 비활성이다. 완전하지 않은 업종은 한도 검사를 통과시키지 않는다. TARGET v0는 출발점·비교 기준이며 반도체 묶음 55%가 40% 상한을 초과한다는 사실을 표시한다.
