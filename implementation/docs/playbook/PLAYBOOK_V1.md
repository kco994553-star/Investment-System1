## 0. 원칙

1. 숫자는 앱이 보여주고, 해석은 AI가 돕고, 판정은 사용자가 한다.
2. 화면의 판단 어휘는 7단계를 그대로 쓴다: ■차단 > ▼위험재검토 > ▼비중축소검토 > ▲비중확대검토 > ●추가검토 > ●보유맥락 > ●관찰.
3. 각 판단 아래에 세부 코드를 둔다. 세부 코드마다 행동요령이 하나씩 있다.
4. 기준값은 기업 유형이, 조사 항목은 업종이 정한다.
5. 실제 포트폴리오 화면에는 매수·매도 동사를 쓰지 않는다. 실제 주문 기능은 없다.
6. 모르는 것은 0이나 좋은 것으로 취급하지 않는다. "확인 불가"로 표시한다.
7. 모든 플레이북은 "행동" 또는 "다음 코드 + 확인일"로 끝나야 저장된다.

## 1. 세부 코드와 진입 조건

`{유형}`은 6절의 유형별 기준값을 쓴다는 뜻이다.

| 판단 | 코드 | 진입 조건 | 이유 코드 |
|---|---|---|---|
| ■ 차단 | X1 | 가격·환율·스냅샷 결측 | PRICE/FX/SNAPSHOT_MISSING |
| | X2 | 데이터 관문 BLOCKED | COVERAGE_BLOCKED |
| | X3 | 사용자 '제외' | USER_EXCLUDED |

| | R2 | Q·G 하락이 {유형} 임계 이상, 또는 배당 유형의 배당 삭감 | QG_DECLINE / DIVIDEND_CUT |
| | R3 | 업종 대비 이상 하락(20세션 초과수익률 < 252세션 평균 − 2σ) | RECHECK_ABNORMAL_DROP |
| | R4 | 데이터 품질 READY → PARTIAL | COVERAGE_DEGRADED |
| | R5 | 사용자 '보류' | USER_HOLD |
| ▼ 비중축소검토 | T1 | Q·G 유지 + V가 20세션 전보다 {유형} V 임계 이상 하락 | V_DETERIORATED |
| | T2 | 실제 비중 > 목표 + Band(13-4), V 변화 임계 미만 | OVERWEIGHT_GAP |
| | T3 | 확신 보유 비중 합계 > 상한 | CONVICTION_CAP_EXCEEDED |
| ▲ 비중확대검토 | U1 | Q·G 유지 + V가 {유형} V 임계 이상 상승 | V_IMPROVED |

| | U3 | 매크로 경고·위기 + 시장 주도 하락 + 우량·재무 안전 조건 충족(13-5) | MACRO_DISCOUNT |
| ● 추가검토 | E1 | 실적 발표 7일 전 ~ 새 Q·G 반영 전 | EARNINGS_WINDOW |
| | E2 | 기업 유형 변경 | TYPE_CHANGED |
| | E3 | 데이터 일부 부족(PARTIAL) | COVERAGE_PARTIAL |
| | E4 | 리더보드 재평가 신호 NEAR_TRIGGER 또는 REASSESS | REASSESS_SIGNAL |

| ● 보유맥락 | H1 | 보유 중, 신호 없음, 분기 1회 | QUARTERLY_CHECK |
| | H2 | 확신 보유 12개월 경과 | CONVICTION_ANNUAL |

| | W2 | 미보유 + Q·G 리더보드 상위 50위 + V가 20세션 전보다 10점 이상 개선 | ENTRY_CANDIDATE |

"Q·G 유지" = 비교 기간 동안 Q·G 평균 하락이 {유형} R2 임계 미만.

## 2. 동시 발생 규칙

1. 주 코드는 하나다. 판단 순서대로 고르고, 같은 판단 안에서는 코드 번호 순서(R1 > R2 > R3…)대로 고른다.
2. 나머지는 보조 칩으로 표시하고, 보조 코드의 질문을 주 플레이북에 합친다. 예: R2 + R3 → R2 플레이북에 R3의 "사건 정리" 질문 추가.
3. 보조 코드의 제한:
   - ▼가 하나라도 있으면 ▲ 행동 비활성.
   - E1이 보조이면 신규 매수·매도 보류(■, R1은 예외).
   - E3이 있으면 확대 선택지 비활성.
4. 확신 보유 종목은 R2·R3·T1에 "확신 유지" 선택지가 추가된다. R1이 발생하면 이 선택지는 사라진다.

## 3. 코드별 조사와 행동 기준

출처 표시: [앱] 자동 · [AI] 프롬프트로 조사 · [공시] 원문 확인 · [본인] 판단

### ■ 차단

**X1 데이터 결측**
- 조사: 빠진 값 [앱]. 3거래일 초과 시 휴장·거래정지·티커 변경·합병 여부 [AI]
- 기준: 3거래일 이내 대기. 초과 시 원인 확인. 티커 변경·합병이면 식별 정보 갱신.

**X2 데이터 관문 BLOCKED**
- 조사: 막힌 관문과 사유 코드 [앱]
- 기준: 판단 동결. 7일 초과 시 데이터 수정 작업 등록.

**X3 사용자 제외**
- 기준: 제외 사유 필수. 분기 1회 제외 목록 재확인.

### ▼ 위험재검토

**R1 무효화 조건 발생**
- 조사: 조건이 공시·확정 실적으로 확인됐는지, 뉴스로만 나왔는지 [공시][AI]
- 기준:
  - 공시로 확인 → 확신 해제, 목표비중 즉시 1/3 축소, R2 진행.
  - 뉴스로만 → 7일 안에 공시로 확인. 그동안 추가 매수 금지.

**R2 Q·G 하락**
- 조사 순서:
  1. 하락한 세부 지표 [앱]
  2. 일회성 항목(일회성 비용, 회계 변경, 환율, 인수합병) [공시][AI]
  3. 업종 동료 3곳의 같은 지표 방향 [앱][AI]
  4. 가이던스 변화 [AI]
  5. 업종별 조사 항목(7절) [AI]
  6. 산 이유별 유효·약화·훼손 [본인]
- 기준(위에서부터 먼저 해당하는 것):
  1. 산 이유 과반 '훼손' → 목표 0, 3회 분할 → 완료 시 W1.
  2. 회사 공식 가이던스 중간값 하향 + 동료와 다른 방향 → 목표 절반 → E5(30일).
  3. 동료 3곳 중 2곳 이상 같은 방향 → 업종 사이클. 유지(경기민감은 −1%p) → E5(다음 분기 실적일).
  4. 일회성 항목 제외 시 하락폭 < {유형} R2 임계의 절반 → 일회성. 유지 → E5(다음 분기 실적일).
  5. 해당 없음 → 추가 매수 금지 → E5({유형} 재확인 간격).

**R3 업종 대비 이상 하락**
- 조사: 기간 내 사건 날짜순 정리 [AI] → 실적·가이던스 변화 [공시][AI] → 사건과 산 이유의 관련성 [본인]
- 기준:
  - 업종별 "구조적 사건"(7절)이 공식 발표로 확인 → R2로.
  - 실적·가이던스 변화 없음 + 산 이유와 무관 → 일시적. 유지. V가 {유형} V 임계 이상 상승했으면 U1로.
  - 판단 불가 → 추가 매수 금지 → E5(14일).

**R4 데이터 품질 악화**
- 기준: 14일까지 복구 대기. 초과 시 E3으로 기록, "신뢰도 낮음" 상태로 판단.

**R5 사용자 보류**
- 입력 필수: 보류 사유, 해제 조건, 해제일.
- 기준: 해제일에 조건 충족이면 해제. 미충족이면 1회만 연장. 2회째에는 반드시 판정.

### ▼ 비중축소검토

**T1 V 하락(비싸짐)**
- 조사: 안전마진 [앱] → 역DCF 내재 성장률 vs 최근 3년 실제 성장률 [앱][AI]. DCF 불가 시 현재 PER vs 5년 평균 PER [AI], "추정" 표시.
- 기준:
  - 안전마진 < 0 이고 내재 성장 > 실제 성장 → 목표 −1%p.
  - 그 외 → 유지 → E1(다음 실적).

**T2 비중 초과(가격 상승)**
- 조사: 초과 %p·금액 [앱], 매도 시 예상 세금 [앱][본인]
- 기준:
  - 초과 2%p 이하 → 매도 없이 새 입금으로 다른 종목을 사서 조정.
  - 초과 2%p 초과 → 초과분만 매도. 해외주식 연간 양도세 공제 한도 안에서 우선 처리.

**T3 확신 보유 상한 초과**
- 기준: 유효한 산 이유가 가장 적은 확신 종목부터 상한까지 축소.

### ▲ 비중확대검토 (▼ 신호가 있으면 진입 불가)

**U1 V 상승(싸짐)**
- 조사: Q·G 유지 [앱] → 하락 원인 회사·업종·시장 [AI] → 안전마진 [앱] → 유형 특수 규칙(6-4)
- 기준:
  - 원인이 업종·시장 이고 안전마진 ≥ {유형} 기준 → 목표 +1%p까지 {유형} 분할 횟수로 주 1회 분할.
  - 원인이 회사 고유 → R2 또는 R3.
  - 불명확 → 보류 → E5(14일).

**U2 비중 부족**
- 조사: 입금 미배분인지 가격 하락인지 [앱]
- 기준: 입금 미배분 → 바로 목표까지. 가격 하락 → U1과 같은 원인 확인 후 {유형} 분할 횟수로 분할.

**U3 매크로 할인 (경고·위기 중에만)**
- 조사: 하락 중 시장·업종 설명 비율 [앱] → R3 미발동 확인 [앱] → Q·재무 안전 순위 [앱] → 회사 고유 악재 여부 [AI]
- 기준: 13-5의 U3 조건 5개를 모두 충족하면 목표 + Band까지, 6회 분할·2주 간격(약 3개월). 하나라도 빠지면 매크로 차단 규칙을 따른다.
- 월 매수 상한: 그달 입금 + 보유 현금의 1/6.

### ● 추가검토

**E1 실적 기간**
- 조사: 발표일, 컨센서스, 업종별 핵심 확인 지표 3개(7절) [AI]
- 기준: 신규 매매 보류. 새 Q·G 반영 후 재판정. 발표 후 3거래일 지나도 미반영이면 직접 확인.

**E2 기업 유형 변경**
- 기준: 즉시 매매 없음. 포트폴리오 목적 기여가 바뀌면 다음 분기 리밸런싱 때 목표비중에 반영. 새 유형의 기준값을 다음 판정부터 적용.

**E3 데이터 일부 부족**
- 기준: 유지 가능, 확대 금지. 30일 초과 시 대체 데이터 출처 검토.

**E4 재평가 신호**
- 조사: R2와 같은 질문(매매 없음)
- 기준: 펀더멘털 변화 없음 → "정상 복귀" 기록. 변화 있음 → R2.

**E5 다음 확인일**
- 조사: 당시 판정·근거·예상과 현재 비교 [앱]
- 기준: 예상대로 → 종료. 다름 → 해당 코드로 재진입.

### ● 보유맥락

**H1 분기 점검**
- 조사: 산 이유별 유효·약화·훼손 [본인]
- 기준: 훼손 1개 이상 → R2. 약화 2개 이상 → E4 방식 점검. 그 외 유지.

**H2 확신 보유 12개월**
- 조사: 확신 유지 성적 [앱], 산 이유 다시 쓰기 [본인]
- 기준: 산 이유를 지금 그대로 다시 쓸 수 없으면 확신 해제.

### ● 관찰

**W1 관심 종목**
- 기준: 등록 시 "관심 이유" 한 줄.

**W2 편입 검토** (5개 모두 통과해야 편입)
1. 사업을 한 문장으로 설명할 수 있다 [본인]
2. 산 이유 2~3개 + 무효화 조건 2~3개 작성 [본인]
3. 안전마진 ≥ {유형} 기준 [앱] (DCF 불가 시 PER 비교 "추정")
4. 편입 후 단일 테마 비중 ≤ 40% [앱]
5. 처음 비중은 목표의 절반, 다음 실적 확인 후 나머지 [본인]

## 5. 근거 등급과 확인 불가

모든 확인 항목에 근거 등급을 표시한다.

| 등급 | 뜻 |
|---|---|
| 증거 | 공시, 확정 실적 |
| 신호 | 뉴스, 컨센서스 |
| 추정 | 대체 지표 |
| 믿음 | 사용자 판단 |

확인 불가는 종류를 표시한다.

| 종류 | 처리 |
|---|---|
| 아직 없음 | 사유와 예상 시점 표시. 대체 지표가 있으면 "추정"으로 표시 |
| 원래 비공개(경영진 질, 해자 지속성) | "믿음"으로 사용자 판단과 근거 입력 |
| 원래 알 수 없음(먼 미래) | 시나리오와 무효화 조건 입력 |

판정 핵심 항목이 확인 불가이면 유지·보류만 가능하고 확대·편입은 비활성이다.

### 6-2. 유형 판정 규칙 v0 (미정이던 유형)

| 유형 | 규칙 |
|---|---|
| 우량 | 3년 평균 ROIC ≥ 15% 그리고 5년 영업이익률 변동 < 5%p 그리고 순부채/EBITDA < 1.5배 |
| 가치 | PER이 업종 중앙값보다 20% 이상 낮음 또는 자기 5년 평균보다 20% 이상 낮음 |
| 경기민감 | 업종군 "경기민감 후보" 또는 5년 매출 변동성 상위 30%. 반도체·반도체 장비 포함 |
| 경기방어 | 업종군 "경기방어 후보" 그리고 5년 매출 변동성 하위 30% |

성장·배당·주도는 기존 type_config_v1 규칙을 쓴다. 이 판정은 플레이북 기준에만 쓰고 QGV 가중치는 바꾸지 않는다.

### 6-3. 복수 유형

- 주 유형 = 소속 점수 최고. 동률이면 경기민감 > 성장 > 우량 > 가치 > 배당 > 경기방어.
- 확대·편입 기준(안전마진, V 임계)은 해당 유형 중 가장 엄격한 값.
- R2는 해당 유형 조건 중 하나라도 걸리면 발동.
- 재확인 간격과 분할 횟수는 주 유형 값.

### 6-4. 특수 규칙

| 규칙 | 조건 | 효과 |
|---|---|---|
| 경기민감 고점 이익 | 영업이익률이 5년 중 상위 20% 구간 | U1·U2 확대와 W2 편입 비활성 |

## 14. QGV v2 기본 채택에 따른 플레이북 조정
