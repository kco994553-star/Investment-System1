# SEC 발행사 SIC 입력 계약 v2 · 나라 필터

Main은 동일 SEC submissions 회차로 `sec-issuer-sic/2`를 만든다. [v1의 파일 형식, 필드, 정렬, 원문·멤버 해시, 시각 및 완료 검증](SEC_ISSUER_SIC_V1.md)을 유지하고 manifest의 schema_version을 갱신한다. 아래 세 키는 모든 발행사 객체에 필수다. 값이 있는 문자열은 대소문자와 표기를 그대로 복사하고 원천 키 부재, null, 빈 문자열 및 공백뿐인 값은 JSON null로 기록한다. 회사 이름, 우편 주소, 거래소, DR 또는 SIC를 대체 근거로 쓰지 않는다.

| 발행사 열 | 같은 SEC 원문 안의 위치 | 의미 |
| --- | --- | --- |
| incorporation_code | stateOfIncorporation | 설립 주 또는 국가의 EDGAR 원문 코드 |
| business_address_code | addresses.business.stateOrCountry | 사업장 주소의 EDGAR 원문 코드. 본사 소재지 필터에 쓰며 우편 주소와 구분한다. |
| recent_reporting_form | filings.recent.form | 아래 규칙으로 선택한 최근 제출 서식의 원문 종류 |

**최근 서식 선택.** 같은 filings.recent 배열의 form, acceptanceDateTime, accessionNumber를 같은 위치로 묶는다. 발행사 observed_at까지 접수된 10-K, 10-Q, 8-K 또는 20-F, 40-F, 6-K를 대상으로 하며 각 서식의 /A도 포함한다. 접수 시각 내림차순, 동률이면 accessionNumber 내림차순으로 첫 서식을 택한다. 정렬에 필요한 배열의 길이나 대상 서식의 시각·접수번호가 잘못되어 선택을 확정할 수 없거나 적격 서식이 없으면 null이다. 최근 묶음만 사용하며 추가 공시는 요청하지 않는다. 이 값은 제출한 서식 계열의 근거다.

**코드 사전.** 두 지리 코드는 각각 독립적으로 같은 버전의 EDGAR 주·국가 코드 사전에서 조회한다. 원천 코드와 사전 버전을 결과에 보존한다. CA와 DE는 각각 미국 캘리포니아와 델라웨어다. 코드에 ISO 국가 약어를 임의 적용하지 않는다. 미등재 코드는 미대응, 원문 null은 누락이다. 미국 기업용 서식과 해외 기업용 서식은 위 두 서식군으로 판정하고 null은 미확인으로 둔다. 나라 정보는 시장 → 섹터 → 하위 산업 → 기업과 독립된 꼬리표·필터다.

**비공개 대사.** 11/23 고정 STOCK 행에서 유일 연결 CIK의 설립지, 사업장 소재지, 보고 유형을 독립적으로 기록하고 해당 증권의 마스터 DR 표시를 함께 보존한다. 섹터 배정·보통주 증빙과 독립적으로 집계한다. 본사 소재지는 국가별 종목 수 내림차순(동률은 표준 국가 코드 오름차순) 상위 10개, 그 밖의 확인 국가, 미확인으로 나눠 전체 행 수와 맞춘다. 설립지와 사업장의 국가가 모두 확인된 종목 및 고유 발행사를 분모로 불일치 수를 센다. 같은 국가 내 주 차이는 일치다. 해외 서식 발행사는 유일 연결 고유 CIK 기준으로 1회 센다. SEC 전달·고정 해시·별도 실행 승인 전에는 미측정으로 둔다. 회사별 결과는 비공개에만 남기고 공개 인계에는 집계와 링크만 쓴다.
