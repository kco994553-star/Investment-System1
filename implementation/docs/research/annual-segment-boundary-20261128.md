# 복수 사업 발행사의 주 사업 판정

정책 버전은 `annual-segment-boundary/2026-11-28.1`이다. 11월 8일 경계 정책에 복수 사업 판정을 추가한다. 운영 평가일 연구 기록과 전체 시장 후보에는 판정 버전과 사전 버전을 함께 남긴다. 발행사별 판정은 비공개에 보존하고 과거 버전은 덮어쓰지 않는다. [기존 경계와 적용 단위](../frontend_v2/COMMON_CLASSIFICATION.md)

## 평가일과 근거

1. 평가일 **이전**에 SEC에 제출된 최신 연차보고서(10-K, 20-F 또는 40-F)의 해당 회계연도를 사용한다. 평가일 당일 및 이후 제출물은 제외한다. 해당 기간 정정 공시가 있으면 평가일 이전에 공개된 정정 부분을 반영한다. 원문이나 필요한 정정 부분이 없으면 자료 미수신으로 남긴다.
2. 연차보고서의 사업 설명과 부문 주석에서 발행사가 구분한 사업 부문 전체와 같은 연도의 매출을 대조한다. 같은 연결 범위·통화·단위에서 외부 고객 매출을 비교하며, 내부 거래가 있으면 제거 후 금액을 확인한다. 연결 합계와 부문 소계를 부문으로 세지 않는다. 비교 가능한 부문 매출을 확정할 수 없으면 판정을 보류한다.
3. 매출이 단독으로 가장 큰 부문을 주 사업으로 삼는다. 과반 기준은 없다. 해당 부문의 실제 사업이 적용 사전 한 항목의 정의와 포함·제외 범위에 분명하게 맞아야 한다. REIT, 통신과 미디어, 관리의료에는 기존 경계를 적용한다. 확정된 상위 섹터와 충돌하면 기존 배정을 보존하고 오너의 별도 결정 대상으로 남긴다.

| 판정 조건 | 기록할 결과 또는 사유 |
|---|---|
| 최신 연차 원문 또는 필요한 정정 부분 미보유 | 수령 대기. 수령 후에도 자료가 없는 경우와 구분 |
| 사업별 구분 없이 지역별로만 공시 | 미확인 · 지역별 부문만 공시 |
| 부문별 매출이 없거나 동일 기준으로 비교 불가 | 미확인 · 비교 가능한 부문 매출 부족 |
| 최대 매출 동률 | 미확인 · 최대 부문 동률 |
| 단독 최대이나 사업 설명이 모호하거나 사전 대응이 0개 또는 복수 | 미확인 · 사전 대응 불명확 |
| 사전의 상위 섹터와 현재 고정 섹터가 충돌 | 배정 보류 · 상위 섹터 충돌 |
| 단독 최대이고 사전 한 항목에 대응하며 경계 통과 | 해당 하위 산업 배정 |

비공개 판정 기록에는 평가일, CIK, 서식·접수번호·제출일·결산일, 원문 SHA-256과 표 위치, 사업별 매출·단위·기간, 최대 부문의 설명, 채택한 사전 ID 또는 보류 사유를 남긴다. 분기 매출, 이익, 자산, 지역 매출 또는 SIC만으로 연간 사업 순위를 만들지 않는다.

## 전체 시장 후보에 적용하는 절차

기존 소비기의 `issuer_candidate`에서 유일한 발행사에 연결됐고 사업 검토가 필요한 행을 발행사별로 모은다. 증권 종류 상태, 제외 사유, 엄격 집계의 보통주 검증 조건을 보존한다. 보유 연차 근거가 있으면 위 표를 적용해 `CANDIDATE`에만 반영하며, 미확인 회계모형은 그대로 둔다. 검토 대상에 필요한 미보유 원문 수는 평가일·CIK·접수번호로 중복 제거하여 센다. 접수번호조차 미확인인 발행사는 별도 계수한다. 이 단계에서는 전체 시장의 문서를 요청하지 않는다.

같은 발행사에 종목이 여러 개인 경우 문서 검토는 한 번 하고, 종목 수와 고유 발행사 분포를 각각 보고한다. 운영 평가일 확정 기록, 공식 QGV와 회계모형에는 자동 반영하지 않는다.
