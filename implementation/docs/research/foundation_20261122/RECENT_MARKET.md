# 비공개 미국 상장 보통주류의 최근 가격 1회 설계

평가 거래일의 실제 상장 명부가 분모다. 약 5,600은 용량 계획의 가정이다. 해당일 거래소 상장 원장·변경 공지에서 당시 유효했던 증권을 복원하고 SEC 발행사·종류 정보를 대조한다. 보통주, 종류주, ADR·ADS, 외국 보통주, 보통주 성격의 SPAC 등을 보유한다. 거래량·가격·시총이 낮거나 자료가 없어도 후보 행과 근거를 보존한다. 전용 ETF 비교 명부는 별도다.

| 단계 | 제안하는 기록과 결과 |
|---|---|
| 명부 고정 | 평가일, 마감시각, 시장별 출처·해시·유효기간, 증권·발행사·종류 키 및 심벌 변경을 기록한다. 당시 명부의 시장별 수, 중복 처리, 미해결 종류를 대사한다. |
| 최근 일봉 한 번 | 승인 뒤 각 증권에 최근 원봉 한 페이지를 우선 요청한다. 요청 시도와 성공, 공급처 기호 매핑, 빈 결과, 오류와 미시도를 각각 남기고 같은 페이지는 과거 채우기에서 재사용한다. |
| 기존 기준 평가 | 주요 거래소, 발행사 명목 시총, 대표 증권 종가와 63거래일 통합 거래대금 중앙값을 각각 통과·미달·미확인으로 기록한다. 이전 선정 상태로 진입·유지선을 선택하고 SIC 6770·증권 종류 판정도 보존한다. 부족한 입력과 기준별 판정 이유가 남는다. |
| 시총과 상위 500 | 동일 기준일 종류별 실제 발행주식수·원종가·통화·ADR 비율 및 전체 후보의 시점 적격성을 검증한 후 발행사 순위를 낸다. 증명 범위에 따라 시총 후보·확인, 순위 후보·확인을 구분한다. 공식 모집단 전환은 별도 결정이다. |
| 이력 결정 | 전 종목 5년안과 통과 증권 5년·나머지 1년안을 비교한다. 최근 페이지 포함 각각 `13N`, `3N+10P`로 계획한다. N은 명부의 증권 수, P는 5년 배정 증권 수다. 실제 요청 수는 상장일·공급 이력·거래소 탐색·재시도에 따라 달라진다. |
| 조회 저장 | 64개 색인 조각은 요청 종목의 위치를 찾는다. R2는 비공개 저장 위치다. 월별 과거 부분과 일별 꼬리 묶음은 객체의 형식으로, 별도로 선택할 수 있다. 오너 인증 후 같은 세대·해시의 한 증권만 전달하는 조건으로 두 형식을 비교한다. |

기존 비공개 파일을 로컬에서만 읽는 용량·복원 시험에 대해 별도 승인을 요청한다. 시험 범위는 색인·묶음·로컬 객체 디렉터리의 무결성, 실패 시 이전 세대 복원, Git·객체·증빙의 바이트와 접근 횟수 측정이다. 운영 R2 계정·결제·토큰·배포 및 신규 가격 수집은 별도 결정에 따른다.
