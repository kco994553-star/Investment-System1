## 오너 결정표 · 어떤 용도에 충분한가

2000~2024년 시간 분리 평가를 기준으로 한다. 신호가 유지된 연속 월을 한 구간으로 집계하고, 전망창 중복에는 24개월 블록 재표집 민감도를 병기했다. 아래의 '참고만'은 수치 자체는 설명할 수 있으나 미검증 규칙으로 실시간 자동 판정하거나 해당 빈도를 개인 투자확률로 제시할 근거가 부족하다는 뜻이다.
